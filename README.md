# 2D Rigging Lab

2D キャラクターのイラストを「動くモデル」にするための、個人の実験用プロジェクトです。

レイヤー分けした PSD を取り込んで、メッシュ・変形・パラメータ・揺れ物を組み、独自のランタイムで表示して配信に乗せるところまでを、一通り自前で作っています。もう一つのテーマは **AI エージェントと一緒に作ること** です。コードや設計の大半は LLM エージェントとの共同作業で書かれています。さらに、エディタを AI が人間と同じ操作で動かせるようにして、AI 自身にモデルを組ませる実験もしています。

## 位置づけ

- 個人の研究・実験として作っているもので、製品ではありません。
- 動作・互換性・今後の開発継続について、何も保証していません。Issue や Pull Request に対応できるとも限りません。
- 「中身を見たい人向けに公開している」くらいの温度感です。

## 中身

### apps/

| ディレクトリ | 内容 |
|---|---|
| `apps/editor` | GUI エディタ（Electron）。PSD の取り込み、メッシュ生成、デフォーマ、パラメータ、物理（揺れ物）の編集 |
| `apps/runtime-player` | 作ったモデルを表示するプレイヤー（Electron）。フェイストラッキングで動かして、OBS などで配信に乗せる |
| `apps/authoring-host` | AI エージェントがモデルを操作・検証するためのコマンド実行ホスト |
| `apps/soul/agent` | AI との共演配信の実験。LLM がチャットを読んでしゃべる |

### packages/

| ディレクトリ | 内容 |
|---|---|
| `contracts` | モデルのデータ構造と各種スキーマ |
| `package-format` | モデルパッケージ（保存形式）の読み書き |
| `operation-core` | 編集操作と操作ログ |
| `authoring-core` | メッシュ自動生成などの制作処理 |
| `runtime-core` | パラメータからモデルの変形を評価するランタイム |
| `render-core` / `render-webgl2` / `render-software` | 描画（WebGL2 とソフトウェア描画） |
| `validator-core` | モデルの検証 |
| `ai-interface` | AI エージェント向けのコマンド体系 |

### discussion/

設計判断、実験の記録、調査レポート、レビューなどを溜めている場所です。AI エージェントとの作業の「外部記憶」として運用していて、ほとんどがエージェントとのやり取りの中で書かれています。入口は [`discussion/_map.md`](discussion/_map.md) です。

## 動かすには

pnpm のワークスペース構成です。

```bash
pnpm install
pnpm test
```

ほかのコマンドは各 `package.json` を見てください。サンプルのモデル素材（PSD）はリポジトリに含めていないため、それを使う一部のテストは動きません。
