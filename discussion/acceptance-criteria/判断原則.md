# Open Live2D Stack Acceptance Criteria System Draft

## 判断原則

ある要素をACに含めるか迷った場合、次の問いで判断する。

1. それは Open Live2D Stack が表現領域として成立するための本質能力か。
2. それがなければ Open Model Format / Runtime / Viewer / Editor / SDK / VTuber App / Validator のいずれかが成立しないか。
3. それがなければ Cubism 非依存の制作・実行・配信・組み込み利用が成立しないか。
4. それがなければ AIエージェントがモデル構造、runtime state、差分、検証結果を観測・操作・レビューできないか。
5. それは Cubism Editor や VTube Studio のUI都合ではなく、Live2D 的な制作成果・実行成果に関わる能力か。
6. それは Open Source 公開を前提に、権利的にクリーンな仕様・資産・依存関係として扱えるか。

上記のいずれかに強く該当するならAC候補とする。

該当しないなら、後続の仕様・シナリオ・UI設計・便利機能・将来拡張に降格する。

次は初期ACまたはMVPの成功条件にしない。

- `.cmo3` の独立読み書き
- `.moc3` 互換出力
- Cubism Editor UIの模倣
- VTube Studio 互換設定の完全再現
- MotionSync / LipSync
- Video Editor

これらは、参照対象、移行調査、将来拡張として扱ってよい。
