## 2. 動きのまとまりとしての15系統（提案）

感情名だけでなく、「相方に何を伝えるか」「頭・視線・姿勢でどう見せるか」で束ねる。番号は今回の会話で用いた番号を保持する。

| 番号 | 仮分類 | 記録にある意図の例 | 動きのイメージ案 |
|---|---|---|---|
| ① | 対象へ注意を向ける | ゲーム画面へ顔を向ける／コメントへちらっと目を向ける | 視線を先に送り、顔がついていく。その対象を見ながら話す |
| ② | 探す・確かめる | 周囲を探すように視線を動かす／画面の奥をのぞき込む | 視線を巡らせる、少し顔を寄せる。まだ見極めている途中 |
| ③ | 考える・腑に落ちない | 考えるように少し首をかしげる／不思議そうに首をかしげる | 首を傾けて少し留まる。答えが定まっていない |
| ④ | 納得・手応えを共有する | 手応えを感じて小さくうなずく／思い出したように小さくうなずく | 一つ頷いて落ち着く。「そういうことか」「うまくいったね」 |
| ⑤ | 気づく・発見する | 気づいたように少し顔を上げる／ぱっと顔を上げて笑う | 一瞬止まり、顔や視線が上がる。気づいた対象へ注意が集まる |
| ⑥ | 驚いて身を引く | 驚いて少し身を引く／コメントに驚いて少し顔を引く | 頭が短く後退し、対象を見直す |
| ⑦ | 身構える・固唾をのむ | 画面の敵に視線を向けて少し身を固くする／宙に浮いた光を警戒して目で追う | 姿勢を少し固め、対象を追って待つ。警戒が続く |
| ⑧ | 苦笑・呆れを共有する | 苦笑して肩をすくめる／苦笑しながら軽く首を振る | 首振りや身のすくみを挟み、相方に「困ったもんだね」と返す |
| ⑨ | 一緒に笑う | つられて笑う／思わず笑って軽く肩を揺らす | 頭や上体に笑いの弾みが出る。⑧より素直に楽しんでいる |
| ⑩ | 落胆・悔しさに寄り添う | 悔しそうに少し肩を落とす／思わず肩を落として画面を見つめる | 頭や姿勢が沈み、少し間を置く |
| ⑪ | 安堵して緩む | ほっと肩の力を抜く／詰めていた息を少し吐く | 張っていた姿勢がほどける。⑩と違い、沈んだあとに安心が残る |
| ⑫ | 喜ぶ・称える | 嬉しそうに小さく拍手する／満足そうに笑う | 顔や姿勢が明るく持ち上がり、喜びを相方に届ける |
| ⑬ | 親しみ・照れを返す | うれしくて少し照れたように視線を落とし相手に戻す／相手と目を合わせて照れくさそうに笑う | 一度視線を外し、柔らかく相方へ戻る |
| ⑭ | ちょっと得意になる | 少し得意げに笑う | 少し顔を上げ、相方を見る。「そこは僕の出番だね」 |
| ⑮ | 挨拶を届ける | 視聴者へ軽く手を振る／笑顔で小さく手を振る | 挨拶する相手へ向き、短い呼びかけの動きを送る |

今回の記録には、相方と一緒にゲーム画面を見て、驚き・困り・状況のおかしさを共有する意図が目立った、というのが通読したエージェントの印象。分類別の定量的な順位は未計測。

## 3. 分類を制作へ使うときの留保

- **15系統＝完成モーション15個ではない。** 同じ基本動作から表せそうな候補の束。例として⑧の首振りと肩すくめ、⑫の満足と拍手は、制作時に分ける可能性がある。
- 一つの意図に複数の働きが重なってよい。「ほっとした笑顔で手を振る」は安堵と挨拶を含む。一件を一分類へ無理に押し込めない。
- 視線・顔の行き先は分類から独立した検討事項。相方は画面左（キャラから見て右）だが、ゲーム画面・コメント・視聴者を全部同じ方向に置くとは合意していない。
- 既存の「受け取る」「関心を向ける」は①・④などと近い。しかし、未対応判定の理由を確かめずに既存候補へ戻さない。
- 手・肩・眉などを明示した意図を、現在のモデルの頭や視線だけで十分表せるかは別の判断。頭の代替動作を作っただけで元の意図に対応済みとしない。
- タグは自由記述のまま。分類表をチャッピーが選ぶ許可語彙へ変えない。本人の意図と本文の一致を外部採点・矯正しない。

## 4. ユーザーの判断と次の対象

2026-11-12追記: 下記は⑪着手前の判断。現在は短い安堵の3対象版を実装・配布確認済みで、次の制作対象として⑨「一緒に笑う」を選択した。笑みの参照画像と、口の複雑化を追わず目・眉・動き中心で表す合意は[一緒に笑う表情](shared-laughter-expression.md)を参照。

当初エージェントは⑧苦笑・⑪安堵・⑥驚いて引くを制作候補として提案した。ユーザーはこの分類を見て「笑み」の表情差分が欲しくなると述べ、**まず笑みの追加なしで対応できそうなものから進める**と判断した。

- 次に議論する対象は **⑪安堵**。
- **⑥驚いて引く**も汎用性が高い制作候補。次の制作を確定・着手したわけではない。
- 笑みの表情差分の追加、⑧の制作は今回まだ着手しない。
- この文書の保存後、⑪の見え方をユーザーと議論する。具体的なパラメータ列やモデル変更はまだ合意していない。

## 5. ⑪安堵の議論へ持ち込める実例

以下は記録にある意図と本文。原文はローカル記録フォルダで意図・本文から検索できる。文脈全文はそちらを参照する。

| 意図 | 発話 |
|---|---|
| 安心したように肩の力を抜く | じゃあ、今できるかは気にせず、僕がしたい動きを添えていけばいいね。 |
| ほっとしたように肩の力を抜く | よし、これで前に集中できるね。分けて倒す作戦、うまくいった。 |
| 詰めていた息を少し吐く | 耐えた……！ でも柱と馬車の間、逃げ場が狭いね。 |
| ほっと肩の力を抜く | 回復できたね。ちゃんと立て直せる隙もつかめてきた。 |
| 安堵して笑う | よかった、ちゃんと倒した甲斐があるね。次はあの金色に怯えず探索できる。 |

最後の「笑う」を含む意図まで表情差分なしで対応可能と決めたわけではない。まず身体が緩む部分を検討する。
