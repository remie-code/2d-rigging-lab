# Experiment 01 — 1枚絵のグリッド choice

> Status: **未実測**(2026-10-12、API 残高不足で全呼び出しが 429)。

## 1. 目的

ゲーム画面1枚に対し、Decisions API の choice でグリッドのマスを選ばせられるか、選択がどれくらいぶれるかの傾向を見る。正解は定めない。

## 2. 条件

- 画像: エルデンリング、マルギット戦の配信画面1枚(1080x608、ユーザー提供)。無加工。`tmp/gaze-target/margit-01.png`(リポジトリ外)。
- モデル: `gpt-6-luna`。input は画像のみ(テキスト併記なし)。
- 問い(choice、`name: gaze`): 「ゲーム配信をしている配信者がこのゲーム画面を見たときに見ている場所はどこか？」
- 選択肢: `r{行}c{列}`(0始まり)。説明 = `上から{行}行目・左から{列}列目（x a–b%, y c–d%）`。
- グリッド: 4x3(12択)、16x9(144択)。
- 回数: 各3回(API 自体のぶれを見るため)。
- スクリプト: [apps/soul/agent/scripts/probe-decisions-gaze.mjs](../../../../../apps/soul/agent/scripts/probe-decisions-gaze.mjs)

```powershell
node --env-file=apps/soul/agent/.env.decisions.local apps/soul/agent/scripts/probe-decisions-gaze.mjs --image tmp/gaze-target/margit-01.png --grids 4x3,16x9 --runs 3
```

## 3. 観測

| 実行日 | 結果 |

| 2026-10-12 2回目 | API 残高 $5 追加後、6回とも HTTP 200。下記。 |

### 3.1 実測値(2回目)

| グリッド | choice(3回) | confidence | 上位確率 | 遅延 ms |
|---|---|---|---|---|
| 4x3 | r1c2 / r1c2 / r1c2 | 0.2 | r1c2 .27, r2c2 .20, r1c1 .19, r1c3 .10, r1c0 .08 | 1391 / 329 / 652 |
| 16x9 | r4c8 / r4c8 / r4c8 | 0.05 | r4c8 .06, r4c9 .05, r4c10 .05, r4c4 .03, r4c6 .03 | 448 / 299 / 343 |

- 3回の `answers` は2グリッドとも**完全一致**(確率分布の全値まで同一)。
- 144択はエラーなく通り、`probabilities` は全144件が返る(合計1.00)。
- 確率は全件**0.01刻み**。16x9 では多くのマスが 0.00〜0.01 に潰れる。
- 4x3 の確率分布(行=上から):
  ```
  0.01 0.02 0.02 0.00
  0.08 0.19 0.27 0.10
  0.05 0.04 0.20 0.02
  ```
- 16x9 では、行4(y 44–56%)の横帯と、列8(x 50–56%)の縦帯が周囲より高い。交点が r4c8。
- 応答のトップレベルは `model` / `answers` / `usage`。`usage.input_tokens = 1186`(画像込み)、`output_tokens = 0`。1回あたり約 $0.00012。
- 遅延は手元計測(日本から、base64 で約 0.9MB の PNG を送信、ネットワーク込み)。公称の ≈150ms より長い。
- 確率をマスごとに重ねた画像: `tmp/gaze-target/runs/margit-01-heat-{4x3,16x9}.png`(リポジトリ外)。

### 3.2 解釈(仮説。未検証)

- 同一入力に対する答えは決定的に見える。そうなら、連続画像でのぶれは API の揺らぎではなく画面の変化から来る。
- 4x3 の choice r1c2 はマルギットの下半身を含むが、頭は r0c2(.02)。
- 16x9 の十字型の分布は、モデルが「行」と「列」をおおむね別々に判断している可能性を示す(説明文が行・列の文字で書かれているため)。
- マルギットが画面中央付近にいるため、「マルギットを見た」のか「画面中央に寄った」のかはこの1枚では区別できない。

## 4. 未決

- 中央寄りの偏りと対象の検出を切り分けるには、注目対象が中央から外れた画像が要る。
- 16x9 は confidence が低く分布が散る。0.01 刻みの粒度とも合わせ、使えるかは未判断。
