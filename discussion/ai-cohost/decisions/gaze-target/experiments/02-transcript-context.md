# Experiment 02 — 発言の文字起こしを添えると視線は変わるか

> Status: 1回実施(2026-10-12)。[01](01-single-frame-grid.md) と同じ画像・問い・選択肢で、入力に発言の文字起こしだけを足した。

## 1. 目的

配信者の発言(文字起こし)を入力に添えたとき、選ばれるマスが発言内容に応じて動くかを見る。視線は引き続き見た目の演出であり、発言は判断材料として使う。

## 2. 条件(01 からの差分)

- 01 の結果(答えが3回とも完全一致)を受け、各条件1回のみ呼ぶ(ユーザー合意 2026-10-12)。
- input の content を `[input_text, input_image]` にした。input_text = `配信者の発言（文字起こし）: 「聖杯瓶あと何個だっけ？」`。問いの文言は 01 と同一。
- 画面上の聖杯瓶(緋雫の聖杯瓶、残り5)は左下。4x3 では r2c0、16x9 では概ね r7–r8 / c1。

```powershell
node --env-file=apps/soul/agent/.env.decisions.local apps/soul/agent/scripts/probe-decisions-gaze.mjs --image tmp/gaze-target/margit-01.png --grids 4x3,16x9 --runs 1 --transcript "聖杯瓶あと何個だっけ？"
```

## 3. 観測

| グリッド | choice | confidence | 上位確率 | 遅延 ms |
|---|---|---|---|---|
| 4x3 | r0c0 | 0.23 | r0c0 .29, r2c0 .19, r1c0 .15, r2c1 .10, r2c2 .08 | 891 |
| 16x9 | r5c11 | 0.02 | r5c4 .03, r5c11 .03, r4c9 .02, r4c10 .02, r4c11 .02 | 293 |

- 4x3 の確率分布(行=上から)。発言なし(01)では左列の合計が .14 だった。
  ```
  0.29 0.04 0.03 0.01
  0.15 0.06 0.02 0.01
  0.19 0.10 0.08 0.02
  ```
- 4x3 は確率の山が左列へ移った(左列の合計 .63)。ただし最上位は聖杯瓶のある左下 r2c0 ではなく、HP/FP/スタミナのある左上 r0c0。
- 16x9 はほぼ平坦(最大 .03、同率首位が2マス)。聖杯瓶のマスは .00–.01。
- 重ね画像: `tmp/gaze-target/runs/margit-01-flask-heat-{4x3,16x9}.png`(リポジトリ外)。

### 3.1 追加: 直接的な発言(4x3 のみ)

16x9 は「4x3 程度が粒度の限界」との示唆を受けて外した(ユーザー判断 2026-10-12)。発言を「アイテム欄見たい」に変え、左下を見分けられるかを見た。

| 発言 | choice | confidence | 上位確率 | 遅延 ms |
|---|---|---|---|---|
| アイテム欄見たい | r2c0 | 0.3 | r2c0 .36, r2c1 .33, r2c2 .14, r1c0 .06, r1c1 .04 | 369 |

```
0.01 0.01 0.01 0.00
0.06 0.04 0.00 0.01
0.36 0.33 0.14 0.03
```

- 下の行の合計 .83。アイテム欄のある左下 r2c0 が最上位になった。ただし隣の r2c1(自キャラとボスHPバー)と僅差。
- 重ね画像: `tmp/gaze-target/runs/margit-01-itemslot-heat-4x3.png`(リポジトリ外)。

## 4. 解釈(仮説。未検証)

- 4x3 では発言が判断に効いている。
- 「アイテム欄」と直接言えば左下に届くので、左下の位置を見分けられないわけではない。「聖杯瓶」という語から、画面上のアイテム欄(画面には「緋雫の聖杯瓶」の文字も出ている)へ結び付けるところで外れた可能性が高い。
- 横方向の判別(r2c0 と r2c1 の差 .03)は、縦方向(下の行の合計 .83)より弱い。
- 16x9 では発言を足すと分布が崩れ、視線として使える信号が残っていない。4x3 程度が粒度の限界である可能性(ユーザー所見)。
