# 語彙で描き直した絵(Undine 2026-10-30、たたき台)

> 状態: たたき台。ユーザーと線引きを確かめるための絵。決定ではない。語彙は [scope.md](scope.md) §5〜§10、今の部品の場所は [research/layer-classification-2026-10.md](research/layer-classification-2026-10.md)。
> 会話では同じ並びの図を 2 枚(配信モード・Discord モード)見せた。ここはその文字版。

## 1. 並び(上から)

| 段 | 配信モード | Discord 参加モード |
|---|---|---|
| 体験 | 操縦席(配信の画面)/ コメント(YouTube から)/ 配信の言葉(判定・指示の文)/ 合うロール(チャッピー) | **操作の画面(VC 用の手元)/ ロールの登録(キャラ設定など)/ VC の言葉(判定・指示の文)/ 入れるロール(選んで入れる)** |
| 場 | あなた(話し手で操作者)/ 視聴者(文字で入る)/ 1 段目(場が許す)/ 長さ(体験 1 回分) | **仲間(声で 1 人ずつ)**/ あなた / 1 段目 / 長さ |
| ロール | チャッピー: 性格・方針 / 声・頭 / 体(任意、Live2D)/ 記憶(ロールごと) | チャッピー(Discord 用): 性格・方針 / 声・頭(選んだモデル)/ **体なしでも話す / 記憶は配信とは別** |
| 芯 | 会話の正本(話者付き・N 人)/ 2 段の判定(許す → 判断)/ 考える(頭・思い出す)/ 声にして出す(区切って順に) | 同じ |
| 入口・出口 | 耳(マイク 1 本)/ 目(ゲームの窓)/ 声の出口(スピーカー)/ 体の口(runtime-player) | **耳(1 人ずつの声)/ Bot の接続(DAVE 暗号化)/ 声の出口(Discord へ)**/ 体の口(今回は使わない) |

太字は Discord で新しく要るもの。

## 2. 今のコードで固く絡んでいる所(配信モードの図で強調)

- 会話の正本が耳の中にある(耳 1 本 = 正本 1 つ = 場の始まり)。
- 名前と性格が頭に付いている(ロールという単位がない)。
- 声にして出すのに体が必須。

## 3. 絵から見えること(Undine の見立て)

- 芯の段は、2 つのモードで同じ形のまま使える絵になる。違いは上の 3 段と、下の入口・出口に集まる。
- 固く絡んだ 3 か所は、どれも芯とロールの段にある。Discord を足す前に、配信モードのままここをほどけば、配信の体験は変えずに芯を切り出せる見込み【推測】。
