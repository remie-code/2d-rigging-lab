# 配信モードの体験の流れ: 今と、新しい語彙での形(Undine 2026-10-30)

> 状態: 全場面が決まった(ユーザー 2026-10-30、[scope.md](scope.md) §13・§14)。場面 3 はうちの推奨がそのまま通った。
> 「今」は [research/cockpit-today-2026-10.md](research/cockpit-today-2026-10.md)(コードで確かめた事実)から。
> Discord の流れ([experience-sketch.md](experience-sketch.md))と同じく、あなたの目から見た場面で書く。

## 場面 0. 開く

- **今**: AivisSpeech を起動する。runtime-player を起動して channel を Open にし、URL をコピーする。AHK のホットキーを起動する。ターミナルで `node scripts/cockpit.mjs` を打ち、ブラウザで操縦席を開く。
- **新しい形**: 外回りの起動は**今のまま、あなたが手でやる**(決定)。アプリの受け持ちは開いたあとから。開くと「何をする?」の画面が出て、「配信」を選ぶ。

## 場面 1. 今日しゃべるロールを決める(決定)

- **今**: 「頭脳」を 6 つのモデル名から選ぶ。選ぶと名前と会話指示も一緒に替わる。声は起動引数かコードの定数。
- **新しい形**: ロール(チャッピー)を選ぶ。モデルはロールの中の設定(「チャッピー — GPT-6.1 Sol で動かす」)。名前・性格・声・方針は、ロールを選べば全部そろう。

## 場面 2. ロールを直す(ときどき・決定)

- **今**: 会話指示は「技術頭脳」ごとに 6 つ別々。口数・話し始めは「運転」タブ。声は画面に無い。
- **新しい形**: 「ロールの編集」で、性格の指示・声(方式と話者)・動かすモデル・しゃべり方の方針(口数・話し始め)・体を使うか、をまとめて直す。**体験の外の共通の場所に置く。**

## 場面 3. 今日の配信の準備(うちの推奨・決定)

- **今**: 接続・入出力・運転の 3 つのタブをまたぐ。声の出力先とゲームの窓は、開くと一覧の先頭が選ばれている(保存した値ではない)。YouTube は起動のたびに Connect を押す。器は最初の発火までつながらない。
- **推奨**: 1 枚の「配信の準備」に、触る頻度の順で並べる。
  - **毎回見るもの**
    1. YouTube の URL(今日の配信)。入れるだけで、Connect は「配信を始める」がやる。
    2. ゲームの窓。前回の窓が選ばれた状態で出す。
    3. 器の URL。**ロールに体があるときだけ出る。** runtime-player から写したものを貼る。
  - **たたんでおくもの(めったに替えない。前回の値で出す)**
    4. マイクと、文字起こしの方式
    5. 声の出力先(OBS に乗せる先)
    6. 忙しい間のコメント(あとで拾う / 見逃す)
  - 出ていかないもの: 声の方式(→ ロールの声)、口数・話し始め(→ ロールの方針)、頭脳(→ ロールのモデル)。
  - 「配信を始める」を押すと、YouTube・耳・目・声・体を全部つなぎに行き、つながらなかったものをこの画面で名指しで出す(今は器の失敗が「頭のエラー」に見える)。
  - 体と器の分け方: ロールが持つのは「体を使うか」まで。どこにつなぐか(器の URL)は今日の場の準備。runtime-player をあなたが手で起動する以上、URL はその日の手元の事情やから。

## 場面 4. 配信を始める(決定)

- **今**: 耳の Start が、事実上の始まり。声のプレイヤーと画面キャプチャも一緒に起こす。
- **新しい形**: 「配信を始める」が場の始まり。耳・目・声・体がまとめて起きる。**耳だけ試す手は作らない**(今も耳を起こすと全部起きるので要らない)。

## 場面 5. 配信中(決定)

- **今**: メイン画面は見るだけ。操作は KILL / 復帰とホットキー、設定のダイアログ。
- **新しい形**: **今の画面を大きくはいじらない。** 1 段目のつまみ(KILL・自発・かぶり)はあなたが握り、置き場も今のまま。
- **口数は配信中に替えない。** ロールの方針が持ち、操縦席での上書きは作らない。話し始めも同じくロール側【推測。口数と同じ扱いとして書いた。返事では口数だけ触れている】。

## 場面 6. 終わる(決定)

- **今**: 耳を Stop すると、記憶の保存が走る。ターミナルで Ctrl+C して閉じる。
- **新しい形**: 「配信を終える」が場の終わり。そのロールが、自分の記憶に今日のことを書く。
- 今ある記録は、全部チャッピーのロールの記憶になる(§14)。
- **書き出しの指示(② への頼み方・`_conventions.md`)は一字も替えない。** 替わるのは置き場(そのロールの記憶)だけ。

## 変わる画面のまとめ

| 今 | 新しい形 |
|---|---|
| 「頭脳」の選択(名前と指示が付いてくる) | ロールの選択。モデルはロールの中 |
| 会話指示の編集(技術頭脳ごとに 6 つ) | ロールの編集(性格・声・モデル・方針・体)。体験の外 |
| 声の方式(入出力タブ)・話者(起動引数・コードの定数) | ロールの声 |
| 口数・話し始め(運転タブ) | ロールの方針。操縦席からは外す |
| 接続・入出力タブ | 「配信の準備」1 枚(場面 3) |
| 耳の Start / Stop(始まりと終わりを兼ねる) | 配信を始める / 終える |
| 運転タブの残り(自発・かぶり・Fire)とメイン画面 | ほぼ今のまま |
| 「記憶」タブ | ロールの記憶(今日を記録はそのまま、書き出しの指示も替えない) |
