# 画面を見たまま、不思議そうに首をかしげる

ゲームの出来事や登場人物の言葉に「どういうことだろう」という疑問が残る場面の比較試作。現行の探索には「見れば手掛かりがありそう」、問いかけには「相手から答えがほしい」という働きがある。今回の仮の分類は「不思議に思う」で、三つとも注意先はゲーム画面。[試作クリップ](clips.json)

| 仕草 | 元の場面（原記録ID先頭） | 見比べる点 |
|---|---|---|
| 予想が外れて「あれ？」 | 「あれ、今の一振り出なかったね。」（`534466ab`） | 手元を見て動きが止まり、一度浅く首が傾く。三つの中で先に反応し、先に次を見られる姿勢に戻る。 |
| 言葉が引っかかって考える | 「ホフカルも初耳なのに、ミツドキはいつ知ったんだろうね。」（`37096aca`） | ひと呼吸置いて顎が下がり、考えと一緒に首がじわっと傾く。身体はほぼ残る。 |
| 相手につられて小首をかしげる | カタパルトの「あたしたち、何しに来たんだっけ？」に共感した場面（`b468b0ee`） | はじめに画面の人物に顔を向ける。少し遅れて小首をかしげ、肩もついていく。目元が少しだけ緩む。 |

比較後、3本とも採用。「不思議に思う」を独立した演技の系列として登録した。Decisionには表の順に `wonder-nuances--unexpected`、`wonder-nuances--ponder`、`wonder-nuances--echo` が並び、それぞれゲーム画面向けの比較済みクリップを再生する。[登録定義](../../../../apps/runtime-player/assets/speech-motions/wonder-nuances.json)

リポジトリ直下で `python discussion/ai-cohost/experiments/game-head-tilt-2026-11-22/preview.py` を実行すると、[共通レンダラー](../game-curiosity-astra-62/render.mjs)で `tmp/speech-motion/game-head-tilt-2026-11-22/comparison.mp4` を再生成できる。同じモデル（astra-chan r843）と画角で正面ニュートラルから同時に開始し、20fps・等速・無音で再生する。字幕は元発話を短くした見出し。
