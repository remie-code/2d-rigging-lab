# ゲーム画面を見て喜ぶ三つの仕草

2026-11-22の比較試作。11/21夜の配信で「嬉しさが弾む × ゲーム画面」と判定された実例から、喜んだ直後に何を見たいかに合わせて動きを作った。[試作クリップ](clips.json)

| 試作 | 配信での発話の抜粋（原記録ID先頭） | 動き |
|---|---|---|
| 一手が決まった | 「きれいに360入った！」（`f4180ddf`） | 一撃に合わせて短く顔と肩が弾む。笑みは一瞬で、すぐ目を開けて次の手を追う。 |
| 好機が見えた | 「王さまの体力、あとほんのひと筋だ。」（`636d2831`） | 視線の高さを落として少し寄り、目を開けたまま期待が顔に出る。体は少し長くその位置に残る。 |
| 決着がついた | 「よっしゃ、ゴッドフレイ撃破！」（`2703d797`） | 一瞬だけ沈んでから、顎と肩が大きく起きる。笑顔をしばらく保ってゆっくり落ち着く。 |

比較は同じastra-chan r843、同じ画角、20fpsの等速、無音・閉口。短い仕草は正面に戻って待つ。6本比較の下段には、左から登録済みの画面向け「笑顔がうつる」「ふっとほころぶ」と、相方向け「嬉しさが弾む」を置いた。上段と下段を縦に見ると、一瞬の反応とつられた笑み、期待と愛着、画面と相方に向けた喜びをそれぞれ比べられる。

比較後に3本とも採用。「決着がついた」は既存の成功を喜ぶ候補 `joy` の画面版に登録し、「一手が決まった」「好機が見えた」は、進行中の出来事からそれぞれを選べるように `joy-hit` と `joy-opening` の画面版に登録した。[配布定義](../../../../apps/runtime-player/assets/speech-motions/smile-nuances.json)

リポジトリ直下から `python discussion/ai-cohost/experiments/game-joy-2026-11-22/preview.py` で再現する。[共通レンダラー](../game-curiosity-astra-62/render.mjs)で描画し、`tmp/speech-motion/game-joy-2026-11-22/` に新作3本の `three-game-joy.mp4` と、登録済み3本を加えた `with-registered-smiles.mp4` を出力する。
