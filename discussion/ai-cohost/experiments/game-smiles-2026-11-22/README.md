# ゲーム画面を見たまま微笑む三つの試作

2026-11-22。旧判定で「柔らかく微笑む × ゲーム画面」となった29区間を手掛かりに、正面の同じモデルと閉じ目笑顔のキーフォームで三つの演技を作った。[試作の再生定義](clips.json)

| 演技 | 11/21昼の台詞（抜粋） | 見比べるところ |
|---|---|---|
| ふっとほころぶ | 「二人とも同意してるのに、ちょっと温度差あるの好きだな。」 | 画面の二人を目の前に置き、小さく横に顔を運んでから首が傾き、笑みが短く出る。三案で最初に表情が戻る。 |
| 笑顔がうつる | 「ふふ、カタパルト、いい顔するなあ。」 | 相手の顔を見る短い間を置き、顎が上がるのと一緒に笑顔が開く。肩が少し遅れてついていく、一度の明るい反応。 |
| じんときて微笑む | 「『我が愛娘、ホフカルよ』か……。」 | 最初はじっと聞く。顔をゆっくり伏せて微笑み、うなずきの底から視線の高さを戻す途中にも表情を残す。 |

原記録のID先頭は上から `99400386`・`53b12d01`・`a8970c04`。本人が等速比較で3本を採用。「ふっとほころぶ」は既存の柔らかい笑みの画面版（`soft × game`）、「笑顔がうつる」「じんときて微笑む」は同じ笑みの系列に画面向けの2候補（`echo`・`moved`）として追加した。[登録定義](../../../../apps/runtime-player/assets/speech-motions/smile-nuances.json)
