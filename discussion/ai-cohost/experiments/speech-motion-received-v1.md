# 「受け取った」の動き — 初回試作

> 2026-11-10。ユーザーから「全然悪くない」「すごくいい」と評価。将来の採用は未決、再現用保存を依頼され[保存セット](speech-motion-received-v1/_map.md)へ格納。モデル・製品実装の変更なし。

## 目的

[発話の分解](../concept/speech-motion-intent.md)の冒頭「うん」にあたる、「話が届き、受け止めた」という動きを一つ作る。ユーザーは過去のastra-chanの動作確認GIFを高く評価し、その描画経路で発話意図に沿う動きを実際に作って見ることに合意した。今回は発話全体、アイドル、喜び・強い賛成の演出は扱わない。

## 試した演出（仮説）

正面への注意を保ち、小さく一度顎を下げ、底で短く落ち着いてから、下げるときよりゆっくり戻る。目は閉じきらず少しだけ柔らかくする。これが「受け取った」と見えるかは未確認。音声・口パクは付けず、身体の動きだけを先に見る。

時間は先頭からの秒:

| 時刻 | 動きの強さ |
|---|---|
| 0〜0.50 | 正面で待つ（0） |
| 0.50〜0.86 | 顎を下げる（0→1） |
| 0.86〜0.96 | 小さく下げた位置を保つ（1） |
| 0.96〜1.46 | ゆっくり戻す（1→0.12） |
| 1.46〜1.90 | 正面へ収める（0.12→0） |
| 1.90〜3.20 | 正面を保つ。ループを急かさない余白 |

区間内は五次smoothstep。強さ1で `param_face_angle_y=-8`、`param_face_angle_z=0.65`、左右の目の開き `0.91`、視線Y `0.08`。これらはモデルのパラメータ値で、観察された実際の頭の回転角とは同一視しない。他の顔・体・眉は中立、口は閉じる。モデルに既存のDynamicsは通常評価する。
