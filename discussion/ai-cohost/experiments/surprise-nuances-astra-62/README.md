# 驚きの五つの演技を見比べる

11月19日の直近配信では、再生受付された驚き10区間のうち、8件の意図は目を丸くする仕草、2件は少しのけぞる仕草だった。23時27分ごろの2区間は約11秒差。攻撃説明の「三連発」に目を留める発話と、次の説明で「三発から六発」と聞いて少し引く発話に、同じ演技が選ばれた。一覧は、この記録と11月11日の未対応記録から選んだ五つの反応を、同じ正面基準で比較するための試作。

| 演技 | 記録IDの先頭 | 見比べるところ |
|---|---|---|
| ① 意外な数字に目が留まる | 4cb78557 | 「もう8体分」で目が開き、顔が一拍止まる。目の前の数字を読める程度に体は静かに保つ。 |
| ② 速さに驚いて追う | 63db51f9 | 「速っ」で視線が先に走る。顔、肩と順に追い、敵が着いた先に注意を留める。到着先を画面右としたのは演出上の仮定。 |
| ③ 不意を突かれて引く | 15ae0cf2 | 巨体が跳んだのを見て顔と姿勢が引ける。c575b3e4の採用済みクリップをそのまま使用。 |
| ④ 意外な可能性に惹かれて寄る | 5ade96c1 | 一度目を開いて受け、そこから首と上体が前へ出る。聞いた情報が自分にとって魅力的だった間を取る。 |
| ⑤ 驚きがほどけて笑う | dcdba40a | 「入り口までつながるの!?」で見開きが出たあと、驚きが消えてから閉じ目の笑みがこぼれる。 |

①②は全件記録の `speech-intent-motion`、③〜⑤は過去の `speech-intent-none` にある発話。記録への照合用IDと台詞は [studies.json](studies.json) に含む。音声は日本語のローカル仮読み。②の眼球は見開きが変化する間は止め、⑤では見開きと閉じ目笑顔の間に通常の目を通る。表情は既存のモデルから引く。

## 再生

出力先は `tmp/speech-motion/surprise-nuances-astra-62/`。`comparison.mp4` は同時開始・等速の5面比較。短い演技は終端の正面姿勢を表示する。`with-voice.mp4` は同じ5本を番号順に台詞と口パク付きでつないだもの。各案の個別MP4も同じ場所に出る。比較後、本人が4本とも採用。[配布定義](../../../../apps/runtime-player/assets/speech-motions/surprise-nuances.json) と現用自律スロットに追加した。ゲーム画面・視聴者の両方から同じクリップを使う。③は従来の `startled-recoil` で選べる。

再生成はリポジトリのルートで次を実行する。[共通のモデルと描画環境](../game-curiosity-astra-62/README.md)を使用する。

```powershell
python discussion/ai-cohost/experiments/surprise-nuances-astra-62/preview.py
```
