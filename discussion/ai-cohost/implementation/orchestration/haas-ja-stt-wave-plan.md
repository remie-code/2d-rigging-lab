# Haas-ja をローカル文字起こしに追加

2026-11-09 合意。実装ブランチは `codex/haas-ja-stt`、実験の基点は `0de501bb`。

配信とDiscordで同じ文字起こし方式を選べる。Haas-jaを選んで開始すると、端末内で発話が転写され、短い転写には既存の咳払い対策が効く。既存の選択値を引き継ぎ、未設定時は従来どおりWhisper。最初の実運用確認はユーザーが試しやすい配信で一度行う。

根拠は [比較実験と結果](haas-ja-experiment-wave-plan.md)、[Windows実動作と独立レビュー](../reviews/haas-ja-experiment/review.md)、[既存ローカルSTT計画](local-stt-wave-plan.md)。

## Wave 1 / Domain A — Haas実行系から共通の選択肢まで

一人の担当で、**実行系と分類 → 耳への接続 → 共通の選択・保存 → 両経路の検証**を順に進める。共有部分の変更が想定以上に広くなる場合は、着手範囲を広げる前にUndineへ戻す。

1. Windowsで実証済みの `speech.cpp` v0.10.1 と Q8 GGUF、標準入出力の常駐ワーカーを起点にする。実験のプロトコル実装を再利用する。既存の配置を利用でき、未配置の環境でも取得先・版・配置手順が分かるようにする。実行ファイルとモデルはGit外。配信・通話の開始に必要な準備を確かめ、準備不足は理由を表示する。
2. 共通VADで切った発話を認識し、既存の咳払い分類・棄却・表示をHaasでも適用する。既存の短文条件としきい値、分類器を使い、sherpaのネイティブ依存を親プロセスへ読み込まない。既存STTの動作を保つ。
3. Discordでは、同じ通話内でHaasのモデルを共有する構成を第一案とする。各発話の結果は発話元の耳に返す。話者の離脱・停止・ワーカー異常時は、古い仕事や結果が次の話者・セッションへ混ざらないようにする。起動失敗時や停止時は、その場で持つプロセス・待機中の仕事を解放する。異常は既存の耳の状態表示に届ける。
4. 操縦席の共通候補にHaas-jaを追加し、配信・Discordの既存の保存と開始の経路で同じ候補として扱う。場のモードでHaasの可否を分けない。Haasの語彙補助は今回の合格条件に含めず、試す際の条件を明記する。

## 機械ゲートと簡易レビュー

- 両モードでの表示・選択保存・開始。既存の設定値・未設定時の挙動・他方式の回帰。
- 両経路での咳払い棄却と相づち通過を、認識と分類の制御可能な入力で確認。Discordの近接した複数話者、離脱と停止、処理中の異常終了で、結果の取り違え・遅れて届く結果・資源の残留がないことを確認。
- Windowsで、導入後のHaas実行経路に公開の日本語試験音声を通す。機械検証は実マイク、Discord実接続、実データ・認証情報を使わない。 `apps/soul/agent` の `node --test`、ルートの `check:soul-zone`、差分チェックを通す。
- Undine → Orch-Sylph → 別コンテキストの Gnome と Review-Sylph。Orch-Sylph自身は実装担当ではない。source implementation は必ず別コンテキストの Gnome に委譲し、レビューは必ず別コンテキストの Review-Sylph に委譲すること。これを分離できない場合は実装せず escalate / blocked として報告すること。委譲時に `[subagent-call]` と呼び出し元を記載する。
- 独立Review-Sylph一人が計画・差分・テスト結果・実行証跡を一報告で照合する。特に共通選択、話者の対応、停止と異常、咳払い、既存方式の回帰を見る。問題がなければ一巡で閉じ、修正した箇所を限定再確認する。報告先は `../reviews/haas-ja-stt/review.md`。

## 実運用確認

機械ゲートとレビューを通した後、Undineが操縦席でHaasを選ぶ手順と、従来方式へ戻す手順を伝える。ユーザーが普段の配信で一度試し、聞き取り、返答までの待ち、咳払いと相づち、ゲームや描画と同時の負荷を観測する。Discordの機械検証と実通話の確認は別々に記録する。

2026-11-10、ユーザーがHaas-jaでチャッピーと会話し、特に問題はなかったと報告した。全体的に文字起こしの精度が高く、特にカタカナ語や外来語を正しく起こせたという所感。確認できたのは今回の会話で、配信負荷・Discord実通話・咳払いの個別評価は記録なし。この確認を受け、ユーザーは `master` への統合とpushを指示した。
