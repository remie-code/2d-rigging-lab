# 読み上げ文から演技を決める 2 Wave

2026-11-22。作業ブランチ `codex/sentence-motion-decision`。[体験と責務の合意](../../concept/sentence-motion-decision.md)・[配信と比較実験](../../experiments/sentence-motion-decision-2026-11-22.md)。配信者が台詞を指定したら、一文の判定から実際の再生まで追えること、声が判定を待たないことを両Waveの基準にする。

## Wave 1　一文から選び、その根拠を記録する

- 読み上げ対象の一文を明示し、直前の会話と同じ返事の先行文を手掛かりにする。発話者に意図タグの生成を求めず、既存のカタログで演技と注意先を一度に判定する。
- 注意先だけが不明でゲーム画面を共有中ならゲームに補う。共有していなければ不明のまま。該当演技なし・対象版未制作も区別する。文・文脈・生の選択・補完先・演技版・再生の観測を辿れる形を定め、過去の区間記録も読めるようにする。
- 文境界の試験には「料理が効いてるね。お、今の一撃…！」を使える。判定器に入った一文・先行文・未来の文が混入していないことを確かめる。APIの個々の選択値に自動試験を依存させない。

## Wave 2　音声と並行して決め、その文に合わせて動く

- Wave 1の独立レビュー合格後に開始。Codexの逐次発話とClaudeの一括発話を通常経路から結線する。体あり・ElevenLabs・Player接続という既存の適用範囲と配信／Discord VCの両経路を引き継ぐ。意図タグの通常時・初回・圧縮復元の教示を片付け、表情・思い出し・小タスクの各制御を保つ。
- 音声と判定を文ごとに並行開始。早い結果は該当文の再生開始に、遅い結果は該当文が鳴っている間に限り適用する。同じ返事で同じ演技・対象が連続すれば再始動しない。未制作、失敗、見送り、連続時も文と結果の記録を辿れるようにする。
- 判定を意図的に保留したまま一文目と二文目の再生開始を観測する。逆順完了、読了、割り込み、場終了／接続交替、連続うなずきを確認。ゲーム共有中と見る窓なしVC、体なしの場合を普段の入口から検証する。遅延や429の新しい閾値は設けない。
- 独立レビューと関連・Soul回帰、必要な現用起動経路の確認後、配信者による最終確認を一度だけ行う。普段どおり話して応答のテンポ、途中の演技の切替、同じ仕草の連打の有無を見て、気になった台詞を記録から再確認する。

## 体制と報告

単一のOrch-Sylphが2 Waveを順に担当し、各Waveで実装Gnomeと独立Review-Sylphを分ける。Orch以下はGPT-6.2 Sol。独立レビューは `../reviews/sentence-motion-decision/`、機械検証と最終確認手順は `../waves/sentence-motion-decision/` に残す。実機確認には開発用の場・記憶を使用する。
