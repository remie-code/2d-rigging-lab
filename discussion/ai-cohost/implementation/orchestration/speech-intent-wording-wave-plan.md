# 言葉だけでも自然に返せる意図タグの説明

2026-11-20。11月19日の配信で、短い相槌は言葉だけでよく、動きも添えたいときにタグを使うと話し合った。6.2 Astraで返事が断片になった際のモデル出力全文は残っておらず、説明文との因果は未確定。

## 1 Waveで行うこと

ウンディーネが[発話時の説明](../../../../apps/soul/agent/skills/speech-intent.md)を更新する。会話を第一に置き、仕草でも伝えたいときの書き方を後に続ける。短さや長さでタグの要否を決めず、話者自身が意図を選べることを大切にする。適用条件と既存の区間書式を引き継ぐ。

別コンテキストのシルフに更新後の本文だけを渡し、短い会話に返答してから、どのような返し方が許されると読んだかを尋ねる。返事でタグを使ったかどうかは採点しない。続いて書式と既存テストを照合する。次回のCockpit起動後、実際の配信で書き損じが減るかを観察する。

## 結果

初見のシルフは「君も実質チャッピーだしな」に「『実質』ってとこだけ妙に慎重だな。もうチャッピーでいいじゃん。」と言葉だけで返した。理由は軽いツッコミがそのまま伝わるからで、肩をすくめる感じも伝えたいなら意図を添えられると説明した。区間の開始・切り替え・解除と読み上げ時の扱いも読み取れた。表情タグと併用できることは伝わり、併記の具体例はこの本文にはないとの所見だった。

`fire-orchestrator.test.mjs` と `incremental-sentence-tag-buffer.test.mjs` は149件すべて成功した。開発側の確認は完了。6.2での書き損じに対する効果は今後の配信で観察する。
