# 苦笑の新5案の登録

承認された比較試作の②〜⑥を、正面版のままゲーム画面・視聴者向けに共用する。比較基準の①「やれやれ」は既存の wry-headshake を使う。相方に向く別版は未制作。

1. Gnome が新規5件を version 2 の単一外部JSONへ登録する。試作の実効値を保ち、口は通常の発話経路へ任せる。既存の件数検査と試作READMEの採用節を更新する。
2. Review-Sylph が原本と再生結果を独立に照合する。既存ID・曲線、対象の未制作処理、候補の共存を確認する。
3. 配布済み通常版を隔離して起動し、11資産・24候補・36組・28クリップ、5案それぞれの両対象の選択と記録参照を確認する。レビュー合格後、現用へ新規JSONを配置し、配布元・現用の既存10件のハッシュを照合する。

採用元は experiments/speech-motion-wry-nuances-v1。隔離起動と外部配置は smile-nuances-registration の手順を踏襲する。
