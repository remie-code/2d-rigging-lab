# アークナイツの固定表示が繰り返し確定する問題の独立レビュー

2026-11-22。**合格。** 固定表示が複数の追跡に分かれる現象と、画面が変わらないのに別の誤読が六回確定する現象を、実画像で確認して解消した。短い別文への交代と、実際に消えた文の再表示は別件として残る。

## 実画像での比較

採取担当の記録では、アークナイツの対象 HWND だけを Windows Graphics Capture で取得し、ゲーム操作は行っていない。同じ JPEG を修正前後の Windows 日本語 OCR と追跡器で比較した。初回48枚と別採取60枚の画像・時刻・OCR は `tmp/arknights-ocr-1122/` にある。実画像の末尾まで見出しが表示されていたため、最後の列だけは、画素が変わり文字が消えた二枚を追加した合成試験の結果。

| 標本 | 全確定 旧→新 | 「勲章シリーズ」確定／保留 旧→新 | 消失追加での見出し確定 旧→新 |
|---|---:|---:|---:|
| 初回48枚 | 10→0 | 0／2→0／1 | 2→1 |
| 別採取60枚 | 1→0 | 0／1→0／1 | 1→1 |

- 固定見出しの OCR 表記は「勲童シリース」。WinRT が画像全体の傾きを +2.2° としたときだけ、見出し左上が約 (77, 156) へずれた。補正後は (86.78, 132.85) で、傾きなしの (87, 133) に一致する。画像中心を基準に語の矩形を元画像へ戻すため、追跡と数値再読は画素と同じ座標で比較できる。[Windows OCR の座標補正](../../../../../apps/soul/agent/src/eyes/windows-ocr.ps1)
- 別の誤読「を一を」は初回48枚で確定六件がゼロになり、一件が保留された。この領域の復号 RGB を独立に比較し、外接矩形と比較用タイルに広げた矩形の双方で48枚すべてが同一であることを確認した。局所の画素一致は、対応する OCR 行が得られない間だけ継続の根拠になる。行の交代判定は既存の文字・画素比較を保つ。[追跡器](../../../../../apps/soul/agent/src/eyes/game-dialogue-tracker.mjs)

## 回帰

- 目の機能の Node テスト85件がすべて通過した。同じ文字列の左右二表示のうち、画素が変わった側だけが消え、再表示で別件になる。独立に実行した「え」→「あ」→消失→「え」→消失でも、上部の固定表示を保ったまま短い三件が確定した。[追跡テスト](../../../../../apps/soul/agent/src/eyes/game-dialogue-tracker.test.mjs)
- エンドフィールドの保存画像146枚を再認識した結果から、修正後の追跡を独立に再計算した。戦闘は確定40→19、保留3→3、ミンホは18→5、9→5、物語は26→13、6→6。総件数には操作 UI、クエスト、誤読が含まれる。戦闘の二件の数値除外は維持し、ミンホの短い問いと後続の発言も同じ本文・表示時刻で残った。物語の「早めに北の雪祭司へ届けてやる必要がある」は一件で、同じ行と確認できた単独の誤読名札は吸収された。「ティフォロス」と「なんにせよ、残りの2つの祭壇を探さないと。」の改行も維持した。ミンホと物語は数値除外の有無で全文・順序・時刻が一致した。[三場面の素材と再生手順](../../waves/game-dialogue-ocr/wave-1a-endfield-replay.md)

見出しの文字そのものには OCR の誤読が残る。静止中に保留された誤読も、領域が実際に消えれば一件として確定し得る。記録した108枚は実地で報告された連続確定をそのまま再現した標本ではなく、静止中の二重追跡と、合成消失後の二重確定を切り分けて検証した。
