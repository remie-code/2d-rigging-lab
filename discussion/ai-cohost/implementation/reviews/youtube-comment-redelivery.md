# YouTube コメント再取り込みの実装レビュー

判定は合格。初回の独立レビュー後、Soul の全件試験で見つかった既存の開場時の受付条件を復元し、再レビューした。

動画 ID と投稿 ID の組を、場の会話に受け付けた時点でガード判定の前に記録する。自動復帰、同じ場での手動再接続、耳の停止と再開で記録を保持し、閉場時に破棄する。開場処理中は会話の正本が作られた時点から従来どおり受け付ける。正本がない時点などに届き、取り込まれなかった投稿は記録しない。組を作れない場合も従来どおり扱う。

- 模擬自動復帰では、再取得した既読4件を除外し、切断中および復帰後の新着を到着順に会話欄と発話判断へ渡すことを確認した。
- 手動接続と部品試験では、ガード待ち中の重複、同じ本文の別投稿、別動画の同じ投稿 ID、同じ動画の URL 表記違い、投稿 ID の欠落、場外・切断済みの器官からの到着、耳の再開と閉場後の再受付を確認した。
- 最終差分で関連330件、Soul 全2642件が通過した。独立再レビューでは Wave の3件と Domain A・M を含む12件が通過した。`git diff --check` も通過した。

YouTube の応答は模擬し、接続を必要とする試験ではローカル HTTP を使用した。
