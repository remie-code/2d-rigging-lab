# 意図モーション全件記録の実装契約

[承認済みの Wave 計画](../../orchestration/all-motion-recording-wave-plan.md)を受入基準とする。対象は現行 ElevenLabs 配信経路で捕捉した意図付き発話区間。

## 区間と観測

- scene・utterance・generation・section の識別子で区間を一意に扱う。原意図タグ、捕捉した最終本文、判定時点の入力、会話文脈を保持する。判定前に中断した場合にも捕捉内容を残す。
- 選択、未対応、判定失敗、終了時点での未判定を区別する。演技と対象は判定が返した値を残す。中断や後続区間への遷移で無効になった結果は後続区間へ反映しない。
- 判定とモーション要求と音声を別の観測として保存する。要求は見送り、受付、拒否、結果不明を区別し、受付は Player の応答を示す。音声は送信・再生経路の観測を記録する。
- JSON の記録先は `apps/soul/agent/tmp/speech-intent-motion`。新形式は独自の schema version を持つ。同じ区間の重複終了は一つのファイルに収束させ、書きかけのファイルは公開しない。既存の `speech-intent-none` と固定実験用の集計は保持する。

## 演技版

- Player は候補生成・再生に使う起動時の有効 JSON 定義を、スロットの `speech-motion-archive/<sha256>.json` で内容により識別して公開する。定義には対象とクリップの対応表およびクリップ本体を含める。同じ内容を共有し、編集・削除・再起動によって過去の版が失われないようにする。
- hello で選択元の定義版と対象ごとのクリップを辿れるようにする。定義版の識別と版の保存状態を区別する。対応クリップがなければクリップ参照は付かない。旧 Player から版を受け取れない場合も区間記録は残す。
- 保存処理と要求応答・判定を音声進行から切り離し、保存失敗を診断へ出す。版の参照は選択に使った接続の情報を保持する。
