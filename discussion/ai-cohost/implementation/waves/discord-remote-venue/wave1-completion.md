# Wave 1 — 今回の設定でDiscordの場を開く

独立レビューは合格。修正ループなし。最終差分の実装側対象テストは247件、独立レビュー側のCockpit・Discord対象テストは406件が合格した。作業途中の全体テストも2582件が合格した。[独立レビュー](../../reviews/discord-remote-venue/wave1-review.md)

- 既存の開場APIが一時指定を受け、初回から指定VC、VC付属チャット、見る窓なし、自発ONを適用する。明示されたチャット、見る窓、自発、ロール、モデルも場の有効値にする。Discord準備の文字起こしと、有効ロールの声を使う。
- 既定と明示値の両方を、保存値を意図的に食い違わせたHTTP試験で確認した。失敗、部分開場、閉場後の通常開場も確認した。指定先を解決できない場合はVCへの接続を始めない。
- 選択したCodexモデルを会話、記憶の書き出し・整理・思い出し、小タスクの既存の担当モデル解決に渡す。書き出しが待ちに入ったときも受付時のモデルを使う。Claudeロールは通常の役割分担に従う。

実行したのは隔離したデータ、合成Discord、テスト代替のモデルでの試験。開場処理中に手動でDiscordの窓を変更した場合にキャプチャとの同期が遅れる既存の競合は、独立レビューに記録した。実Discordでの音声、実モデルの応答および本人データでの動作は本人確認に残る。
