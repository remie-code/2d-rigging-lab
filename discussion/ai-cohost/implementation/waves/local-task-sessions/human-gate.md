# 本人確認 — 記憶参照とDiscordの資料

確認状態は未実施。[合意した本人確認条件](../../orchestration/local-task-sessions-wave-plan.md#accepted-user-gate)

1. 操縦席でいつものロールの場を開く。チャッピーと普通に話し、覚えているはずのことを一つ尋ねて、思い出した内容が従来どおり会話に戻るか確かめる。
2. 操縦席のDiscordで「読むチャット」を選ぶ。選んだチャンネルに4ページ目以降にも固有の情報があるPDFを投稿する。たとえば「今貼った資料の5ページから、集合場所を確認して」とチャッピーに頼む。
3. 担当が調べている間にチャッピーへ別の話をする。会話を続けられ、後で資料に基づく返答を受け取れるか確かめる。
4. 同じ場で元の資料について別の問いを出す。VCを退出して再参加した後に、PDFを投稿し直さず同じ資料を確認してもらう。
5. 資料の確認を頼んだ直後に操縦席で場を閉じる。閉場中は新しい発話を始めず、担当の仕事と最後の記憶保存が終わってから次の場を開けるか確かめる。

ターミナルから終了する場合、最初の Ctrl+C または EOF も通常の閉場を待つ。さらに Ctrl+C を押すと Cockpit が強制終了し、使用中の可能性がある場の領域は残る。再起動後は新しい場として開き、前の作業領域の回収は手動で行う。残った領域を片付ける前に、担当や writer の停止を確認し、閉場時の通知が示したその場の作業領域を個別に確認する。

違和感があれば、操作した手順、依頼の言い方、確認したいページ、実際に返った言葉、閉場時に見えた状態のうち、差が出た箇所を伝える。報告に実資料や秘密の内容を含める必要はない。
