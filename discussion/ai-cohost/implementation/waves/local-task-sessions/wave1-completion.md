# Wave 1 完了 — 共通セッションと記憶参照

[計画](../../orchestration/local-task-sessions-wave-plan.md) · [実装契約](basis.md) · [独立レビュー](../../reviews/local-task-sessions/wave1-review.md)

通常の Cockpit の Fire が受理した記憶参照を、場ごとの共通実行口に接続した。担当は依頼ごとに新規セッションを使い、完了時に片付ける。記憶の作業フォルダ、読み取り専用、検索指示、待機一件、結果を話すか次の会話へ前置きするかの判断は記憶参照側が引き続き担当する。

独立レビューの指摘を受け、一度の修正を行った。旧場から発生した遅延依頼はその場の転写と照合し、旧場を閉じると記憶参照由来の未消費の前置きを破棄する。担当の停止を確認できなかった場合は、担当の返答と別に共通実行口へ障害を記録する。場領域を保持する処理は Wave 2 の責務とした。

- 対象テストは着手前58件、修正後63件成功。独立レビューで63件を再実行した。実 Fire と Cockpit をつないだ閉場のHTTP試験は修正後2件成功。モデルと音声は試験用の代替実装を使った。
- 実装担当が実行したSoul全体は初回2,570件、修正後2,573件成功。Soul境界チェックと差分チェックは成功。ソース構成チェックは既存の `apps/runtime-player/src/main/physiology/index.ts` に1件の指摘を返した。
- Wave 1 の内部確認は合格。本人の会話確認は未実施。
