# Wave 2 完了 — 場の資料と終了順序

[計画](../../orchestration/local-task-sessions-wave-plan.md) · [実装契約](basis.md) · [独立レビュー](../../reviews/local-task-sessions/wave2-review.md)

場が原本と依頼ごとの作業領域を保持し、担当と記憶の書き出し役に絶対参照を渡す構成を追加した。閉場は新規受付と会話配送を止め、受付済みの担当の終端を待つ。資料と担当の返答を転写とともに書き出し役へ渡し、保存と必要な整理の後で場領域を解放する。担当または書き出し役の停止が確認できない場合は領域を保持する。永続記憶の置き場を掃除の対象に含めない。

最後の保存を90秒で切り上げる挙動を撤去した。最初の Ctrl+C と EOF も通常の閉場を待つ。終了処理中の再度の Ctrl+C は、領域を残しプロセスを終了コード130で止める。相対指定の一時フォルダから発行した資料参照が担当の cwd で壊れる指摘を受け、一度の修正で発行時に絶対パスを固定した。

- 実装担当はSoul全体2,569件と、その後の関連311件に合格した。独立レビューは修正後の関連274件と、新規の相対一時フォルダの回帰に合格した。
- Wave 1 からの全体件数差は、廃止した待機上限と旧Ctrl+Cの7件を外し、既存テストの更新と新規テストで純増3件とした分。独立レビュー後の相対パスの回帰は別計上。
- 仮想91秒を過ぎても待機が続くこと、資料または返答のみから保存できること、writer・commit・整理・解放の順を試験した。Soul境界、依存境界、差分チェックは成功。ソース構成チェックには既存のPlayerファイルの指摘が1件ある。
- Wave 2 の内部確認は合格。Discord原本から小タスクを起動する経路と実モデル確認は Wave 3、本人確認は未実施。
