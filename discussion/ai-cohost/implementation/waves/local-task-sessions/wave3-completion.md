# Wave 3 完了 — Discord資料とローカル小タスク

[計画](../../orchestration/local-task-sessions-wave-plan.md) · [実装契約](basis.md) · [独立レビュー](../../reviews/local-task-sessions/wave3-review.md) · [検証記録](local-task-experiment.md) · [本人確認](human-gate.md)

Discord添付の原本を場に保存し、チャッピーに資料参照を渡す。自由文の依頼を発話から取り出し、記憶参照と同じ実行口から毎回新しい担当セッションを起動する。担当が調べる間も主会話を進められる。VC退出中は返答を保留し、結果を渡す ask が失敗した場合は次の ask に渡す。主会話のモデルが返答を受領した後は、音声合成の成否に関わらず同じ内容を再投入しない。閉場時は会話への配達に代えて書き出し役へ資料と返答を渡す。

- 実装担当の Soul 全回帰は2,573件成功。独立レビューの横断回帰は492件成功。依存境界・Soul境界・差分チェックは成功。ソース構成チェックには既存のPlayerファイルの指摘が1件ある。
- Windowsで担当専用cwdへの書き込みと原本の読み取りを確認した。原本、他の担当の作業先、共有TEMP、合成の永続記憶への書き込みは拒否された。WinRTの道具は場発行の資料IDと任意のページ番号を受け取る。
- GPT-6.1 Sol と GPT-5.6 Terra の双方が、圧縮文字PDFの第4ページと画像PDFの第5ページを読み、同じ担当のcwdへ結果を書き出して再読込した。通常 Cockpit の隔離起動と、合成Discordからの会話継続・配達は個別に試験した。
- 二度目の Ctrl+C の強制終了では保持する場の作業領域をターミナルに表示する。再起動時の回収は手動。通常の閉場では受付済みの担当と記憶保存・整理の後に片付ける。
