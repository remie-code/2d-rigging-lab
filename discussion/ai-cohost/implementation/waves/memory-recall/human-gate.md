## 0. 準備

- 器(runtime-player)は変えていないので、作り直しは不要。
- 操縦席を、今までどおり管理者で起動する(`start-cockpit.cmd`)。頭は Codex。
- 記憶のフォルダは `apps/soul/agent/memories/`(別の git。移し替え済みで、トピックは arknights / arknights-endfield / cohost-dev / live2d-editor)。

## 1. 確かめる 6 点

| # | やること | 合格の目安 |
|---|---|---|
| 1 | 起動して Start する | ターミナルやログに、ユーザーの MCP サーバー(node_repl・blender など)の起動が出ない。Codex の turn のたびに、ユーザーの通知が鳴らない |
| 2 | 配信前の動作確認で「今日は○○の配信やで、関連すること思い出せる?」と頼む(○○は記録のあるゲーム) | チャッピーが一言しゃべってから探しに行く(ログに「思い出し中」)。その間も会話できる。30 秒前後で結果が届き、2 回目にしゃべる(ログに「思い出した」) |
| 3 | 記録にない話題で同じように頼む | 「思い出せなかった」趣旨のことを言う(ログに「見つからなかった」) |
| 4 | 頼んだ直後に、まったく違う話題に変える | 結果を言わない(ログに「避けた」)。そのあと同じ話題に戻ると、知っている |
| 5 | 「今日を記録」・耳の Stop・Ctrl+C のどれかで保存する | 記憶のフォルダに、正しいトピックの本体と目次ができる。`git -C apps/soul/agent/memories log --oneline` に「書き出し役」のコミットが積まれる |
| 6 | 移し替えた過去の記録のことを聞く(例: 前のアークナイツの配信) | 過去の配信のことを思い出して話せる |

## 2. ついでに見てほしいこと

- 「避けるか」の判定のしきい値(0.8 以上でだけ避ける)は、4 の結果で詰める。
- 思い出しに約 30 秒かかる間の体感。
- 会話指示の編集画面に、思い出す教えが「いつも足される内容」として読める形で出ているか。
