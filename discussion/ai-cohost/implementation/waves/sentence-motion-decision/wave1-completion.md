# Wave 1　一文から演技と注意先を決める

実装と独立レビューに合格。独立レビューで関連29件が成功し、`git diff --check` も通過した。[Wave 1独立レビュー](../../reviews/sentence-motion-decision/wave1-review.md)

- 確定した読み上げ文を、直前の会話と同じ返事の先行文から区別してDecisionに渡す。「料理が効いてるね。お、今の一撃…！」の試験で、判定対象と先行文、未来の文が混ざらないことを確認した。
- 現行カタログから演技と注意先を一度に選ぶ。注意先が不明でゲーム画面を共有している場合は、該当演技の注意先をゲーム画面に補う。生の注意先と補完後の注意先、演技なし、対象版未制作を区別する。
- 文記録は既存の区間識別子と保存処理を使い、`version: 2` とした。選択時の演技版の参照と音声・モーションの観測欄を持ち、同じ保存先にある旧区間記録も読める。

Codex・Claudeの通常経路からの入力、実際の文ジョブとの時間合わせ、場の終了や接続交替時の失効はWave 2で検証する。[2 Wave計画](../../orchestration/sentence-motion-decision-wave-plan.md)
