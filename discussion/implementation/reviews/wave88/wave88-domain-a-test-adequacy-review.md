## Residual Risks

- The non-change test covers rig-control non-membership changes, keyforms, and dynamics, but does not include a warp-lattice-specific deformer metadata fixture. Source inspection reduces this risk because the signature helper does not consume non-membership rig control fields.
- The source signature change test mutates source bytes, not every texture metadata field. Source inspection confirms texture entry metadata and binary ref metadata are in the normalized payload.
- `sourceSignature` is optional in the package schema for backward compatibility; downstream Domain B/C should explicitly handle old layout summaries without signatures as missing/stale or define a migration policy.

- No blocking user decision is required for Domain A test adequacy.
