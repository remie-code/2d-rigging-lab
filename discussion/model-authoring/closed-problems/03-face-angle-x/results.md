# 閉問題 03: 結果（問い B の判定）

> 定義: [problem-definition.md](problem-definition.md) / 答え移植版の記録: [build-log.md](build-log.md) / 盲目再構成: [blind-experiment/design-log.md](blind-experiment/design-log.md)

## 二段階の判定（2026-07-03、いずれも満点）

### 第1ラウンド: 答え移植版

**「答えを参照してショートカットしたとはいえこれは・・・100点だ。およそ完璧に動作しているように感じる、違和感もない」**

ただし審美的設計の原作量はほぼゼロ（値は ref field の移植、Fable の原作は移植工法のみ）と Fable が自己申告 → ユーザーの保留問題「craft の言語のみからたどり着けるか」が未検証と合意。

### 第2ラウンド: 盲目再構成実験（ユーザー発案）

設計: git で cp03 前へ巻き戻し → クリーンコンテキストの Fable サブエージェントに craft のみで rigging させる（ref・答え記録・git 履歴へのアクセス禁止、設計ログ義務、数値ゼロの委任文）。

結果: **7 op / reject 0 / 回帰無傷 / 視覚イテレーション1回で完走。**

**ユーザー判定: 「忖度なしに言って、上品な回転としては満点だ、けちのつけようもない完璧な動きをしている」**

## 実験の定量的発見: field = 構造 × ゲイン

- 盲目版の内部比率（眼min/鼻 0.85 vs 答え 1.03 等）は答えと誤差2割以内で一致 = **言語は構造を運んだ**
- 全要素が一様に約1/2スケール = **言語はゲインを運ばなかった**（盲目 Fable は鼻振幅を頬幅の11%と自己決定。答えは約20% = ユーザーの「大きく動いた方が楽しい」という演出意図）
- ユーザー裁定: ゲインは正しさの軸ではなく**演出の軸**。「今回はゲイン=1という世界線を採用しよう。この結果はこの世界線において完全な正解」→ **盲目版（rev 94）を正典として採用**、答え移植版は branch `cp03-answer-transplant` に保存
- craft への昇格: 構造とゲインの分離をレシピ06に恒久化（構造をゲイン1で組み、gate でユーザーがダイヤルを回す）

## 意味

- **craft の自己完結性テスト（審美込み・完全版）に合格。** まっさらな Fable が、レシピの言語と巻尺だけで、ユーザー満点水準の rigging を初見のパラメータ工程で完成させた——「2周目を1周目より上手くやるための記憶」が、コンテキストを跨いで機能することの実証
- 盲目エージェントが持ち帰った craft 曖昧点5件は全てレシピ06に反映済み（書き戻しループ）
