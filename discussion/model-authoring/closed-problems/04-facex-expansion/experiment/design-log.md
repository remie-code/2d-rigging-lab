# cp04fix — 前髪 FaceX の球面射影則による打ち直し（修正ラウンド）

開始 rev 108 → 終了 rev 110。ユーザー gate 判定「前髪の左右端付近が動きすぎる」への修正。
根拠: レシピ 06「球面射影則」（改訂済・最上位原理）。dx(点) = Δ · z_shell(点のx)、z_shell = ±√(R² − (x−cx)²)。

## 診断（なぜ線形ランプが違和感を生んだか）

旧 field の列プロファイル 0/0.4/0.8/1.0（線形）は face の内部比率の流用だが、face のそれは
「シルエット作り替えの圧縮 field」であり殻上のテクスチャ滑りではない。前髪に流用すると
limb（殻の縁）外にあるサイドの長い房（実測 x<790, x>1210 の帯）が avg 6.5〜15px 動いてしまう。
球面射影則では |x−cx| ≥ R_shell の点は z=0 = 完全凍結が物理。

## 殻ダイヤルの決め方（設計ログ義務項目）

正典からの逆較正で初期値を置き、目視で確定（イテレーション 1 で確定、追い込み不要だった）:

- **回転量 Δ の較正**: 目・遠側 25.5px（目中心 |x−cx|=85）と鼻 30px から。造作殻 R_feat=190 と置くと
  z_eye(85)=√(190²−85²)=170 → Δ=25.5/170=0.15 → z_nose=30/0.15=200（殻190+鼻の突出10。整合）
- **前髪殻**: R_hair = R_feat + Δr、層間差 Δr=10 → **R_hair=200**。中心振幅 = Δ·200 = **30 = 1.0T（ピーク不変）**。
  眼上 x=915 で前髪 25.9 vs 目 25.5 → 前髪がわずかに先行（外側の殻の読み）
- **cx=1001**（前髪 domain 中心 ≈ 顔正中線 1000）
- **縦方向**: 球頂 = 前髪最上端 y=143 → cy=343。cy より上は球断面 r(y)=√(R²−(cy−y)²)、
  cy より下は **円筒延長 r=R**（垂れ髪は付け根の並進を運ぶ。旧設計の「自軸回転円筒のシルエット不変」を
  下半分の断面として保持）
- 各格子点で field = 30·√(max(0, r_eff(y)² − (x−1001)²))/200 を点評価（gen-fix-hair.mjs）

# cp04fix2 — 前髪 FaceX の回転射影則（弦の式）による再構築（第2修正ラウンド）

開始 rev 110 → 終了 rev 113。ユーザー指摘①死帯（描画範囲内に全く動かない境界）②端の内向き縮みの欠落
③格子解像度（bezier ≠ transform、7×7 は粗い）への対応。根拠: レシピ 06「回転射影則」（最終形に改訂済み）。

> **dx(点) = u·(cosΔ − 1) + z(点)·sinΔ**（弦の式・有限回転）

fix1 の誤りは改訂レシピの「よくある誤り2つ」そのもの: 微分近似 dx=Δ·z + 単一球 ansatz R=200 →
|u|≥200 の房が完全凍結（幅 622 の素材に対し左右あわせ約 220px の死帯）。

## 格子の再作成（指摘③）

- `deleteRigControl`（rig_facex_hair_front 7×7 bezier2×2 を削除。keyform は自動除去、reject なし）
- `createWarpDeformer` で **transform 11×11 + bezier 11×11**（= transform、レシピ 06 改訂の格子解像度規則。
  7→9→11 の2段階細分）。domain は現行踏襲 x655 y135 w692 h638。displayName 同一 →
  導出 ID も rig_facex_hair_front を再取得（キー op がそのまま通ることで確認）
- `editKeyformKey createEndsCenter`（statePatches min/default/max、121 点 ×3）
- rest レンダは再作成後も fix-rest / final-rest と**バイト一致**（default キーの恒等性は delete→create を跨いで厳密）

## z プロファイルの設計（唯一の設計対象）

素材の**実描画幅全体**（x 690〜1312、u = x−1001 ∈ ±311）に z を割り当てる。球 ansatz は初期値に過ぎない:

- **z_phys(u,y) = U · shapeU(u) · s(y)**、U = 320（髪シェル半径。素材半幅 311 + 余白 → 素材内で z > 0、死帯なし）
- **shapeU(u) = 1 − (u/U)²（放物線）**。★球の √(1−(u/U)²) は limb で傾き無限大になり、
  区分線形格子で折り返し（fold）の危険がある（u=319 で d(dx)/du < −1 を実際に検算）。
  放物線は縁まで有限傾斜（端で −0.21）で、z>0 のまま滑らかに 0 へ向かう
- **s(y)**: y<463 は球冠 √(1−((463−y)/320)²)（頂点 = 素材最上端 y=143。頭頂は回転軸上でほぼ不動）、
  y≥463 は円筒延長 s=1（fix1 の「垂れ房は付け根の並進を運ぶ」を継承。赤道 = 目の高さ ≈ 頭部最広部）
- **ゲイン**: g = 30/(U·sin30°) = 0.1875。物理スケール（U=320 の球頭）で弦の式を評価し、
  正典 gain-1（中心ピーク 30px = 鼻と同期）へ一様乗算。展開形:
  **dx±(u,y) = −0.02512·u ± 30·shapeU(u)·s(y)**

### 弦の項の帰結（指摘②の解消）

- 弦の項 u·(cosΔ−1) は **cos が偶関数なので ± 両キーで同符号** → min/max は鏡像にならない
  （レシピ 06「+max と −min のオフセットは鏡像にならない」の髪での現れ）
- 端（z≈0）は弦の項が支配し **どちらへ向いても左右端が中心へ縮む**: ±30 とも幅 622 → 606〜610（約 2.5%）
- リーディング側の dx=0 等値線（+30 時 x≈1278 付近）は測度ゼロの曲線であり、fix1 の帯状凍結とは別物。
  完全静止頂点は存在しない（min |dx| = 2.2〜2.8px）

## 実測（inspectEvaluatedGeometry、242 頂点、rev 113）
