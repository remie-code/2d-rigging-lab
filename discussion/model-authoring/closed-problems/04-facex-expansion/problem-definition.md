# 閉問題 04: Face Angle X 展開（口・右目・両眉・前髪）— craft 追試験

> 2026-07-03 定義。閉問題03（最小核、盲目再構成で満点）の続き。**craft の追試験**として、二代目のクリーンコンテキスト Fable サブエージェントに委任する（ユーザー承認済み）。

## スコープ: 5要素、全て param_face_angle_x

| 要素 | 種別 | 内容 |
|---|---|---|
| 口（通常セット） | 反復 | メッシュ生成から。純平行移動クラス |
| 右目 | 反復（鏡像） | 既存の状態デフォーマ塔 `rig_eye_r_*` へ wrap 挿入。左目の鏡像 = 非対称言語の逆方向テスト |
| 左眉・右眉（通常セット） | 反復 | メッシュ生成から。顔表面造作クラス、左右非対称 |
| **前髪（本体のみ）** | **一段上** | 変形主体クラス（顔輪郭と同類）。ただし「隠れる縁は固定」が適用できない——**髪の縁はシルエットそのもの**。レシピ06の変形言語の一般化テスト |

除外: 房（hair_f_l/r）・耳・眼鏡・後ろ髪・帽子（揺れ・別問題クラス。以降の閉問題へ）。
