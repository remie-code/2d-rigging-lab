# 閉問題 05: FaceX 頭部外周（耳・房・後ろ髪）

> 定義日: 2026-07-03。選定はユーザーとの往復で確定（残り要素の列挙はユーザー、グルーピングと除外は Fable 提案 → ユーザー承認 + 較正3点 + 帽子の性質訂正）。

## 位置づけ

**回転射影則の未踏 z 領域3種への追試験。** 新法則の建設はゼロ想定——確立済みの式 dx = u·(cosΔ−1) + z·sinΔ に、まだ実証していない z 域を代入する問題。したがって本問題は同時に **craft（レシピ06）の完成度測定**を兼ねる（cp04 と同じくクリーン委任で回す）。

## 対象: 6要素

右耳 / 左耳 / 前髪の右房 / 前髪の左房 / 後ろ髪の右側 / 後ろ髪の左側

（drawable の特定は実行時に partId・レンダで行う。層構成が想定とちゃう場合はエスカレーション）

## 各要素の法則上の予測と要求品質（2026-07-03 ユーザー較正）

| 要素 | z 域 | 法則上の予測 | 要求品質 |
|---|---|---|---|
| 耳 ×2 | limb（u 大・z≈0）の初適用 | 弦の項が支配。移動はごく小さく、両耳とも内向きに縮む | 顔輪郭との整合 |
| 房 ×2 | limb 近傍の垂れ物 | 球冠+円筒延長（fix2 知見）の追試。既存の前髪 field と付け根で連続 | **付け根の位置精度は不問**（前髪に隠れる）。勝負は「正面→斜めに向いたときの見え方」= z プロファイルの層差という非決定論ダイヤルのセンス |
| 後ろ髪 ×2 | **z<0 の初実証**（レシピ06に記載はあるが一度も踏んでいない唯一の領域） | 逆方向移動 | **「それっぽく動いてればいい」**。毛先の品質は問わない（ユーザー自身も自作時に気にしていない）。本質は逆方向に流れることそのもの |

## 判断の所在（ゲシュタルト判定）

6要素は単独では判定がほぼ不可能（耳は数px、後ろ髪は縁しか見えない）。揃って初めて一発の問いになる:

> **頭が一個の塊として回っているか。顔面（04までの成果）と外周の境目が裂けていないか。**

- 後ろ髪の確認は高倍率 + sweep 前提（露出が狭い）。ただし上記の通り要求品質は緩い
- 【ユーザー gate】は複数要素同時 sweep のゲシュタルトで行う

## 除外事項

- **眼鏡・帽子** → 06 候補「アクセサリ」へ。両者とも**「回転する頭部に載る物体の追随・接続」というオブジェクト固有問題**を抱える:
  - 眼鏡 = 顔造作（目・鼻梁）の field への追随。ズレ = 物が浮く
  - 帽子 = **頭部との接続線の合わせこみ**。頭部側の縁は回転で大きく流れるため、接続線は座標変換だけからは生まれず視覚的な補正が必要（ユーザー言語化 2026-07-03）
  - いずれもモデル固有性が高く、craft 蒸留上 **optional** であるべき（追試験の母集団に混ぜない）
- 目・眉の遠側キーへの弦の項（04 の休眠提案）は本問題でも触らない。craft 完成後の通し確認で扱う（ユーザー決定）

## 成功基準

- **A（API）**: 新 API 不要の見込み。createWarpDeformer / editKeyformKey / inspectEvaluatedGeometry / renderView で足りる
- **B（ユーザー満足）**: 上記の較正済み品質での gate 通過（要素ごとに要求水準が異なることに注意——一様な満点を狙わない）

## 実行様式

- クリーン Fable 委任（cp03/04 と同じ封じ込め: `ref/`・`closed-problems/03-face-angle-x/` 文書・`01-eyeball-x/experiment/` アーカイブ・rigging ワークスペースの git 履歴/ブランチの遮断。委任文に答え数値なし）
- 設計ログ義務（z プロファイルの選定理由を要素ごとに言語化）
- エスカレーション権あり（層構成の想定外・既存 field との干渉など）
- 既存機能の回帰確認必須（04までの FaceX・目の開閉・眼球移動を合成レンダで）
