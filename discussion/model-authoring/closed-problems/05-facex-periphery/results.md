## この閉問題が獲得したもの（レシピ06へ反映済み）

1. **未踏 z 域3種の実証**: 耳 = z≡0（±両キー同一 patch、cos の偶性）/ 房 = 直上 field と完全同一式（層差0）/ 後ろ髪 = z<0 カーテン模型（U_spread は頭殻と別、弦の項は根本写像、左右分割素材は単一大域式）。**回転射影則は新法則ゼロで全域を吐いた**——craft の完成度測定として合格
2. **隠蔽維持拘束（振幅の上限則）**: rest で隠れている描き縁は全キーでも隠れ続ける。罠は二重苦（隠される側の流れ + 遮蔽層自身の弦縮み）。実装は s(y) と独立の乗数 q(y) ——絞りがワンノブになり gate 補正が updateCurrent 一括で済む
3. **同一モデル内拡張の作法**: 既存 field から物理枠（cx・U・Δ・g）を復元し z だけ設計する。モデル自身が唯一の較正基準（外部数値ゼロで整合が全自動）
4. **差動パララックス**: 隠れたパーツのチラ見えは「前髪がずれて受動的に露出」ではなく「逆方向の微小ドリフトとの差動」が生む——立体感の源泉
5. **素材と rig の相互作用の実例**: ユーザーの後頭部パーツ追加は、六代目の実測（静止カーテンすら前髪が覆えない行の存在）で**構造的必須**と裏付けられた。rigging が素材の欠落を露出させる——素材追加はユーザー側工程として自然に混ざる
6. 格子解像度規則の判断軸修正: 「domain の余裕」は代理指標で、真意は「素材の大きさ × field の曲率」

## 運用知見

- ユーザーが実験の合間に Editor で drawable を追加 → run-batch の manifest 自動追従で無事故。**Editor とヘッドレスの時分割共存は素材追加込みで成立**
- 委任文の新パターン「設計骨格（合意済み原理）を固定し、量の具体化を委任する」が機能（六代目）
