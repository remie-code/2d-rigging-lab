# 閉問題 06: FaceX アクセサリ（眼鏡・帽子）= FaceX の完結

> 定義日: 2026-07-03。選定はユーザー（「FaceX を閉じたい」）。設計原理2つはユーザーの実作言語化と Fable の推論の合流で合意済み。

## 位置づけ

**「回転する頭部に載る物体の追随・接続」クラスの初攻略。** この問題で param_face_angle_x の戦線を閉じる。

- 眼鏡・帽子はモデル固有性が高く、craft 上 **optional** であるべき（cp05 定義時のユーザー判断）
- したがって蒸留先はレシピ06ではなく**新規 optional レシピ 07（アクセサリ）**——06 は「どのモデルにもある顔の回転」の普遍レシピのまま保つ
- cp05 の残課題「back_top_hair 上端の帽子縁ゼロ絞りは帽子静止前提の暫定」を本問題で構造的に回収する

## 対象

- **帽子**（headwear）。**未メッシュ**（cp05 六代目の実測でレンダ不出を確認済み）——メッシュ生成からのフルコース
- **眼鏡**。drawable の特定・メッシュ状態の確認は実行時

## 設計原理（合意済み。量の具体化は実行エージェントの仕事）

1. **接続線では連続性が法則に優先する**（帽子）: 帽子の内部（前面・頂部）は回転射影則が支配するが、後頭部に接する縁の帯では**場の値は自分の z プロファイルではなく隣接層（頭部シルエット・後頭部層）から与えられる**。滑らかな接続 > 球面精度（ユーザー実作の言語化）
2. **剛体は低次場で近似する**（眼鏡）: 下地の顔造作 field を標本化しつつ、**平行移動 + 一様縮み程度のアフィン近似**に均して剛性を守る（ユーザー実作で確認: 「基本は平行移動＋縮み調整しかしてない」）。場の曲率をそのまま通すとフレームが有機的に曲がり「壊れた眼鏡」に見える。z = 顔造作層のわずか上（目の field にわずかな先行を乗せる——先行率・標本化則の親戚）
3. **帽子 rig に伴う境界条件の書き換え**: back_top_hair 上端を「静止 = 0」から「**帽子縁の場と式レベルで一致**」へ更新する（層の接続は式の共有で払う——房・後頭部に続く第3例）

## 判断の所在（【ユーザー gate】）

- 帽子: **後頭部との縫い目の滑らかさ**（接続線が裂けない・段差にならない）+ 頂部が塊として回るか
- 眼鏡: **剛性の維持**（フレームが曲がって見えないか）+ 顔への追随（浮かない・遅れない）
- 全体: FaceX 完結の通し sweep で頭部全体のゲシュタルト

## 成功基準

- **A（API）**: 新 API 不要の見込み（generateMesh / createWarpDeformer / editKeyformKey / 巻尺 / renderView）
- **B（ユーザー満足）**: 上記 gate の通過

## 除外事項

- Face Angle Y・口の開閉（次問題以降）
- 眼鏡・帽子の表示切替（着脱）や FaceX 以外のパラメータ

## 実行様式

- クリーン Fable 委任（封じ込め継続: `ref/`・03 文書・01 実験アーカイブ・rigging ワークスペース git 履歴の遮断、委任文に答え数値なし）
- 設計ログ義務・エスカレーション権・回帰確認必須（05 までの全機能）
- 蒸留は**新規レシピ 07** として craft/ へ
