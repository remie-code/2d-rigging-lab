## この閉問題が獲得したもの（→ 新レシピ [07](../../craft/07-volumetric-rotation.md) へ蒸留）

1. **ステッカー↔立体物のスペクトラム**（ユーザーの訂正で確立）: 隠面の出現はアクセサリという物のクラスでなく領域の性質。座席は領域単位で、同じ drawable 内で支配則が遷移する。房は立体寄り＝再走での正規適用対象
2. **技法6種**: シルエット縁 / 傾いた接続ループ（dz→dy）/ 立ち付属物の非対称錐断面 / 剛体の低次場 / 接触縁の所有権と差動従属（完全一致は上限であって最適ではない）/ 接続の連続性次数（G1 = rest 関節角の保存、相手は回転後の所有者）
3. **拘束台帳 = planning-gate の実体化**: palimpsest 条件（fix 2ラウンド以上 / 原理3つ以上重畳）で `Inventory first` を自動発火。全拘束を処置付きで委任し、保存行は assert で drift 検出。台帳は永続ファイルに住む
4. **人間仕上げ境界の初測定**: 「センスに見える課題」は原理の言語化で1回試す（G1 は勝ち、接触判断は不達）→ 不達なら人間領域。**Fable = 土台 / 人間 = 仕上げ**の役割分担で、費用対効果の目的は達成される
5. **人間補正後の機械再生成は禁忌**（台帳 C10）: 人間の手直し commit 以降、committed 現物が正典

## 運用知見

- **L0 の失敗モードの初記録**: 九代目の複合欠落はエージェントでなく L0 の計画失敗（recency 圧縮）。対策が台帳運用として恒久化
- Sylph（opus）の inventory は委任前提の誤りを指摘する品質を持つ——調査は「L0 の仮説の検証」まで含めて設計してよい
- 停止条件付き委任（一回勝負）が2連続で機能: 九代目 G1（勝ち）、十代目 λ 較正（1回で収束）
