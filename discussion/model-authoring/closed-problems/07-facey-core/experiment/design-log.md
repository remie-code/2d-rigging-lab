## 転置した物理枠

committed FaceX field から復元した gain-1 正典（cx=1001、Δ=30°、T=鼻30px、z単位: 鼻=320 ⇔ 30px @ zC=0.09375）を縦に読み替え:

> **dy±(点) = g·[v·(cosΔ−1) ± sinΔ·z(点)]**、v = y − cy、dx = 0 全点
> min（俯き、+y=画面下）が +z 項、max（見上げ）が −z 項。**弦の項 v(cosΔ−1) は cos の偶性で両キー同符号** → min/max は鏡像にならない（X と同じ帰結が縦にも出る）

## 上下非対称の言語化（本問題の craft 原料）

**何を**: ゲインを上下独立に置いた。**g_dn = 0.1875（X の gain-1 正典と同値。鼻 +29.4px）/ g_up = 0.15 = 0.8·g_dn（鼻 −24.5px）**。構造（z プロファイル・弦）は上下共通で、非対称はゲイン2値に集約した。

**なぜ**:

- **俯きがフル正典ゲイン**: うなずき・照れ・伏し目は Y の表現の主戦場。下方向は移動先に余地がある（口 +22 で顎縁まで残 28px）。「上品」の基準レンジ（鼻 ±30px 級 ≈ 頬幅10%）をそのまま縦に渡す
- **見上げは 0.8 に絞る**: (a) 見上げは**未描画領域（顎裏）を晒す**方向——絵が持っている以上の回転を要求すると嘘がバレる。(b) 眉・目が上へ行くほど静止した前髪の下に潜る——潜り自体は自然な演出やが、フルゲインだと目の上半分が房に食われて表情が死ぬ。(c) 人体としても顎を上げる可動域は俯きより狭い
- **見上げの読みはゲインでなく顎帯が担う**: 顎は z が縦断面の端で小さく弦が支配 → 俯きで +5.3px しか下がらんのに見上げでは −9.0px 上がる（弦と z が同方向に重なるため）。口が −20.6 上がるのに顎が −9 → **口-顎の間隔が 11px 開く = 顎裏が見えてくる読み**が式から構成的に出る。これが「見上げ=顎裏が効く」の実装形や
- 副産物の非対称: 眉は俯き +28.0（弦が加勢）/ 見上げ −18.4（弦が抵抗）。俯きでは眉が目 (+26.1) より先に降り、見上げでは目が眉を追い越す——顔面の「詰まり方」が上下で逆になる。これも偶性の帰結で、設計はしていない（法則が只でくれた）

## レシピ06の転置で足りなかった点・詰まった点（craft の転置可能性測定・正直な生データ)

1. **顔要素はクラスごと転置できない**。X の顔 = 「移動小・変形大・外周ゼロ固定」のシルエット再構成 field。この作法を Y に機械転置すると「上下縁ゼロ固定・内部流し」になるが、それは**誤り**: Y では (a) 顔の側縁は縦に滑ってもサイド髪の被覆内（隠蔽維持は縦滑りに対して構成的に安全）、(b) 額縁は前髪の奥深くで動いてよい、(c) 顎縁は**動かさなければならない**（Y の可視シルエットの主役）。結果、Y の顔は「殻上の皮膚流し + 顎の弦」クラスに移籍した。**「どの縁が固定か」は軸ごとに隠蔽関係を測り直す必要がある——レシピの縁規則は法則でなく X での実測結果やった**
2. **縦の殻は軸まわり非対称（V_up ≠ V_dn）**。X の横殻は ±U 対称で「赤道=目の高さ」の一行で足りたが、縦は軸（耳の高さ）が頭の縦中心より大きく下にある。上極（頭頂）は正典から取れるが、**下極（顎の巻き込み点）は X 正典のどこにも居らん**——テクスチャの顎縁実測 + 「顎下で面が裏へ回る」の目測で新規に置いた（y609。顎縁+32px）。転置には「下半分の極をどこに置くか」という新ダイヤルが1個増える
3. **ゲインの非対称が一級の設計対象になる**。X は ±1ゲインで済んだ（左右は役割交代で吸収）。Y は g_dn/g_up の2値が必要で、その比（今回 0.8）は演出ダイヤル。レシピ06の「ゲイン=一様乗算のスカラー1個」は Y では「方向別スカラー2個」に拡張が要る
4. **X の先行率正典（1.2/1.32）は素直に転置できない**。X の顔 field の値はシルエット再構成クラスの急な列テーパを含んでおり、先行率はその副産物。Y の顔は緩テーパの殻なので、単一の Z_face では鼻先行と目先行を同時に X の値に合わせられない（1.38/1.19 で挟むのが精一杯）。**先行率は「z の層差」の現れであって普遍定数やない——クラスが変われば数値も変わる**。gate で顔皮膚の追従が薄い/濃いと出たら Z_face が唯一のノブ
5. 詰まらなかった点（転置が効いた部分も記録する）: 弦の式そのもの・偶性による非鏡像・放物線 ansatz・格子規則（affine は 5×5 で厳密、曲率 field は 9×9）・「鼻から決める」ゲイン手順・wrapChildren の作法・隠蔽維持の考え方——**レシピ06の言語の8割は軸の読み替えだけでそのまま走った**。1D 問題としての FaceY は X より簡単ですらある（左右役割交代が消えるため）

## fix ラウンド: 下向きの要素内勾配（foreshortening）復元 — rev 230→234

### 診断の原理（L0-ユーザー合意——本 fix の設計原理。craft レシピ06転置ノートの原料）

**変位と縮尺の一致則**: 見る側は回転角を①要素間の変位（sinΔ 系）と②要素内の縮尺 = foreshortening（(cosΔ−1) 系）の両方から読む。ゲイン g は変位を線形に縮めるが cos 系は g 倍で知覚の下に沈む——実測: 目開口の縦縮みは g·(1−cos30) = **2.5%**（eyewhite-l 56.0→54.6px）しかなく、知覚不能。一方顎・口の変位は 30° 級の首折れを語っていた。**縮尺は「ゲイン後の角度」でなく「変位が語る角度」に合わせる**: 幾何アンカーは 1−cos30 = 13.4%、演出ダイヤルは 10% 級から。

実装: min キー（俯き）のみに加算の線形勾配 **ddy(y) = SQUASH·(YREF − y)**、SQUASH = 0.10、YREF = rest の白目中心（L y439 / R y448、巻尺実測）。

- **YREF を開口中心に置く理由**: 平均変位を保存する（ユーザー承認済みのゲシュタルト振幅を変えない——潰しは開口中心の周りに分配される）
- 格子は 5×5・勾配は y の一次 → bilinear 厳密、分解能問題なし。dx 不触（Y回転は縦の営み）

### 下向きキーの同定根拠

y-min30 レンダ = 造作が下降・眉が前髪の下に現れ・顎が下がる = 俯き。y-plus30 = 造作上昇・顎裏帯が開く = 見上げ。**min = 俯き**（十一代目の設計と一致、レンダで再確認）。

### 勾配の向きの導出（言語化義務）

「上端と下端のどちらを多く動かすか」を独立な2経路で導出し、一致を確認した:

1. **顔殻の局所勾配**: 読み取り角強度での縮尺 = (cos30−1) + sin30·dz/dv。目の位置（v≈−20、V_UP=316、u テーパ後 Z≈228）で dz/dv = +0.11 → 傾き負 = **上の点ほど大きく下がる**。殻項（+5.5%）が弦項（−13.4%）を部分相殺し、物理は ~8% を指す——10% ダイヤルの直下に座る
2. **X 規則の転置**: limb 側（下 = 顎の巻き込みで z→0 に向かう側）の端点が小さく、軸/中心側（上）の端点が大きく動く——X の「縁側 0.25T / 中心側 0.65T」の縦読み
3. 絵の自然さ: 上端が多く下がる = **上まぶたが押し下がる伏し目**。逆向き（下端が迫り上がる）は「見開いたまま縮む」不自然になる

### craft への指摘（レシピ06転置ノートの原料）

1. **「要素内勾配」は演出でなく法則の半身**: X の 0.65T:0.25T 勾配は「横縮みの演出」と読めるが、実体は**弦の項 (cosΔ−1) を読み取り角強度で入れる**行為。転置チェックリストに「各要素の要素内縮尺が (1−cosΔ) 級か」を入れるべき——ゲイン分離（構造×ゲイン）の罠: **ゲインは sin 系（変位）にだけかけてよく、cos 系（縮尺）にかけると知覚から消える**。レシピ06の「field = 構造 × ゲイン」は「変位 field = 構造 × ゲイン、縮尺 field = 構造のまま（読み取り角強度）」に精密化が要る
2. **標本化則は勾配にも及ぶ**: 眉 = 目 field の標本化、は 0次（変位）だけでなく 1次（勾配）にも適用する。片方だけ入れると間隔が逆に開き、fix 前より悪化する（実測 +4.5px）
