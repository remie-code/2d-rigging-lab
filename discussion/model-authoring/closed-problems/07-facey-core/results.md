## 獲得（レシピ06へ反映済み）

1. **craft の転置可能性の実測**: レシピの8割が軸読み替えで走った。折れた2割は「実測由来の規則（軸ごと再測）」「縦殻の軸非対称」「方向別ゲイン」「先行率のクラス依存」
2. **変位と縮尺の一致則**: ゲインは sin 系（変位）にのみ。cos 系（縮尺）は読み取り実効角の強度で。X の 0.65:0.25 勾配の正体 = 弦の項の半身
3. **標本化則の1次拡張**（眉は目の勾配も標本化）+ **平均変位保存アンカー**（gate 済み振幅を壊さず縮尺を足す合成則）
4. ポリシー確立: 1デフォーマ=1パラメータ責務、対角は Runtime 責務（設計対象外・監視のみ）
