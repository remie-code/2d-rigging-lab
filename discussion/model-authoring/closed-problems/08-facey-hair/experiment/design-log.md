## 重力減衰プロファイル W(y) — 本問題の核心（craft 原料）

**原理（ユーザー言語化の実装形）**: 付け根付近は頭に追従するため球面理論が勝つ。毛先はもう球面の移動ではなく重力が支配的になる。W は**変位全体**（弦の項も含む）に掛かる——ぶら下がった毛先は頭の何にも追従しないため、z 項だけ殺して弦を残すのは誤り（弦だけ残すと v の大きい毛先が「軸に向かって吸い上がる」非物理が出る)。

**境界の置き方の言語**:

> **境界の始点 = その毛束が頭蓋との接触を失う行**（頭は触れている毛しか押せない）。**遷移距離 = その下に垂れる自由長に比例**（長い振り子ほど順応を長い距離に分配する）。

| 要素 | W(y) | 境界の根拠 |
|---|---|---|
| 前髪 | y≤500 → 1、500..773 で smoothstep → **0.7**（下限） | **接触を失わない**（額・こめかみに貼り付く = 顔に律則）。境界なし、毛先の軽い減衰のみ。中央の房（目の上 y430-500）は W=1 でフル追従——眉 (+28.0)・目 (+26.1) の直上を前髪 (+27〜31) が数px 先行で滑走（外殻の物理、cp06fix3 λ の縦版が構成的に出る） |
| 房 L/R | y≤550 → 1、550..900 で smoothstep → **0** | 顎ライン y~577 で頭のシルエットを離れる → 境界 550。自由長 ~400px の大半（350px）を遷移に使う。毛先（y900+、肩・胸に着地）は完全静止 |
| 後ろ髪 L/R | y≤500 → 1、500..1000 で smoothstep → **0** | 襟足 y~500 で頭蓋を離れる → 境界 500。最長素材（毛先 y~1800）= 遷移距離も最大の 500px。肩甲帯 y1000 で完了し、腰までの質量は一切動かない——「毛先は垂れたまま」のゲシュタルトの実体 |

- 減衰が作る縦の伸縮（付け根 ±20px、毛先 0）は素材長に対し ~4% で歪みとして知覚されず、かつ**これ自体が髪の「要素内縮尺」として角度を語る**——cp07fix の一致則（縮尺は変位の語る角度に合わせる）は髪では重力勾配が構成的に払う。追加の foreshortening 項は不要と判断した
- 弦の帰結: 頭頂（z→0 の極近傍）は両キーとも**下がる**（v(cosΔ−1) は偶）。min で前髪上端 +8、max でも +6 下がる = 見上げで頭頂が奥へ畳まれる読み。帽子（Y 未 rig の静止物）の裏で起きるので隠蔽も只で成立

## craft への指摘（レシピ06/07 転置ノートの原料）

1. **重力減衰 W(y) は「垂れ物の Y 応答」の新テンプレ**: X の垂れ物則（円筒延長 s=1 = 付け根の並進を毛先まで運ぶ）は Y では**真逆**になる——Y は変位方向が垂れ方向と一致するため、運ぶのではなく減衰させる。「境界 = 頭蓋接触を失う行、遷移距離 ∝ 自由長、W は変位全体に掛ける（弦含む）」の3点で言語化できる。X の s(y)（殻の縦断面）と Y の W(y)（重力）は**別物として直交に掛かる**——s は z の形、W は追従度
2. **q(y)（隠蔽絞り）は軸ごとに要否を測り直す**: X で必須だった付け根 1/6 絞りは Y では不要だった（遮蔽層が縦に長く、縦滑りは遮蔽の内側に収まる）。「隠蔽維持拘束は縦プロファイルと独立の乗数」（cp05fix）の続き——**独立だからこそ、軸転置で外せる**。殻に混ぜていたら Y の振幅が理由なく 1/6 になっていた
3. **「同じ殻を別の軸で読む」が転置の基底**: X 実装の z(u,y) をそのまま Y の sinΔ 項に差すだけで、層順・ゲイン整合・左右 seam 連続が全部引き継がれた（左右分割カーテンの単一大域式も、そのまま Y で seam 連続を保証した）。素材の殻は一度設計すれば軸の数だけ再利用できる——「殻の設計は軸横断の資産」とレシピに書ける
4. **剛体の低次場は軸転置で本当に未知ゼロだった**（追試成立の報告): 標本化アンカーを「その軸で剛体が乗り続けるべき点」（Y では白目中心 = squash の平均保存点）に置き換えるだけ。gained 弦を維持する判断（モデル世界線との整合 > 単体の読み取り角強度）も X と同じ理屈で通る。残差 0.003px 級の機械検証もそのまま効く
5. **後頭部層の Y は「カーテン式 × 上下ランプ」一本で書けた**: X（cp05fix の z 式 + cp06 の帽子式上端）より単純。理由は帽子が Y 未 rig でランプ上端が 0 に固定されるため。cp09 で帽子 Y が入るとき、上端行の書き換え（式共有の作法: マスター=帽子、受け手=btr/btl 最上段）が必要になる——**cp06 の「暫定が閉じる」手順の Y 版を予約**
6. 実行系メモ: keyformSet の識別子 (target, parameterId) は**一意でない**（開閉塔は opacity と offsets の2セットが同居）。snapshot 照合は位置対応で行うこと。また re-parent は rig-controls の property 順序を変えるため、不変 assert は canonical JSON（キーソート）で比較する

### 実装した式

> **field(u,y) = W(y)·球面場(u,y) + (1−W(y))·球面場(u, y_root(u))**

- 重力減衰は「動きの消滅」ではなく「**回転性の消滅**」。球面場を並進（付け根が運ばれる分）と回転性（Θ 依存の振り回し分）に分けると、W が絞るのは回転性のみ。毛束は付け根に付いている以上、並進は毛先まで運ばれる——毛先の極限 = 自分の付け根の変位のコピー（純平行移動）
- **恒等式 field_new − 球面場(root) = W·(球面場 − 球面場(root)) を assert D で機械確認**——「W(y) は回転性成分の混合比」の実装形そのもの
- W(y) の境界・遷移距離・殻・ゲイン・格子・domain は十三代目の値を**全部保存**（assert A: committed 現物が旧式と一致 = 開始状態の完全性。assert B: 付け根帯 y≤yHead が修正前後で byte 一致）
- 前髪（wTip=0.7）も同型に統一: 尾部の 0.3 の減衰分が「ゼロへ」ではなく「自列の y500 の場の値へ」収束。顔律則でほぼフル追従だから差は小さい（tail 実測 min +12.2→+15.0）が、式の型が全要素で一本化された

### y_root(u) の取り方

十三代目の W 境界（= その毛束が頭蓋との接触を失う行）をそのまま流用: 前髪 500 / 房 550 / カーテン 500。境界行は要素ごとに1本（房・カーテンの付け根はその高さの水平帯に並ぶ）だが、**各列は自分の列の球面場の値 球面場(u, yHead) をコピーする**——運ばれる並進量は殻を通して列ごとに変わり、境界行だけが共有される。列ごとの実測は不要だった（形状と噛み合う。エスカレーション不要）。

### craft への指摘（fix 由来の追補——初版 craft 指摘 1. の訂正）

1. **「付け根の並進を運ぶ」は軸横断の不変量**: 初版 craft 指摘 1. の「X では運ぶ / Y では減衰させる、真逆」は誤りだった。X の円筒延長則（垂れ房は付け根の並進を運ぶ。球で減衰させると裂ける）は Y でもそのまま成立する——垂れ物はどの軸でも「付け根の並進 + 減衰した回転性」。軸で変わるのは回転性の中身（X=横振り、Y=縦振り）だけ。減衰の収束先を空間ゼロにすると「見えない杭」（Y）/「裂け」（X）という別の絵で同じ誤りが露出する
2. **W(y) は回転性成分の混合比であって変位の減衰率ではない**: 実装形は field = W·球面場(u,y) + (1−W)·球面場(u,y_root)。恒等式 field − root = W·(球面場 − root) が「W が絞るのは回転性のみ」の機械検証になる。初版の「W は変位全体に掛ける（弦含む）」は、正しくは「回転性の定義に弦の差分も含まれる」と読み替える——y_root の弦は並進として残る
3. **y_root は W 境界の再利用で足りる**: 「頭蓋接触を失う行」は減衰の始点と並進コピーの標本行を兼ねる（同じ物理的意味——そこまでは頭が運ぶ）。列ごとの境界実測は素材が水平帯の付け根を持つ限り不要。運ばれる量の列変化は殻が自動で払う
4. **下流参照の格子は「参照先の帯」で要否を測る**: back_top_hair は「付け根帯しか見ていないはず」が思い込みで、格子が遷移帯を跨いでいた。式共有（マスター=カーテン、受け手=bt）の受け手は、マスターの式が変わったら**格子の全行で差分 assert してから**裁定する（assert C の型）。式レベル同期はブレンド修正を自動で継承した（R·curtain の形が保存されるため）
