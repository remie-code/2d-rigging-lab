# 閉問題 08: FaceY 髪系 + 眼鏡（重力干渉の初攻略）

> 定義日: 2026-07-04。選定はユーザー承認済み。planning-gate 実施済み（L0 コンテキスト十全判定。rev 175→216 の空白はユーザー確認により「帽子の手動補正のみ」と判明——構造変化なし。Editor のリビジョン計数は人間作業で爆増する性質があり、rev 差分の大きさは構造変化の証拠にならない）。

## 位置づけ

**重力と球面理論の初めての干渉。** これまでの全 rigging は重力に反する仕事が発生しなかった（X の変位は垂れ方向と直交、顔パーツは顔に律則されて重力に勝つ）。FaceY の髪は**部分部分で支配則が異なる**:

> **付け根付近は頭に追従するため球面理論が勝つ。毛先はもう球面の移動ではなく重力が支配的になる。**（ユーザー言語化 2026-07-04）

**【2026-07-04 gate 訂正——減衰の正しい意味】** 重力減衰は「動きの消滅」ではなく「**回転性の消滅**」である。球面場は並進（付け根が運ばれる分）と回転性（Θ 依存成分——剛体回転なら毛先ほど振り回される分）に分けられ、重力が殺すのは回転性だけ。毛束は付け根に付いている以上、**並進は毛先まで運ばれる**。毛先の極限は静止ではなく「自分の付け根の変位のコピー = 純平行移動」:

> `field(u,y) = W(y)·球面場(u,y) + (1−W(y))·球面場(u, y_付け根(u))`

収束先を空間ゼロにすると「毛先が見えない杭に捕らわれる」絵になる（初版で実際に踏んだ。誤訳の出所は L0 の定義文「変位→0」）。これは X の円筒延長則（「付け根の並進を運ぶ。球で減衰させると裂ける」）の双子であり、**「付け根の並進を運ぶ」は軸横断の不変量**。W(y) が制御するのは回転性成分の混合比のみ。

新しい未知 = **重力減衰プロファイル**（回転性がどんな形・どんな距離で消えるか）。ここは感性が求められる領域——「骨格固定・量は委任 + gate でダイヤル」の型で解く。

## 転置・継承する正典

- cy = 459 / ゲイン: 下向き 0.1875・上向き 0.15（cp07 committed 現物から実測復元。外部数値の持ち込みなし）
- **変位と縮尺の一致則**（cp07fix）: ゲインは sin 系（変位）にのみ掛ける。縮尺（cos 系）は読み取り角の強度のまま
- 隠蔽維持拘束・格子規則（素材の大きさ×field 曲率——髪は縦に巨大 + 減衰勾配が強い = 縦に細かい格子）
- **X キーは一切触らない**（wrap のみ）。帽子（人間補正 C10）不触

## 判断の所在（【ユーザー gate】）

- 縦 sweep で「**髪が頭と一緒にうなずぎ、毛先は垂れたまま**」のゲシュタルト
- 毛先の品質は cp05 較正を継承（「それっぽく動いてればいい」）
- 眼鏡: レンズが目に乗り続けるか（±20px 外れの解消）
- 減衰プロファイルの形・距離 = 演出ダイヤル（gate で較正）
