## 転置した物理枠

> **dy±(点) = g±·[v·(cosΔ−1) ± sinΔ·z(点)]**、v = y−459、**dx = 0 全点**
> X の傾きループ例外（dy=−k·u·sinΔ）に **dx の双子は存在しない**——pitch 回転は y-z 平面の営みで、ループの傾きが結合する先（dz→dy）は一般式の z 項に最初から含まれている。「X回転は dy≈0 の例外 = 傾いたループ」に対し「Y回転は dx=0 に例外なし」が転置の答え

z は「同じ 3D 面を別の軸で読む」（cp08 知見3）: cp06 の帽子殻 z(u,y) をそのまま sinΔ 項に差した。ただし**1点だけ軸固有の張り替え**が要った（下記「凍結の分解」）。

## 新未知1: クラウン頂面の出現（面の交代の Y 版）

**X の凍結帯（C3、y<170 で s=0.585 固定）は Y では誤り。** 凍結は「立ち付属物が横回転で付け根に遅れない」ための X の装置。Y でこれを転置すると頂部の z が大きいまま残り、帽子全体が一様平行移動（ステッカー）になる。Y の正解は**真の縦断面** sTrue(y)=√(1−((463−y)/371)²)——極 y92 で z→0:

- min（俯き）: 極の行は弦のみ（+9.2）、額帯は弦+z（+30.6）→ **クラウンが縦に開く**（頂点-縁の間隔 実測 +12.3px）。行別の縦縮尺 = g((cosΔ−1)+sinΔ·dz/dv) が頂部で +5〜6%/行の**伸び**——素材の間隔が開くことが「見えなかった頂面が見えてくる」の実装形（X の「遠側で柄の間隔が開く」の縦版）
- max（見上げ): 極は偶の弦で**下がり**（+7.4）、額帯は上がる（−17.4）→ 間隔 −17.2px = **頂面が奥へ畳まれる**。cp08 で髪に観察された「頭頂の畳まれ」と同じ帰結が帽子でも構成的に出る

**C3 の分解（craft 転置ノートの原料)**: X の凍結帯は Y では3つに分解される——(a) ドーム/スラック = 真の縦断面（頂面の出現の源）、(b) 耳 = コーン z が y にほぼ定数 = **付け根並進の運搬そのもの**（凍結の役割を z プロファイルの形が担う）、(c) 前傾の読み = 明示の縮尺項（下記）。「凍結」という一つの装置が、軸を替えると3つの別の顔になる。

### C4-Y: 係留先の選定（Y 転置の最重要判断）

レシピ07 技法1 の言明は「係留先 = **頭部シルエット所有者と同じ式**」。X ではそれが後頭部層の X field（弦+微小 z<0）だった。Y で同じ occiput 縮約を転置すると帽子の縁は弦のみ（+8〜10）となり、**ノッチ接合部（y300-330）で直下の房シルエット（committed Y field、+20〜24）から 15px 級に取り残されて輪郭が裂ける**。この世界線（cp07/08 で3度 gate 済み）では、頭部シルエットの Y 挙動の所有者は「ほぼ静止する球の輪郭」ではなく**前髪/房の殻 field そのもの**（頭全体が gained 並進で頷く絵）。よって係留先 = z_fh（EQ463/R320 の頭殻）。

- 帰結1: ノッチで房シルエットと構成的に連続（同じ式）
- 帰結2: 内部（帽子自前の外殻 R371）は縁よりわずかに大きく動く——**縁を素材が通り抜けて下へ流れる**（実測: y235 で縁 +18.5 / 内部 +29.3。レシピ07 の「縁と中身の相対運動」の縦版）
- 教訓: 「シルエット所有者と同じ式」は軸不変の言明だが、**所有者が誰か・その式が何かは軸ごとに答えが変わる**（X=occiput 縮約 / Y=前髪殻）。「絶対静止に係留するな」の警告は Y では「球の輪郭不変性に係留するな」と読み替わる

## craft への指摘（レシピ07 転置ノートの原料）

1. **「面の交代」の Y 版は追加装置ゼロで出る——ただし凍結を外すこと**: X の技法3（凍結帯）は横回転専用。縦回転では真の縦断面 z(y)（極で 0）そのものが頂面の出現（sinΔ·dz/dv の行別伸縮）を生む。転置チェックリスト: 「凍結・付け根運搬系の装置は、回転面に対する付属物の向きで要否が反転する」
2. **傾いた接続ループの結合項は回転面と同一平面では消滅する**: dy=−k·u·sinΔ は X 固有。Y では縁の前後非対称（楕円の開閉）は各点 z の差が一般式経由で自動供給。「例外則は軸の直交性の産物」であり、転置時は式を持ち込む前に「その結合は今の回転面で幾何的に存在するか」を問う
3. **「シルエット所有者と同じ式」の所有者は軸ごとに再同定する**: X の occiput 縮約を Y に機械転置すると輪郭が裂ける。gate 済み世界線では Y の頭部シルエットは前髪殻 field が所有していた。係留という技法は軸不変、係留先は軸依存
4. **一致則は「変位が語る角度」の側で上下非対称まで貫ける**: 縮尺ダイヤルを SQ_DN=10%（30°）/ SQ_UP=6%（実効 23.6°）と分けると、g_dn/g_up の演出非対称と縮尺が矛盾しない。逆に**ピボット要素（耳）は変位が角度を語らないので squash 適用外**——一致則の対偶
5. **境界行の打ち直しは「境界値を運ぶランプ」に一般化できる**: 受け手の格子に描き縁の行がない場合（マージン付き格子）、マスター式の点評価を H(y) ランプで運ぶ。H の台は「マスターの物理的把持域」（帽子=素材下端）で切り、受け手の保存すべき帯（junction）の手前で 0 に落とす。「全行 diff を出してから裁定」（cp08fix assert C の型）とセットで
6. λ 差動（技法5）は**接触対ごとに1回較正すれば軸を跨いで流用できる**（同じ殻差・同じ知覚目標）。Y での再較正は不要だった
7. レシピ06 格子規則への追記候補: wrap 用に domain をマージン拡張したら、**分割数を上げて物理ピッチを保存する**（X 13×13 → Y 15×15。ピッチが 17% 粗くなると耳稜線から列が外れた）
