# 閉問題 09: FaceY 帽子 + 耳（FaceY 完結）

> 定義日: 2026-07-04。選定はユーザー承認済み。cp07（顔面コア）・cp08（髪系+眼鏡）の通過を受けた FaceY 最終ラウンド。通過後は FaceY フェーズ蒸留（07〜09 の獲得を craft へ一括焼き込み）。

## 位置づけ

**Y における立体物の本丸。** 帽子は X より Y の方が過酷——レシピ07（立体物の回転表現）の技法群が軸転置に耐えるかの本気のテストになる。

新しい未知:

1. **面の交代の Y 版**: 俯くと**クラウンの頂面**が見えてくる（X の「側面チラ見え」より劇的）。縁ループは傾いたまま画面内で回り、**下縁の弧の曲率そのものが変わる**（俯き = 縁の楕円が開く）
2. **dz→dy 結合の Y での姿**: X で dy を生んだ縁の傾き k は、Y では回転面と同一平面に入る——縁の前後で dy が大きく非対称になるはず
3. **人間補正済みの場の上に新パラメータ層を重ねる初例**: 帽子の X キーには人間の視覚補正が入っている（06 の constraint-ledger.md **C10**——機械再生成禁忌）。Y 層は wrap するだけなので物理的には安全だが、「X の生成器式は現物を記述していない」前提で設計する作法の初実践

## 対象

| 要素 | 内容 |
|---|---|
| 帽子 | rig_facex_headwear を wrapChildren（FaceY が親）。クラウン球冠の縦断面 + 頂面の出現 + 縁ループ + 猫耳（立ち付属物の Y = 俯きで前傾・縦縮み） |
| 耳 L/R | rig_facex_ears_l / _r を wrap。**cy=459 は耳中心とほぼ一致 → v≈0 でほぼ不動が正解**。ただし死帯禁止——微小変位は入る（「動かないことが正しい」の検証を兼ねる安い同梱） |
| back_top_hair 上端の回収 | cp08 の暫定（帽子静止前提の上端ゼロ絞り）を「**帽子 Y の場と式レベル一致**」に書き換える——X で実証した暫定→回収パターンの Y 版履行 |

## 継承する正典

- cy=459 / ゲイン: 下向き 0.1875・上向き 0.15 / dx=0（cp07 正典）
- 変位と縮尺の一致則（cp07fix）・付け根並進の軸横断不変量（cp08fix）
- 帽子の X 殻・W(y) シルエット半幅・猫耳フットプリント（cp06 生成器は設計知識としては有効。**ただし X キー現物との一致は仮定しない**——C10）

## 判断の所在（【ユーザー gate】）

- 俯き/見上げで帽子が頭蓋に張り付いて回るか（頂面の現れ・縁の弧の変化・猫耳の前傾）
- back_top_hair 縫い目（回収後）が裂けないか
- 耳が浮かないか
- **FaceY 完結の通し sweep**——全要素が揃った最終ゲシュタルト（cp07 で「よくわからない」だった判定が、全証言者の出席で締まるはず）
- X 同様、帽子は人間仕上げ境界が発動する可能性を織り込む（Fable=土台で十分成功）

## 除外事項

- 対角品質（Runtime 責務ポリシー継続。監視レンダのみ）
- FaceY 以外の新パラメータ

## 成功基準

- **A**: 新 API 不要の見込み
- **B**: 上記 gate + 回帰無傷（rest / X / cp07・08 の Y / 開閉、バイト一致。**帽子 X キーのバイト不変が最重要 assert**）

## 実行様式

クリーン Fable 委任（封じ込め継続）、設計ログ義務（頂面の出現と縁ループの Y 挙動の言語化——レシピ07転置ノートの原料）、エスカレーション権、目視イテレーション予算（帽子1回・他1回）。
