## 物理枠（新設——BodyX の正典）

> **dx±(点) = weight(y) · G_B · (chordC(u) ± SIN·zT(u))**、u = x − CX_B、dy = 0 全点
> chordC(u) = clamp(u, ±U_T)·(cos30°−1)（帯域外は変位クランプ = 平行移動の継続）
> zT(u) = Z_T·max(0, 1−(u/U_T)²)（放物線 ansatz、帯域外 0。**縦プロファイル無し** = 胴は縦円筒。縦構造は全て要素別 weight が担う）

- **CX_B = 997**（脊柱軸。テクスチャ alpha 重心の実測: シャツ 997.3 / スカート 994.6 / 首 994.7。**顔の cx=1001 と 4px 差で「ほぼ一致」の予言どおり**——だが胴体自身の実測を採用）
- **U_T = 215**（シャツ最大描画幅 429 の半分）、**Z_T = 150**（胸郭は楕円: 0.7·U_T のダイヤル。頭が Z=U=320 だったのは頭蓋が丸いから）
- Δ = 30°（射影角は顔と同じ。**「浅い」はゲインで作る**——角を変えない）

## 肩ゲイン S の決め方（新正典——FaceX の鼻に相当）

**S = 10px = 胸前面（肩帯中心 u=0）の振幅** → G_B = S/(SIN·Z_T) = 10/75 = **0.13333**。

- 「浅い」の実装: S/鼻 = 10/30 = **1/3**。ゲイン比では G_B/G_FACE = 0.711 だが、Z_T(150) < Z_鼻(320) のため**語られる変位は 1/3**——浅さは「ゲイン比」でなく「変位比」で読むこと（craft 指摘4）
- 一様ゲイン（gained chord、モデル世界線 cp07/08/09 と同じ）で開始。α² 縮尺補正は gate 指摘時のみ（問題定義の裁定どおり）
- 弦の偶性 → min/max 非鏡像: シルエット両肩角（u≈±212、z≈0）は**両キーとも同符号**（limb クラス、耳と同型）。「肩の振幅」の定義点は胸前面であってシルエット角ではない（角は ±3.8 の微動）

## 頭部同調ゲイン α の導出（cp11 の正典——本問題で言語化義務）

**α = 0.6**。導出は S からの連続性（頭は首に載って運ばれる = 接合点で変位連続）:

1. 首は襟の並進を運ぶ。胴の場の襟中心値 = G_B·SIN·zT(0) ≈ **10.03px**（=S）
2. committed FaceX 顔 field の顎接合行 (995, y577) を巻尺（bilinear）で実測 = **±16.47px**（gain-1 正典の顎スパイク。min/max 鏡像だった）
3. **α = 10.03 / 16.47 = 0.609 → 正典 0.6**（クリーンなスカラー。0.2px の継ぎ目残差は首の H ランプが吸収）

意味: BodyX max で cp11 の頭は「FaceX の 0.6 倍」で動く——鼻 18px は胸 10px より**大きい**が、これは同じ捻りでも鼻の半径(320)が胸(150)より大きいことの帰結（剛体寄りの運搬 + 首のわずかな吸収）。「浅い同調」は FaceX 比 0.6 のこと。生成器 assert ALPHA が顎実測と α の整合を毎回機械確認する（drift 検出）。

## 腰ピン拘束の実装形（本問題の核心。craft への新境界条件クラス）

> **field_shirt(u,y) = P(y) · sph±(u) + (1−P(y)) · field_skirt(u)**、field_skirt ≡ 0（スカートは static・未 rig）

- **「縫い付けアンカー」は重力テンプレの上下逆 + 収束先がアンカー衣服の場**。cp08fix の教訓「収束先を空間ゼロにするな」はここでは**適用されない**——裾は物理的に static な物体（スカート）に縫われており、ゼロ収束が正しい。毛先（自由端）と裾（縫い付け端)の区別が本質。スカートがいつか rig されたら、アンカー値はその場のコピーに置き換わる（式が既にその形）
- **アンカー行の決め方**: Y_PIN = **1124** = スカートの最初の幅広描画行（ウエストバンド上縁、テクスチャ実測 y1119..1124）。シャツの幅広部はちょうどそこで終わる（y1117 の w405 → y1145 までに w71 の尻尾に崩落）——「イン」は作画で表現されており層の重なりではない。よって**裾行は描かれたウエストバンドに正確に接着** = P(裾)=0 厳密（格子最下行が y≥1124 で全列 0 を assert PIN で機械確認）
- **勾配の形**: P = 1（y≤700 肩帯 = フル回転場）→ smoothstep で 0（y1124）。C¹ なので縦の折れなし、裾接近は勾配ゼロで滑らか。実測: 肩帯中心 −9.9/+9.2 → 胸 −3.4/+3.6 → 腰上 −0.2/+0.2 → **裾 0.0/0.0、スカート全 308 頂点 0.0**——「肩から上が回り、腰は留まる」の数値実体

## ネクタイ = リボンの運搬

sph±(u) は y 非依存 → 付け根運搬のブレンドは恒等になり、**tie field = sph±(u) そのもの**（一様運搬）。ネクタイは襟にだけ結ばれた自由リボン——先端（y1199、ウエストバンド上）は結び目と同量 ±10 で滑走し、ピン留めされたシャツ裾・static スカートの上を横に滑る。**腰ピンとの矛盾は無い**（縫われていない物は留まらない——エスカレーション条項は発動せず）。弦はそのまま（物質縁、幅 100px で ±0.9px の微差動）。実測: 結び目 −9.9/+9.8 → 先端 −9.7/+9.9 ✓。襟帯ではシャツと式共有（同じ sph±）なので結び目が襟に構成的に乗り続ける。

## 腕 = 付け根並進の運搬 + 薄い面の交代

> **field_arm(u,y) = W(y)·sph±(u) + (1−W(y))·D±_arm**、D±_arm = sph±(u_anchor)

- **運搬値は「肩アンカー1点の場」であって同列の場ではない**（cp08fix の列コピー則の適用限界を1つ発見: 毛のカーテンは縦素材で全列に付け根があるが、**腕は斜行素材**——指先の列 (u≈−450) には付け根素材が無い。列コピーだと指先が弦クランプ値に捕まる。振り子の付け根 = 肩点 (−157,700)/(+162,700)（袖山重心の実測）の場を腕全体へ運ぶ）
- W(y): 1（y≤760 袖山が肩を掴む帯）→ smoothstep → 0（y1150。自由長 ~830px → 遷移 390px、∝則）。恒等式 field−D = W·(sph−D) を assert CARRY で機械確認（回転性混合比の型）
- **薄い面の交代は sph±(u) が只でくれる**: W=1 帯で内縁（zT 大）が外縁（弦のみ・偶）を追い越し、近側の袖は広がり遠側は縮む。実測（右腕胸帯）: 内縁 −4.1/+8.6 vs 外縁 +3.1/+4.3 → max で +5.7px 広がり / min で −7.4px 縮み——体積物の微小幅変化が設計どおり
- 実測の運搬: 右腕 袖山 −1.5/+6.9 → 手 −1.9/+7.5（=D_r −1.86/+7.47 に収束）、左腕 対称役割交代 ✓。腕とシャツは肩帯で**同じ sph± を使う** → 縫い目の差動はゼロから始まり、下方でも 3px 級（シャツはピンへ、腕はアンカーへ収束する差——物理として正しい: 布は腰に縫われ、腕は肩から垂れる）

## 首 = 接続要素（H ランプ = 境界値を運ぶ）

> **field_neck(u,y) = H(y)·α·Xface±(u, y577) + (1−H(y))·sph±(u)**、H = smoothstep(y549→1 / y666→0)

- 上端値 = **committed FaceX 顔 field の顎行を live サンプリングして α 倍**（cp08 眼鏡の標本化と同じ型 + cp09 の H ランプ）。下端 = 肩の場と式共有（問題定義の裁定どおり）
- **neck + neck_back を1デフォーマ2子で** = 前後の首皮膚が構成的に同場（1要素×1パラメータ=1層の「要素」は解剖単位で数えた）
- 実測: 首上帯 ±7.0（α·顎場の列平均——顎スパイクは中心 9.9、端 4-5 に減衰する形を継承）/ 可視帯 ±8.3。**頭は静止（cp11 スコープ）のまま首上端が α 整合で動く**——顎縁裏のわずかな滑りは肌色連続で知覚されず（zoom-neck-min/max で破綻なし）。cp11 が頭に α·FaceX を入れた瞬間、この上端と無編集で繋がる設計

## craft への指摘（蒸留原料）

1. **「縫い付けアンカー」= 新しい境界条件クラス**。垂れ物テンプレの語彙で書くと: `field = P(y)·球面場 + (1−P)·アンカー衣服の場`。重力テンプレ（アンカー上・自由端下・収束先=付け根の並進）と鏡像で、**アンカー下・自由端上・収束先=縫い付け相手の場（static なら 0）**。「ゼロ収束は誤り」（cp08fix）と「ゼロ収束が正しい」（本問題）の分岐は**端が自由か縫われているか**——アンカーの物理的所有者を問うのが判定。アンカー行はテクスチャ実測（相手衣服の最初の幅広行）、勾配は smoothstep、裾行は厳密 0 を assert
2. **付け根並進の運搬は「列コピー」と「点アンカー」の2型**: 縦素材（毛のカーテン）は自分の列の付け根値、**斜行素材（腕）は付け根1点の場のスカラー**。判定は「その列の付け根帯に素材があるか」。列コピーを斜行素材に使うと先端が弦クランプ値に捕まる（見えない杭の変種）
3. **特異列は格子の節点に載せる（スナップ）**: 弦クランプ×z 床の交点（u=±U_T）はミン側で幅一セルのリッジを作る。分割数を上げるより折れ点をピッチが割り切るよう domain を微調整する方が2桁安い（1.37px→0.19px、格子は同サイズ）。cp09 の「耳稜線に列」の一般化——**「素材の大きさ×field の曲率」の曲率には C¹ 破れの位置も含めて読む**
4. **「浅い」はゲイン比でなく変位比で設計する**: 胴の Z(150) は鼻の Z(320) の半分以下なので、ゲイン比 0.711 でも変位は 1/3 になる。逆に頭部同調 α=0.6 は鼻 18px > 肩 10px を生むが、これは半径差の帰結で矛盾ではない（剛体運搬の物理）。ゲイン正典は「基準要素の変位 px」（S=10px @胸前面）で言語化するのが持ち越し可能
5. **要素の単位は解剖で数える**: neck/neck_back の前後2枚を1デフォーマ2子にすると式共有が構造で成立する（2基作って同じキーを打つより安全で安い)
6. y 非依存場（縦円筒 + 一様運搬）では重力ブレンドが恒等になり、リボン（タイ）は「素の回転場」だけで正しく運ばれる——「運搬」の実装が消えることがある
