# 閉問題 10: BodyX 胴体コア（首・上半身服・ネクタイ・両腕）

> 定義日: 2026-07-04。BodyX 戦線の第一手（cp10 = 胴体コア → cp11 = 頭部の浅い同調、の2分割をユーザー承認済み）。ユーザー証言: BodyX は「基本的に FaceX と同じロジック。動きが浅くなるが、体も動く」「首から上に限れば FaceX のゲイン違いでしかない」。

## 位置づけ

**首から下の初 rigging。** 球面理論と立体物の面の交代はそのまま適用されるが、新物理が1つ:

> **腰ピン拘束**: スカートにインしたシャツの下端は「ほぼ動かない」（ユーザー注意点）。隠蔽維持（見た目）とも隣接層連続（帽子縁）とも違う、**衣服の物理的な縫い付けアンカー**という新しいクラスの境界条件。肩は回転で流れ、腰へ向かって場がゼロへ収束する縦勾配——垂れ物の重力テンプレの**上下逆**（アンカーが下・自由端が上）

他の新規要素は既知の不変量・技法の応用:

- **首** = 接続要素（下端 = 肩の場 / 上端 = 頭部の同調ゲイン α に整合。H ランプ = 式共有の作法）
- **腕・ネクタイ** = 付け根並進の運搬（軸横断不変量の X 応用そのまま。腕は体積物なので薄い面の交代が乗る、ネクタイはリボン=物質縁）

## 対象

首 / 上半身の服体部分 / ネクタイ / 右腕 / 左腕（drawable 特定・メッシュ状態確認は実行時。**首から下は未メッシュの可能性が高い**——レシピ01から）

## パラメータと物理枠

- `param_body_angle_x`（preset 想定。カタログで ID・レンジを確認。無ければエスカレーション）
- 軸 = 脊柱（cx は胴体素材から実測。顔の cx=1001 とほぼ一致するはず）
- **ゲイン正典はこの問題で新設**: 肩の振幅 S が基準（FaceX の鼻に相当する役割）。「浅い」= FaceX より控えめ。gate でダイヤル
- **頭部の同調ゲイン α もこの問題で正典化**（cp11 が使う。首上端の整合に必要）
- 縮尺の理論注記: 浅い実効角では (1−cosΔ') は α² で縮む——**変位 α・縮尺 α² が一致則の理論値**。ただしユーザー実作は一様ゲインで足りている——一様で開始し、gate で「縮みすぎ/平板」が出た時のみ α² 補正

## 判断の所在（【ユーザー gate】）

- 「**肩から上が回り、腰は留まる**」のゲシュタルト（腰ピンの成立）
- ネクタイ・腕が体に付いて運ばれるか（浮かない・裂けない）
- 首が頭と体の間で破綻しないか
- **注意: 頭部はまだ BodyX に同調しない**（cp11 スコープ）。頭が静止したまま体が回る絵になる——cp07 の髪と同じ「証言者不足」を織り込んで判定

## 除外事項

- 頭部12要素の同調（cp11: 仮説 = α·FaceX field の相似縮小で機械生成）
- 対角品質（Runtime 責務継続）
- 帽子 X の人間補正（C10）は本問題では触りようがないが、回帰 assert は継続

## 成功基準

- **A**: 新 API 不要の見込み
- **B**: 上記 gate + 回帰無傷（rest / FaceX / FaceY / 開閉、バイト一致）
