# 閉問題 11: BodyX 頭部の浅い同調（頭部18塔の一括 = 相似仮説の検証）

> 定義日: 2026-07-04。cp10（胴体コア）通過を受けた BodyX 完結ラウンド。ユーザー承認済み——**本問題は「未知ゼロが正しいかのチェック」である**。

## 位置づけ

**仮説「パラメータ族は相似」の検証。** ユーザー証言「首から上に限れば FaceX のゲイン違いでしかない」に基づき:

> **頭部要素の BodyX 場 = α ×（その要素の committed FaceX 場）、α = 0.6（cp10 正典）**

仮説が正しければ、頭部18塔の BodyX rigging は**未知ゼロの機械生成**になる——設計せず、既存の FaceX キー（人間補正込みの committed 現物）を格子一致の点対点で α 倍コピーするだけ。当たれば FaceZ・BodyY 等の将来パラメータにも効く大きな craft になる。

## 対象: 頭部18塔（FaceY デフォーマを wrapChildren、BodyX が親）

顔 / 鼻 / 口 / 目 L/R / 眉 L/R / 眼鏡 / 帽子 / 耳 L/R / 前髪 / 房 L/R / 後ろ髪 L/R / 後頭部 L/R

（積み順はユーザー実作の慣例どおり: BodyX > FaceY > FaceX > 要素）

## 方式（レシピ06「移植作法」の自家版）

1. BodyX デフォーマの domain・格子次元を**その要素の FaceX デフォーマと同一**にする → restControlPoints が一致し patch を点対点移植できる（**移植前に格子一致アサーション必須**）
2. BodyX min(−10)/max(+10) キー = FaceX min(−30)/max(+30) キーの **α=0.6 倍**（dx・dy 両成分。帽子の dy 揺れも人間補正もそのまま相似で運ぶ——committed 現物が正典）
3. **一様 α で開始**（ユーザー実作準拠）。一致則の理論値は変位 α・縮尺 α² だが、補正は gate で「効きすぎ/平板」が出た時のみ

## 検証点

- **首の接続**: cp10 の首上端は α·(FaceX 顎場) で打ち込み済み——頭側が入った瞬間に**無編集で繋がる**設計。junction の実測差を数値で確認（これが仮説の一次検証）
- 【ユーザー gate】body sweep の全身ゲシュタルト——「**体を回すと頭も浅く付いてくる**」。cp10 で織り込んだ「頭が静止したまま」の違和感が消えるはず

## 除外事項

- 対角品質（Runtime 責務継続。監視レンダのみ）
- α² 縮尺補正（gate 指摘時のみ）

## 成功基準

- **A**: 新 API 不要
- **B**: gate 通過 + 回帰無傷（rest / FaceX / FaceY / cp10 BodyX 胴体 / 開閉——バイト一致。**帽子 X・topwear/tie の人間補正キーのバイト不変**）
