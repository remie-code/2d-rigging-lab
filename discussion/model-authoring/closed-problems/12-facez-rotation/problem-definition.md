# 閉問題 12: FaceZ 回転コア（回転デフォーマ + 剛体メンバー14塔）

> 定義日: 2026-07-04。FaceZ 戦線の第一手（cp12 = 回転コア → cp13 = 重力ワープ3種、の2分割をユーザー承認済み）。planning-gate 実施済み（`createRotation2dRigControl` の実在・wrapChildren・**pivot 指定可**を operation-core 現物で確認——cp01 以来の A 問題復活は杞憂）。

## 位置づけ

**初の回転デフォーマ（rotation2d）操作。** FaceZ（首かしげ）は X/Y と違い回転が画面内で起きる——射影も殻も不要な本物の 2D 回転。

**重要な前提（ユーザー指摘）**: warp の keyform 補間は格子点の線形補間なので、端点に回転場を打っても**中間パラメータで回転にならない**（弦を渡って縮む）。回転を表現できるのは**角度を補間する回転デフォーマだけ**。

新しい未知:

1. **rotation2d の操作様式**: keyform が warp と違い2プロパティ（angleDegrees + translation）。初操作の craft 化
2. **ピボットの従属性仮説**: 「傾けただけだと首から外れる」問題は、**pivot を首の付け根に正しく置けば構成的に消える**はず（payload で pivot 指定可を確認済み。ピボット P 周りの回転 = 原点回転 + 並進 (I−R)(P−O) ——生成時 pivot 指定でこの並進が自動化される）。translation キーは演出の残余ダイヤル

## 対象: 回転デフォーマ1基 + 剛体メンバー14塔

FaceZ 回転デフォーマを1基新設し、以下の BodyX 塔を **wrapChildren で一括**（FaceZ が親。積み順: [BodyZ] > FaceZ > BodyX > FaceY > FaceX——ユーザー実作の慣例）:

顔 / 目 L/R / 口 / 鼻 / 眼鏡 / 眉 L/R / 帽子 / 耳 L/R / **前髪** / 後頭部 L/R

- **房 L/R・後ろ髪 L/R は含めない**（重力に律則されるため回転メンバーではない——cp13 で専用ワープ）
- 前髪は回転メンバー**かつ** cp13 で重力ワープを上乗せする二重身分
- 首は含めない（体に残る。かしげのピボットが首の付け根）

## キー設計

- パラメータ: FaceZ 系 preset（ID・レンジは実行時確認）
- angleDegrees 三点キー（±端の角度は演出ダイヤル。控えめ=上品から開始し gate で調整）
- translation キーは 0 から開始（ピボット仮説の検証。外れたら補正ダイヤルとして使う）
- pivot = 首の付け根（顎下・首中心の相場。素材実測から初期値、レンダで較正）

## 判断の所在（【ユーザー gate】）

- 「**自然に首を傾げた**」に見えるか（首から外れない = ピボット仮説の検証）
- 剛体メンバーが一塊で回るか（眼鏡・帽子・後頭部含む）
- **織り込み**: 房・後ろ髪はまだ付いてこない（付け根がこめかみで置いていかれる絵——cp13 で解消）
