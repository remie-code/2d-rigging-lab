# 閉問題 15: BodyZ 補正ワープ群（重力追従 + シャツ微調整 = BodyZ 完結）

> 定義日: 2026-07-04。cp14（回転コア）通過を受けた BodyZ 完結ラウンド。ユーザー承認済みの2分割の後半。

## 位置づけ

**「描かれた固定が終わる線」テンプレの3連適用。** 新未知はほぼゼロ——cp13 の3帯モデル・cp10 の縫い付けアンカーを、BodyZ 回転場（pivot=(997.25,1124)、±6°）に対する**回転内差分補正**として書く。

> 統一原理: 固定線（生え際 / 結び目下端 / スカートイン線）まで親の回転に従い、線から先は支配則が交代する——髪・ネクタイは重力（線の変位を運ぶ）、シャツはアンカー（ゼロ収束）へ。

## 対象: 補正ワープ7基（ユーザー指定。両腕は意図的に作らない——配信でほぼ映らず回転任せで違和感が薄いため、作業コスト削減）

| 要素 | 固定線 | 補正の中身 |
|---|---|---|
| 前髪 | 生え際（cp13 の現行 W 形状を流用——試走の既知の乖離を継承） | 固定線から先: BodyZ 回転を打ち消し、線の変位を一様に運ぶ（回転内差分: `(1−W)·(d_line − rot)`） |
| 房 L/R | y_scalp = 520 / 505（cp13 実測値を流用） | 同上 |
| 後ろ髪 L/R | y_scalp = 540（同上） | 同上 |
| ネクタイ | **結び目の下端**（テクスチャ実測） | 結び目まで回転に従い、下は結び目の変位を運ぶ——**rest が鉛直に描かれているので carry だけで鉛直が保たれる**（プラム不要の見込み） |
| シャツ胴体 | **スカートのイン線（y=1124 = pivot と同じ高さ）** | 縫い付けアンカーの回転版: 肩帯はフル回転、裾へ向かって `(1−P(y))·(−rot)` でゼロ収束——めり込み/隙間の解消 |

## 構造

- 各ワープは**その要素の現在の塔 root を wrapChildren**（積み順: BodyZ 回転 > **BodyZ ワープ** > FaceZ ワープ/塔——ユーザー実作の hair_f_l BodyZ > hair_f_l FaceZ の順）
- キーは param_body_angle_z の min/max（createEndsCenter）

## 技術上の注意（既存教訓の適用）

- **符号反転線 = pivot の高さ y=1124**。髪・ネクタイは全域がその上（安全）。シャツの遷移帯も **1124 より上で完結**させる（assert 機械化——cp13 の教訓）
- BodyZ の回転場は頭部の高さでは**ほぼ一様な並進**（pivot から遠い）——補正量は FaceZ より小さいはずだが、「傾いたまま固定される垂れ物」の違和感は角度でなく傾きで効くため省略しない（ユーザー実作も同じ構成）
- プラム項はデフォルト不適用（BodyZ の変位場は毛束スケールでほぼ一様＝作画の嘘を暴かない見込み。レンダで要と判ったら報告）

## 判断の所在（【ユーザー gate】）

- **ネクタイが結び目から下で鉛直に垂れる**（斜め固定の解消）
- **シャツがスカートにめり込まず・隙間も開かない**（イン線の静止）
- 髪が生え際から先で垂れ直す
- BodyZ 完結の通し sweep
