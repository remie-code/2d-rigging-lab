## 獲得（レシピ06へ反映済み）

1. **「描かれた固定が終わる線」の統一実証**: 7基全部が同一文 `net = Φ·rot + (1−Φ)·A`、分岐は `A = carry（重力系）| 0（アンカー系）` の1個。固定線の実測レシピ3型が揃った——生え際（食い込み符号反転行）/ **結び目下端（幅プロファイルの極小プラトー）** / イン線（上縁フラット行）
2. **回転内差分の厳密形 `c = R⁻¹(p+net)−p` はデフォルト化推奨**: 符号反転を跨ぐ carry では O(θ²) 残差が必ず発動（実測 15.2px）。厳密形は op コストゼロで、Φ=0 帯がアフィン化する副産物つき
3. プラム項の不要判定の実例（タイ = rest がほぼ鉛直 / ±6° の一様変位は作画の嘘を暴かない）——発動条件の較正データ
4. 実装罠: warp レコードの格子フィールド名は `latticeColumns/latticeRows`（op payload の transformColumns と別名）
