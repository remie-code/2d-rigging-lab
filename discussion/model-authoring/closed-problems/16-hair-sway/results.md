## 獲得（craft/08 へ蒸留済み）

1. **揺れモード場は等長写像でなければならない**: 位置(s) = ピン + ∫(sinθ, cosθ)dt、θ = Θ(t/L)^κ。弦配置（点をピンから距離 s に置く）は θ 成長がある限り必ず伸びる（√(1+(sθ′)²)、毛先 13% 実測——ユーザーは「毛が伸びて見える」と正確に知覚した）。検証は「列折れ線長 vs rest ≤0.1%」の1不変量に落ちる。κ は剛性ダイヤル（→0 剛体振り子 / 1 鞭）で等長性と直交
2. **静的リグ = 定常、dynamics = 過渡**: 重力の定常を静的 Z リグに焼き込むモデル様式（cp13/15）では、dynamics の angle 入力は重力の二重計上になり静定が真下を通り越す。全入力を positionX（根本の弧並進のレバー線形化 |y_fix−pivot|·rad/unit）にすると**「揺れが収まったら静的ポーズ」が構造保証**になる（angle ゼロの機械 assert）。angle kind は「静的リグが剛体追従のみのモデル」用
3. **物理定数は実測から**: L_eff = (2/3)×自由長（分布質量棒）で周期が長さ別に分かれる（前髪 0.6s / 房 0.8s / 後ろ 1.4s——ref の「全部1本」慣習を捨てた配当）。パラメータ別の根本並進は**パラメータ責務ワープの own 格子**を固定線行で測る（1デフォーマ=1責務が巻尺に効く）。後ろ髪の励起は負符号（後頭部 z<0、実測由来）
4. **板の回転の禁止**: 単一ピンの全格子回転は「斜め重力 + 伸縮」に見える。幅のある素材は列ごとに曲げる
5. 固定線の格子行スナップで直上バイリニア漏れ完全ゼロ（22.9 → 2.4 → 0.00px の3段実証）
