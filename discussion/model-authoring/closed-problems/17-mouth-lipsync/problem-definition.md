# 閉問題 17: 口パク（Mouth Open × 母音、最大情報素材の単一変形方式）

> 状態: Problem defined（2026-07-05）
> 方式合意: ユーザーと L0 が独立に同一結論（「最大情報素材を正とする単一変形」）に到達

## この問題の新しい未知

**素材参照 morph 場**: パッケージ内の参照 drawable（mouth_i/u/e/o、非表示）のシルエットを実測し、基準素材 mouth_a をその形へ変形するワープ場を数値導出する。これまでのオラクル（ref/）は封じ込めで委任エージェントに閉ざされていたが、**パッケージ内参照素材は合法のオラクル**——「ユーザーが絵で答えを描き、Fable が場に翻訳する」の初実証。

## 方式（合意済み設計）

- **mouth_a（全開の「あ」）を唯一の生きた drawable にする**。変形は情報を潰せるが発明できない——歯・舌・口内を持つ最大情報素材が出発点でなければならない
- **閉じ口は純変形の潰し**（opacity swap なし）: 配信縮尺では専用閉じ口素材より潰しの方が視認性が高い（ユーザー決定 2026-07-05）。旧 mouth drawable は永久非表示
- **塔構造**（既存追従塔はそのまま再利用）:

```
rig_facex_mouth（既存・最内側）
  ⊃ MouthOpen ワープ（キー1 = 恒等 = rest の全開 / キー0 = 閉じ口シルエットへの潰し）
    ⊃ 母音ワープ i/u/e/o の4基（各キー1 = 参照シルエットへの morph / キー0 = 恒等）
      ⊃ mouth_a
```

- **入れ子の順序が物理**: 母音が形を作り、Open が外から潰す。「い の半開き」「閉じたら母音が消える」は合成から自動で出る
- **あ = rest そのもの**なので Vowel A のワープは作らない（恒等）
- 母音は**単一非ゼロ運用**（フェイストラッキング側仕様。同時ブレンドは考慮外 = ユーザー決定）
- パラメータ（プリセット常在・作成不要）: `param_mouth_open`、`param_mouth_vowel_{a,i,u,e,o}`（全て 0..1、default 0）。**default open=0 → rest レンダの口は「潰された mouth_a」になる**（旧閉じ口と絵が変わるのは想定内・意図）

## スコープ（操作列）

1. mouth_a のメッシュ確認（無ければ generateMesh——空メッシュの罠）と、既存追従塔（rig_facex_mouth）配下への編入。旧 mouth は非表示、参照4枚も非表示のまま
2. ワープ5基の作成（MouthOpen 1 + 母音 i/u/e/o 4）
3. シルエット実測: mouth_a・mouth（閉じ）・mouth_i/u/e/o の輪郭（テクスチャ alpha 直読み、またはビジビリティ一時トグル + drawableFocus レンダ。手段は A 調査で確定）
4. morph 場の導出とキーフォーム: 列ごとの上下縁対応 + 口角の水平対応（詳細は experiment/design-notes.md に規定）
5. 検証 + sweep レンダ（open×母音の行列）

## 判断の所在

| 判断 | 所在 |
|---|---|
| morph 場の導出式 | Fable（実測シルエット対応。design-notes が正） |
| 各母音の「正解の形」 | ユーザーが素材で既に供給済み（参照 drawable = 合法オラクル） |
| 見た目の満足（潰し閉じ口の視認性・母音の似度） | ユーザー gate（Editor でスライダ操作） |

## 除外事項

- Mouth Smile / Mouth Form（表情差分の戦線送り。ユーザー決定）
- 母音の同時ブレンド品質
- 口パクのトラッキング接続そのもの（player 側の既存機構）
- mouth 2〜10（他表情の口）への展開

## 成功基準

- **A**: sweep レンダ（open {0, 0.5, 1} × 各母音 {0, 1}）で、(i) open=1・母音=1 の口シルエットが参照素材のシルエットと一致（巻尺、行/列縁の残差規定は design-notes）(ii) open=0 で唇が閉線に潰れる (iii) rest レンダの差分画素が口領域に局在（差分局在化手続き = cp14 レシピ）(iv) 既存キー・他 drawable バイト無傷
- **B**: ユーザーが Editor でスライダを動かし「口パクとして成立」と判定

## A 調査残項目（実験前に確定）

1. 非表示 drawable のシルエット取得経路（テクスチャ alpha 直読み vs 一時トグル + レンダ）
2. mouth_a/参照素材のメッシュ有無・テクスチャ領域
3. 現在の visible フラグの実態（ユーザーが Editor で切替済みの状態確認）と現 packageRevision
