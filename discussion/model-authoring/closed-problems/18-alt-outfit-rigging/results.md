## 経過（2026-07-05、一発通過・三十代目）

rev 512→560、48 op、reject ゼロ（学習 dry-run 1件のみ・無傷）。新ワープ8基 + 再標本化キーフォーム + 可視旗の明示化。検証6点 all PASS（恒等検算 0誤差 / committed 照合 maxErr=0 / rest sha 厳密一致 / 既存99 keyformSet 無傷 / 可視状態の完全復元）。ユーザー判定: **「破綻などはしていない、もう本当に好みの問題だ」= 通過**。

## 獲得

1. **場の空間再標本化（相似則の一般化）**: committed 現物の変位場を「空間の関数」として双一次補間 + 外挿クランプで読み、別素材の新格子で標本し直す——約30行で恒等 0誤差。**場は素材ではなく空間に属する**が数学と目視の両面で立証された:
   - シャツ襟用の**人間補正場が、立ちジップ襟にもタートルネックにも自然に乗った**（人間の手仕事の衣装横断再利用）
2. **服の固定の2型（新原理、cp18 では観察のみ・未適用）**: ①**縫い付け固定線**（イン・結び目: くっきり境界でゼロ収束）②**羽織りのフェード帯**（ジャケット等の境界なし服: ベルト行の変位を腰線へ向け Φ ランプで 0 へ）。選択基準 = 端の物理的所有者の親戚「服が縫い付いとるか羽織っとるか」。今回はシャツ場のクランプ運搬で「ベルト固定」に見える——好みの領分としてユーザーが受容、**後続の磨きで適用可**（ソース場の下端をフェード帯で延長する小手術）
3. **空メッシュ = 事実上の非表示、の罠の新型**: 可視旗 true でも空メッシュで隠れている drawable は、メッシュ生成で突然出現する。rigging 前に可視旗を明示化する（三十代目が自律処置、ユーザー追認済み）
4. 実装知見: 新しい塔の作成は create モードの `childRigControlIds` 養子縁組（wrapChildren は in-place 挿入専用）/ evaluatedControlPoints は親合成前のローカル値（world 検証は drawable 頂点で）
