# レシピ 05: 目の開閉（状態切替 rigging）

開き目・半目・閉じ目の3状態を「変形で形を繋ぎ、切替の瞬間だけ opacity で交代する」構造で繋ぐ。閉問題02でユーザー満点 gate を通過した手順の蒸留。**同型の状態切替（口の開閉等）にも骨格は流用可能なはず**（未検証）。

## 前提状態

- 各状態セットのメッシュ生成済み（レシピ01）、動的部品（眼球）のリグ済み（レシピ02）、クリッピング済み（レシピ03）
- 状態セット同士は描画順で「開き目が最前、閉じ目が最後」の並び（PSD 由来の baseDrawOrder で通常成立。要確認）
- パラメータ: preset `param_eye_left_open` / `param_eye_right_open`（1.0=開、0.0=閉）

## 構造（片目につき状態デフォーマ3基）

`createWarpDeformer` ×3。子指定は直接モード（`childRigControlIds` + `childDrawableIds`）:

- **Open**: 子 = [眼球デフォーマ(rigControl), eyelash, eyewhite]。domain = 子要素 bbox の union + pad 10
- **Half**: 子 = [半目眼球デフォーマ, eyelash 2, eyewhite 2]。同上
- **Close**: 子 = [eyelash 3]。domain = その bbox + pad 10

## opacity キー（`addCurrent` ×2/基、targetProperty `opacityMultiplier`）

| 状態 | キー | 意味 |
|---|---|---|
| Open | `1@0.6 → 0@0.5` | 0.5 で完全に消える（半目に交代） |
| Half | `1@0.05 → 0@0.0` | 消失側のみ。**出現側キーは打たない**（param≥0.5 では Open が描画順で覆う） |
| Close | `1@0.0 → 0@0.07` | まつげ線が Open/Half の描画領域外へ食み出すため opacity で消す必要がある唯一の状態 |

0.05〜0.07 は Half/Close の意図された短いクロスフェード窓。

## 形状キー（`addCurrent`、targetProperty `controlPointOffsets`）

**大原則（不変量）: フェード窓の全域で、交代する二者は同じ形を追跡し続ける。** 形の遷移は変形が済ませ、opacity は交代だけを担う。

### Open（2キー: identity@1.0 → 半目形@0.5）

写像はアフィン1本で足りる（開口は両形に存在し、位相変化がないため）。**まつげ bbox の対応から導出**: 開まつげ bbox → 半目まつげ bbox で (ax,bx,ay,by) を解く。検証: この1本で白目・虹彩も 1px 台で追随する（閉問題02実測）。オフセット = `map(p) − p` を restControlPoints 各点で計算。

### Half（4キー: 膨張@0.6 → identity@0.5 → 88%潰し@0.07 → 完全潰し@0.0）

- **@0.6 膨張キー（忘れると二重像）**: Open のフェードイン窓（0.5-0.6）では半透明の Open 越しに Half が見える。Half が静止だと「動かない半目が透ける」違和感になる。目標形 = 通常目@0.6 の輪郭 = `lerp(開まつげbbox, 半目まつげbbox, 0.8)`。アフィンで打つ
- **@0.07 / @0.0 潰しキー**: アフィンでは開口が位相的に消せない。**区分線形の縦写像**を使う。アンカー4点:
  1. まつげ上端 → 線芯 − まつげ厚 − α
  2. 白目上端 → **線芯 − 1**
  3. 白目下端 → **線芯 + 1**（開口がここで潰れる）
  4. まつげ下端 → 線芯 + α
  - **線芯は画素から実測する**: 閉じまつげテクスチャの行ごとに `Σ alpha×(1−luminance)` を取り、その重心行 = 線の視覚的中心（bbox 推定は 2〜5px ずれる。ユーザーが知覚できるずれ）。テクスチャは `texture-atlas.json` の `binaryAssetRef.packageRelativePath`、寸法はメッシュ bounds
  - **帯域外の格子行は傾き1でクランプ**（端区間の傾きで外挿すると暴走する。×5 の傾きで +67px 飛んだ実例あり）
  - @0.07 = 完全潰しの 88%（フェード開始時にほぼ閉じ切っており、残り 12% が窓の中で閉じる）
  - 横方向はまつげ bbox 対応のアフィン

### Close: 形状キーなし（opacity のみ）

## 完了チェック

1. **数値**: Open@0.5 のまつげ bbox ≒ 半目 rest（巻尺、1px 台）
2. **★視覚**: 11段 sweep で連続変形に見える / フェード窓（0.03 等）で「線と線の交代」になっている / 0.55 で Open ゴーストと Half が一つの目に見える
3. **合成**: 開閉 0.7 × 眼球X ±1 で両パラメータが干渉しない
4. **【ユーザー gate】**: Editor スライダーで瞬きの自然さ判定

## エスカレーション条件

- 交代の瞬間に絵が「跳ぶ」→ 潰し先が線芯からずれている（実測し直し）。「いきなり消える」→ フェード開始時点の閉じが足りない（@0.07 の割合を上げる）
- 修正は原則**前進修正**（`updateCurrent` でキー patch を打ち直す。構造が壊れた時だけ git 巻き戻し）

## 切替と変形の選択基準（レシピ09 からの逆輸入。2周目ブラッシュアップ）

状態バリエーションの実装は2方式あり、選択基準は状態空間の形:

- **opacity 切替（本レシピ）が正しいのは「一方向1境界」のとき**——開→半→閉のような一次元の状態列で、フェード則（同形の二者間でのみ交代）が守れる場合
- 状態が直積（開き量 × 形、など多方向）なら**最大情報素材の単一変形**（レシピ09）——切替で直積を書くと組合せ爆発し、設定が複雑化した挙句うまく動かない
