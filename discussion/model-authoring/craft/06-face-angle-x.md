# レシピ 06: Face Angle X（顔の横回転 rigging）

> **読み順の推奨（2周目ブラッシュアップ）**: 初読は末尾の「**回転射影の統一原理**」から入ること。本文の各節（回転射影則・軸の転置・rotation2d）はすべて統一原理の3軸インスタンスであり、本文は導出の歴史的記録として保持している。

顔の横回転パラメータ（`param_face_angle_x`、preset、レンジは parameters を確認。min=画面左向き / max=画面右向き）に対し、要素ごとの FaceX 層デフォーマを積んで擬似3D回転を作る。閉問題03の蒸留。

## 前提状態

- 対象要素のメッシュ・下位リグ（目の開閉塔など）が完成済み
- 対象要素の選定: 最小核は「鼻・顔輪郭・目」。鼻は**基底鼻**（face 階層の part に属する nose。表情セット配下の nose 群とは別物なので partId で見分ける）

## 構造

- **要素ごとに FaceX 専用デフォーマを1枚**作る（1要素×1パラメータ = 1層の原則）
- **格子解像度の規則**（2026-07-03 ユーザー経験則）:
  - **ベジエ分割数は transform 分割数と揃える**（transform 7×7 なら bezier 7×7）
  - 分割数は「domain の広さ × 表現したい field の曲率」で決める。**余裕を持って要素を覆う domain なら、相場（5×5/7×7）より2段階細かく**（9×9〜11×11 級）。粗い格子は回転射影則の曲率——特に端の縮み帯——を区分線形で潰す（分解能不足）
  - 判断軸の真意は**「素材の大きさ × field の曲率」**であり、domain の余裕は代理指標にすぎない（閉問題05: 後ろ髪はタイトな domain でも幅広素材 × z<0 の曲率で 11×11 が要った）
  - 逆に domain を要素にタイトに絞るなら相場の分割数でよい
- 既存リグ塔（例: 目の状態デフォーマ群）の上に被せる場合は `createWarpDeformer` の **`wrapChildren`**（`[{kind:"rigControl",id:...}...]`）で挿入する。既存塔の parentId が自動で書き換わる。**`wrapChildren` は `childDrawableIds`/`childRigControlIds` と併用不可**（排他モード）。**挿入後は既存機能の回帰確認が必須**（開閉・眼球移動・マスクを合成レンダ1枚で見る）
- 素の drawable（鼻・顔）は `childDrawableIds` 直接指定でよい
- domain = 子要素の**生成後の実頂点範囲**の union + 移動量ぶんのマージン（宣言 bounds は実頂点範囲より狭いことがある。メッシュ生成後に測り直す）

## ゲインと構造の分離（2026-07-03 盲目再構成実験で確立）

**field = 構造 × ゲイン。**

- **構造** = 奥行き比率・左右非対称・field の位相（帯・スパイク・固定縁）。客観であり、本レシピの原理から導出可能（盲目実験で内部比率が完成参照と誤差2割以内で一致）
- **ゲイン** = 全体の振幅スカラー。**モデルオーナーの演出意図**であり正しさの軸ではない（控えめ=上品 / 大きめ=楽しい、はどちらも満点になりうる）
- 手順: **構造をゲイン1で組み、ユーザー gate でゲインのダイヤルを回す**。ゲイン1の基準 = 鼻の振幅 ≈ 頬幅の10%（上品な回転として満点実証済み。演出強めなら〜20%）。調整は全 FaceX キーへの一様乗算（updateCurrent 一括）で機械的に反映できる
- 完成参照から抽出する場合も同じ分離を適用する: **比率は essence（持ち越せる）、絶対値はゲイン込みの較正データ（そのモデル専用）**

## 回転射影則（最上位原理。2026-07-03 ユーザーとの対話3往復で最終形に到達）

**全ての点は自分の (u, z) を持つ**: u = 回転軸からの横距離（画面上で見える。u = x − cx）、z = 想定奥行き（見えない。**これが唯一の設計対象**）。「球の内側/外側」という概念は無い——素材そのものが幾何であり、半径 r = √(u²+z²) は点ごとに定義される。

縦軸回りの**有限回転** Δ に対する画面X変位:

> **dx(点) = u·(cosΔ − 1) + z(点)·sinΔ**

この一本が全現象を吐く:

- 中心（u=0, z最大）: z·sinΔ で最大移動
- **端（z≈0）: u·(cosΔ−1) で左右両端が対称に内側へ縮む**（Δ=30° で −0.134u。「縁は固定」は微分近似の誤り——死帯を作ってはならない。完全静止するのは回転軸上のみ）
- 幅を持つ全要素の伸縮（foreshortening）: 点ごとの dx 差として自動発生
- 背面（z<0）: 逆方向移動（後ろ髪）
- 突出部（z 局所大）: 鼻・顎先の大移動

**よくある誤り2つ**（閉問題04で実際に踏んだ）:
1. **微分近似 dx = Δ·z（cosθ 減衰）で止まる** → limb に死帯ができ、「描画範囲内なのに全く動かない境界」が生まれる。弦の式（有限回転）を使うこと
2. z(x) = √(R²−u²) の**単一球 ansatz に素材を無理に収める** → 球より広い素材（髪など）が定義域外に落ちて凍る。z は点ごとに描くもの（球・円筒は初期 ansatz に過ぎない）

**設計手順**: 要素ごとに奥行きプロファイル z(x)（必要なら z(x,y)）を描く → 式で field を決定論的に生成 → 目視イテレーション。層の目安: 鼻・顎（突出）> 前髪・帽子表面 > 顔面造作（目・眉・口）> 顔輪郭 > 頭蓋（軸近傍）> 後ろ髪（z<0）。

**z プロファイルの実装知見**（閉問題04 fix2 で実証）:
- 横断面の ansatz は**放物線 1−(u/U)² が扱いやすい**。球の √(1−u²) は limb で傾きが無限大になり、粗い格子で折り返し（せん断）を起こす危険がある（検算の上で棄却された実例）
- 縦方向: 頭部は球冠（頂点=素材最上端、赤道=目の高さ相場）、**そこから下の垂れ房は円筒延長**（付け根の並進を運ぶ。髪先まで球で減衰させると付け根と先で裂ける）
- **ゲインの適用順**: 式は物理スケール（実寸 U、実角 Δ）で評価してから、正典への整合は一様乗算で最後にかける（中心ピークを基準要素——鼻——に同期させる）

**決定論で決まらないダイヤル（演出領域）**: ①cx（軸の位置）② z プロファイルの形と層間差（髪が「外側に載って見える」深さ差はいくらか）③全体ゲイン（別掲）。法則が形を保証し、ダイヤルは目視とユーザー gate で決める。

## 同一モデル内拡張の作法（2要素目以降。閉問題05で確立）

既存 FaceX 要素が居るモデルへ要素を足すときは、**既存 field から物理枠（cx・U・Δ・ゲイン g）を復元し、z プロファイルだけを設計する**。基準要素（鼻）のキー振幅がゲインの、既存デフォーマの生成式が軸と殻幅の一次ソース。同じ dx± 式に新しい z を差すだけで、ゲイン・弦/z 比・軸・層間連続性が全部自動整合する。外部数値の持ち込みは不要——**モデル自身が唯一の較正基準**。

## 頭部外周の z 域テンプレ（閉問題05で実証。全て回転射影則への代入）

- **耳（limb、z≡0）**: コロナル面上の付属物 → 弦の項のみが残り、**±両キーが同一 patch になる**（cos の偶性）。微小移動 + 内向き縮み
- **垂れ房**: 直上の既存 field（前髪）と**完全同一式**でよい（層差ダイヤル = 0 の選択）。付け根の連続性が構成的に成立する。層差を付けたくなったらそれは演出ダイヤル②の話
- **後ろ髪カーテン（z<0）**: `z = −Z·(1−(u/U_spread)²)·s(y)`。中心深度 Z は前殻の鏡像が相場、**U_spread は素材の広がり全幅で頭殻 U とは別物**（単一球 ansatz の罠の z<0 版）。弦の項の u は根本写像 `u·(U_head/U_spread)` で圧縮して評価する（毛は根本で頭に付いている）。**左右分割素材は単一の大域式で跨ぐ**——seam 連続が構成的に出る
- **後頭部層（帽子と後ろ髪の間の表層）**: 頭蓋裏面の素材。上端（帽子縁。帽子が未 rig なら静止物に合わせる暫定）で振幅→0、下端でカーテン付け根と**式レベルで一致**させて同期する。**逆方向の微小ドリフトが前髪との差動パララックスになり、横向き時のチラ見えを生む**（受動的な露出でなく能動的な差動が立体感の源泉）

## 隠蔽維持拘束（閉問題05 fix で獲得。振幅の上限則）

**rest で隠れている描き縁（髪の付け根など）は、全キーでも隠れ続けなければならない。** 破れると素材が「浮遊物」に見える（頭から生えている前提が崩れる）。

- **罠は二重苦**: 隠される側が流れるのと同時に、**遮蔽層自身も弦の項で縮んで退く**。露出は両者の和で開く（実測例: 付け根 −25px + 前髪縁の後退 +10px = 35px の露出）
- 上限は ±max レンダで遮蔽の余白を**実測**して決める（宣言 bounds でなくレンダ）
- **実装作法**: 隠蔽拘束は縦プロファイル s(y) に混ぜず、**独立の乗数 q(y)** として被せる。縦は3帯——付け根 = 遮蔽余白まで絞る / 毛先の自由帯 = 1 / 間は smoothstep。絞りの強さがワンノブになり、gate 補正が updateCurrent 一括で済む

## 軸の転置（Face Angle Y で実証。2026-07-04、閉問題07〜09）

法則は軸を替えて転置できる: **dy = g·[v·(cosΔ−1) + z·sinΔ]**、v = y − cy（縦の回転軸。耳の高さ相場——実証値は目の高さの X 赤道と 4px 以内で一致）、dx ≈ 0。**g は層の実効角ゲインで、弦と sin の両方を括る**（一様スケール回転 = 形の保存）。弦だけ素の Δ で入れると弦と変位が別々の角度を語り、軸から遠く z の浅い側で弦が sin 項を食って要素が凍る・符号反転する（2周目 FaceY 再導出の失敗実証: 弦と sin が同方向の半面は一致して見えるため、反対の半面が死んでいても診断が遅れる）。実測では**本レシピの8割が軸の読み替えだけで走った**（弦・偶性・放物線 ansatz・格子規則・鼻からのゲイン手順・wrap 作法）。特に**殻 z は軸横断の資産**——X の z プロファイルをそのまま sinΔ 項に差すと、層順・ゲイン整合・seam 連続が全部引き継がれる。ただし**横断するのは形（プロファイル・層順・seam 連続）であって尺度ではない**——元軸の実装でゲイン構造が z に焼き込まれている場合（振幅符号化された z）、転置先では層の実効角機構（アンカー ÷ 殻半径·sinΔ）で殻スケールへ昇格させてから差す。検算 = 昇格後の z(赤道)/殻半径 が 1 近傍に座ること（2周目実証: 0.88）。

**転置で折れるもの（判定基準 = 規則の出自）**:

- **実測由来の規則は軸ごとに測り直す**: 「顔輪郭の外周ゼロ」は X での隠蔽実測の結果であって法則ではない（Y の顔は「殻の皮膚流し + 顎の弦」クラスへ移籍）。q(y) 隠蔽絞りも軸ごとに要否を再実測（独立乗数だから外せる）
- **例外則は幾何的根拠の存在を問う**: 縁ループの dz→dy 結合は「ループが回転面に直交する」という X の幾何の産物で、Y では構造的に消滅する
- **縦殻は軸非対称**: 上極（頭頂）と下極（顎の巻き込み点）は独立のダイヤル
- **ゲインは方向別2値**（実証: 俯き = フル正典 / 見上げ = 0.8倍——未描画面（顎裏）を晒す方向を絞る）
- 先行率はクラス依存（普遍定数ではない）
- **係留先の所有者は軸ごとに再同定**（X の occiput 係留が Y では前髪殻係留になった実例）
- ポリシー（2026-07-04 ユーザー決定）: **1デフォーマ = 1パラメータ責務**。新パラメータは専用デフォーマを新設し既存塔を wrapChildren で包む（新パラメータが親）。**対角成分は Runtime の階層評価の責務 = 設計対象外**（監視レンダのみ。問題が出たら人間が直す）

## 変位と縮尺の一致則（閉問題07 fix で獲得。2周目 FaceY 再導出失敗で2層に精密化）

見る側は回転角を2経路で読む: ①**要素間の変位**（sinΔ 系）②**要素内の縮尺** = foreshortening（(cosΔ−1) 系）。縮尺は**2層あり、別々の強度で入れる**——この2層を1つの規則に潰すと、どちらか片方の逆読みが起きる:

1. **全体の弦（要素間の詰まり・層の縮尺）= 場の実効角スケール**: `g·v(cosΔ−1)`——**変位と同じ g で括る**（一様スケール回転 = 形の保存）。弦を素の Δ で入れると「素の角の縮み × 絞った変位」という角度の矛盾になり、軸から遠く z の浅い要素で弦が sin 項を食い、変位が半減・符号反転する（実証: 素の弦の Y 転置で口の変位が半減し顎が逆流。弦と sin が同方向の半面は正常に見えるため発見が遅れる）
2. **要素内前縮（開口の潰れ）= 読み取り角の強度**: ゲイン g は cos 系に掛けてはならない——縮尺は二次なので g 倍すると知覚の下に沈み、変位が語る角度と縮尺が語る角度が矛盾して破綻に見える（顎は大きく傾いたと語るのに目が潰れない、等）。幾何アンカー = 1−cosΔ（素の角）、知覚床は10%級。**平均変位保存アンカー**（開口中心基準の加算勾配）で、gate 済みの変位ゲシュタルトを壊さず外科的に足す

- **読み取り実効角と層の実効角は同一機構**（invariants/layered-rotation-shells.md §1: 実効角ゲイン = 層の中心振幅/(殻半径·sinΔ)）。**核も層である**——核の弦だけ素の Δ で入れる例外を作らない。ある軸でそれが通って見えたら、殻半径が浅く弦が変位より小さい・縁係留が弦ごとシルエットで吸収している等の偶然を疑うこと（軸を転置して殻半径が跳ねた瞬間に矛盾が顕在化する）
- 「field = 構造 × ゲイン」の精密化: **変位と全体弦 = 構造 × ゲイン / 要素内前縮 = 読み取り角の強度のまま**
- **標本化則は1次（勾配）にも及ぶ**: 目だけ潰すと眉-目間隔が逆に開いて悪化する。眉は目の field の 0次+1次を標本化する
- X の目の 0.65T:0.25T 勾配の正体は要素内前縮（弦の項の半身であって任意の演出ではない）
- **開口要素は準剛体で運ぶ**: 目・口など形が意味を持つ造作の変位は「代表点の0次 + 上記の規定1次（前縮）」のみ。殻の曲率や縁の減衰を要素内に点読みで通すと、中央と端の変形が乖離して描かれた形が崩れる（invariants/layered-rotation-shells.md §5「造作の準剛体則」）
- 対偶: 軸上のピボット要素（v≈0 の耳など）には縮尺を適用しない（変位が語らないものに縮尺だけ語らせない）
- ゲイン非対称なら縮尺も非対称（実証: 俯き10% / 見上げ6% = 実効角 30°/23.6° に一致）

## 垂れ物の重力テンプレ（閉問題08 で獲得。Y 系の垂れ物）

**重力減衰は「動きの消滅」ではなく「回転性の消滅」**。重力は毛束の振り回し（Θ 依存成分）を殺すが、毛束は付け根に付いている以上**並進は毛先まで運ばれる**。毛先の極限 = 自分の付け根の変位のコピー（純平行移動）:

> `field(u,y) = W(y)·球面場(u,y) + (1−W(y))·球面場(u, y_root(u))`

- **「付け根の並進を運ぶ」は軸横断の不変量**（X の円筒延長則と同一物）。収束先を空間ゼロにすると X では「裂け」、Y では「毛先が見えない杭に捕らわれる」として同じ誤りが別の絵で出る
- **W(y) は回転性成分の混合比**であって変位の減衰率ではない。機械検証の型: 恒等式 `field − root = W·(球面場 − root)`
- **W 境界 = 頭蓋接触を失う行**（房は顎・カーテンは襟足）、**遷移距離 ∝ 自由長**。y_root は W 境界の再利用で足りる（減衰の始点と並進コピーの標本行は同じ物理的意味）
- 前髪は適用外: 額に張り付く = 顔に律則されほぼフル追従（重力に勝つ）
- **運搬の3型**（閉問題10で2型獲得・3周目 BodyX で第3型追加）: 縦素材は**列コピー**、斜行素材（腕など）は**点アンカー**（付け根1点の場を全体に運ぶ。列コピーだと先端が弦クランプに捕まる）、面に**乗っている**素材（肩・背に掛かる髪の板など）は**接触運搬**（各列が自分の接触点の下地の場をその場で読む。域外の列は最近縁クランプ = cp18 域外則）。判定は「付いているか・生えているか・乗っているか」の物理所有で行う

## 縫い付けアンカー（閉問題10で獲得。BodyX 系の境界条件）

> 適用前に確認（cp18 で拡張）: 本節はゼロ収束の**ハード型**（服が体に縫い付け/挟み込みされている場合）。羽織り物（ジャケット・コート等の境界なし服）は**フェード帯型**——末尾「服の固定の2型」を参照して型を先に判定すること。

スカートにインしたシャツ等、**衣服が物理的に縫い付け/挟み込みされている端は「ほぼ動かない」**。実装は重力テンプレの鏡像: `field = P(y)·回転場 + (1−P)·アンカー衣服の場`（アンカーが下・自由端が上。static スカートなら収束先 0）。

- **ゼロ収束の可否は「端の物理的所有者」で分岐する**: 自由端（毛先・タイ先端）をゼロに繋ぐと杭/裂けになるが、縫い付け端は正しくゼロへ収束する。タイは縫われていないので先端まで運ばれ、static スカート上を滑走してよい
- 静止帯は薄く（「ほんとにアンカーのライン付近だけ」——ユーザー較正）。フル可動域を際まで伸ばし、直前で急収束
- 体幹の物理枠: 軸 = 脊柱（胴素材の alpha 重心実測）、**「浅い」は変位比で設計・言語化する**（ゲイン比ではない。頭部同調 α との整合は変位で取る）
- **体幹ヨーの縦断面は担い手断面のみ**（3周目 BodyX fix4 で確立）: 体の z は `z(u,y) = ζ·W(y)·dome_u(u; U側(y))`——**縦方向の依存は行別の担い手半幅 W(y) の幾何からしか入らない**。高さ線形のレバー型 `s(y) ∝ (y_地−y)` は傾き（Z 系）の断面形の誤用で、「**首/襟が全場の最大変位**」という診断可能な病理を生む（3周目実走: 首行 50px > 胸。ヨーの最大変位は z 最大 = **肩〜胸帯**が正、首は細い部材で z ≤ 自前半径）。検算 assert = 中心列 |dx| の argmax 行が肩〜胸帯にあること。**ζ（深さ/半幅の楕円比）は襟行の junction 連続から解く**（実走 0.51——物理域 [0.3, 0.9] の中央に着地するのが健全の徴候）。W(y) の非担い手ディップ（コート縁に隠れる肩下・Φ が畳むベルト下フレア）は 06-0 の罠規則で帯別凍結する
- 演出ゲイン（中央の盛り等）も**一致則に従い sin 項のみに掛ける**（縮尺 = 弦は不変）
- 格子: 遷移の折れ点は**格子の節点（行・列）にスナップ**し、式自体を節点上の区分線形で宣言する——再標本化誤差がゼロになる（分割数を増やすより2桁安い）

## 重力テンプレの最終形（閉問題13、y 依存の場 = 回転場で確定）

> 後続獲得のクロスリンク（2周目ブラッシュアップ）:
> - **様式の宣言**: このテンプレで重力の定常を静的リグに焼き込んだモデルは、揺れ dynamics の入力を **positionX 系のみ**にすること（angle 入力は重力の二重計上。レシピ08 §2.1）——様式の選択は2レシピを跨ぐ拘束や
> - 固定線（y_scalp・W 境界の折れ点）は**格子行にスナップ**する（cp16 完結: 直上バイリニア漏れ 22.9→0.00px）
> - **等長性の引き出し（場合により検討、支配的にはしない）**: 特に長い髪の重力追従で「毛が伸びて見える」違和感が出たら、遷移帯に弦成分が混ざっている可能性がある——「列折れ線長 vs rest」の等長検査（レシピ08 §1）を当てる。cp13 実装は満点通過につき予防的再監査はしない

> `field = W(y)·場(u,y) + (1−W(y))·場(u, y_scalp) + plum`

- **3帯モデル**: ①頭皮帯（描かれた生え際まで = 髪が生えている領域。**フル場**——親の回転世界から逸脱しない）②懸垂帯（**生え際の変位ベクトル（X・Y 両成分）を一様に運ぶ**）③最下部（プラム緩流）
- **y_scalp ワンノブ**: W 境界 = 標本行 = 描かれた生え際、に縮退する。測り方 = 毛束メッシュと顔/頭シルエットの**食い込み深度の符号反転行**（解剖学クロスチェック: もみあげ下 ≈ 虹彩下端〜耳下端 / 襟足 = 首上端直上）。センス較正はダイヤルを生成器先頭に置き再調整を1コマンド化
- **遷移は鋭く（数十px）、場の符号反転線（回転場なら pivot の高さ）を絶対に跨がない**——跨ぐと逆向きの場が混ざり運搬が相殺され、物理が逆転して見える。反転線は設計前に引けるので assert を機械化する
- **遷移の内形は C1（多行 smoothstep）**（2周目ユーザー gate で確立）: 1格子セルの線形ランプは両端の微分の折れが「変形が崖のように消える」と知覚される。フェードの幅を格子が表現できない場合は遷移帯の行を細分する（新設の器なら delete→create→keys で rest 恒等のバイト保存を assert）
- **式の形は場非依存、ダイヤルの値は場依存**: Y の球面場では場が y 一様なため3自由度（境界行・遷移の置き場・標本行）が縮退して見えない。y 依存の場に差し替えると独立変数として復活する——**場の差し替え時は各ダイヤルの意味を実測で再証明する**。対偶も成り立つ: **毛束固有のダイヤル（遷移距離 = 自由長の物理）は場を差し替えても不変**——ダイヤルが何に由来するか（場か素材か）で横断可否が決まる（2周目実証: FaceZ で較正したフェードが BodyZ へそのまま渡った）
- **プラム項（作画の嘘の翻訳）**: アニメ髪は腰丈までは重力に従うが、それ超の長さでは「ふわっと見せる」ため付け根→毛先が非鉛直の嘘をつく——正しい物理（形の凍結運搬）がその嘘を暴く長さになったら、`δ = κ·|d_att|·(プラム方向 − rest方向)` で rest の形を緩やかに垂れ直す。κ 控えめ・完全プラム化禁止・最長毛先帯限定・θ 偶
- **前髪も適用対象**（2026-07-04 ユーザー指摘）: 前髪 drawable は「額に張り付く」上部だけでなく横に長く垂れる毛束を含む——**生え際から先は3帯モデルがそのまま適用される**。「前髪は適用外（顔律則）」という Y 時代の記述は、Y では場が y 一様で近似が露見しなかっただけ。Z 以降は前髪にも y_scalp を引くのが正（試走の現行実装は毛先軽減衰の近似のまま = 再走で正規適用する既知の乖離）

## パラメータ族の相似（閉問題11で実証——18塔の設計コスト実質ゼロ）

> 一般形は末尾「場の空間再標本化」（cp18）: 本節の点対点コピー×α は**格子が一致する場合の特殊形**。格子が違えば再標本化（双一次+クランプ+恒等検算）。根拠はどちらも同じ——**場は素材ではなく空間に属する**。

> **新パラメータの場 = α ×（既存パラメータの committed 場）の点対点コピー**

適用条件5点: ①同じ軸方向の回転（BodyX↔FaceX。BodyY↔FaceY が次候補）②「ゲイン違い」という物理的読みが成立（ユーザー証言で裏取り）③ α は接合の連続条件から導出（例: 襟の運搬量 ÷ 顎場実測 = 0.6）④**ソースは committed 現物**（人間補正も形ごと運ばれ、junction は調整でなく構成で繋がる）⑤格子の双子化（domain・次元を複製元と同一に → restControlPoints 一致で点対点移植）。**順序: 転置が済んだものを相似コピーする。**

- **α の健全域と解く方向**（3周目 BodyX fix4 で確立）: α は演出ダイヤルであり相場は「頭の Body 変位 = 顔（FaceX）変位の **1/3〜1/2**」（cp11=0.6・3周目ユーザー較正=0.45）。**junction 連続から解いた α が 1 を大きく超えたら、体側の場が過大/反転している徴候**——その α で組むと頭が体の誤りを増幅転嫁する（3周目実走: α=2.44 → 頭部変位が FaceX ±33° の絵の 2.4 倍・「顔の中身が滑る」窓）。処方 = α を相場で決め打ちし、junction 連続は体側に残る未知数（深さ比 ζ）を解く条件に回す

## 回転デフォーマ rotation2d（閉問題12で確立——画面内回転の正しい器）

- **warp は回転を表現できない**: keyform 補間は格子点の線形補間——端点に厳密な回転場を打っても、中間パラメータでは弦を渡って縮む。**角度を補間する rotation2d だけが真の回転**（検証: 評価後頂点 = R(pivot,θ)·rest の照合、非等分点込み）
- `createRotation2dRigControl`: **pivot 指定可・wrapChildren 対応**。設計対象は pivot 1点と角度スカラーのみ——warp の格子・domain・z プロファイル議論が消滅し、ゲイン調整は数値の updateCurrent
- **ピボット従属性**: pivot を正しく置けば（首かしげ = 首素材 bbox 中心の実測で一発）並進キーは不要。translation は演出の残余ダイヤル。y-down では正角 = 画面時計回り
- **知覚の回転中心は幾何 pivot と一致しないことがある**（2周目実証）: 首かしげの知覚中心は首の付け根で、幾何 pivot（顎下 = 首素材中心）より低い——**差は並進キーで埋める**（pivot 自体を下げると頭部の横振りが過大になる）。この並進は知覚較正なので人間仕上げ領分になりやすい——「translation は残余ダイヤル」の実例
- **剛体グループは1基で一括**（1剛体グループ×1パラメータ=1基。wrapChildren に全塔）
- 回転の**中**の補正ワープの正味は `rot + R·c`（O(θ²) 項）。小角度は無視可、大角度は `c' = R⁻¹·(正味−rot)` で厳密化可
- Z 系の構成 = **回転メンバー**（生えている/貼り付いているもの全部: 顔・造作・帽子・耳・前髪・後頭部）+ **重力ワープ**（垂れ物: 回転の中 = 差分補正 / 外 = 全量——2合成は等価）
- **入れ子は無傷で通る**（閉問題14）: rotation2d の子に rotation2d（BodyZ > FaceZ）。合成 = R_outer∘R_inner を Runtime 階層評価が処理、**両 pivot とも rest 座標のまま**——設計者負担ゼロ。「対角は Runtime 責務」の数学的裏付け
- **空メッシュの罠**: 空メッシュ drawable はデフォーマ配下で bounds ゼロ化し評価から消える——**メッシュ→wrap の順序**を守る
- **回転内差分の厳密形をデフォルトに**（閉問題15）: 補正 c を素朴形 net−rot でなく `c = R⁻¹(p+net)−p` で書く。符号反転を跨ぐ carry では O(θ²) 残差が必ず発動する（実測15px級）。op コストゼロ・Φ=0 帯がアフィン化する副産物つき。**O(θ²) の規模は carry 距離 × 角度で伸びる**——垂れ物が pivot から遠い構成では θ=10° でも数十px・θ=20° で百px 級（2周目実測: 素朴形との差 38px/336px）。「小角度だから無視可」の判定は角度単独でなく carry 距離×角度で行う。**判定の閉形式 = `(1−cos(θ_key/2))·r`**（r = pivot〜点距離。3周目 FaceZ ±33°/BodyZ ±10° の両実測と整合——角度が二次で効くため BodyZ は FaceZ の一桁下。紙上で即決できる）
- **固定線テンプレの統一**（閉問題15で実証）: 髪・ネクタイ・シャツの補正は全て `net = Φ·固定側の場 + (1−Φ)·A`、A = carry（重力系: 固定線の変位を運ぶ）| 0/アンカー場（縫い付け系）。**固定線の実測レシピ3型**: 生え際 = 食い込み符号反転行 / 結び目下端 = 幅プロファイルの極小プラトー / イン線 = 上縁フラット行
- リメッシュ込み変更の回帰は sha256 一致が原理的に不成立——**差分画素の数値局在化**（意図変更領域に閉じることを示す）が正しい手続き。warp レコードの格子フィールド名は `latticeColumns/latticeRows`（payload の transformColumns と別名）

## 奥行きモデル（初期の経験則。球面射影則の断面として保持）

> ⚠ **設計入力にしないこと（2周目 Fable 統制走 2026-07-06 で確定）**: 本節の経験則（目=鼻の8〜9割・0.65T:0.25T 勾配・顎スパイク）は**1周目の結果の要約であって設計規則ではない**。これを設計に使うと0次（変位）だけが写り、1次（縮尺 = foreshortening）が落ちて一致則違反になる——2周目 gate 実測: 目の幅がほぼ不変になり「立体でない」と知覚された。設計は末尾「卵形ドームによる大域場の設計」の点標本化で行う。

> **dx は「回転軸からの奥行き距離」に比例する。** 回転軸は頭部のほぼ不動な要素（頭蓋・帽子級）を通る。最前面の鼻が最大移動、軸より後ろの要素（後ろ髪）は**負 = 逆方向**に動く。dy はほぼゼロ（X回転は水平の営み）。
> 閉問題04で判明した追加則（いずれも球面射影則から導出可能）: **造作先行率 ~1.3**（目・鼻は直下の顔面 field より 25-30% 先行 = 殻の層差の現れ）/ **同行要素の標本化**（眉は直下の目の field を x の一次関数として自 domain 端点で標本化 = 大域 field の局所サンプル）。

- **鼻 = 純平行移動**（warp 0、全格子点一様）。位置だけが仕事
- **顔輪郭 = 移動小・変形大**。仕事は「動く」でなく「シルエットの作り替え」:
  - 上顔面（額〜目の帯）の肉を向く方向へ大きく流す（この帯が field の最大値を持つ)
  - 顎先は独自に向く方向へ振る（最下行に局所スパイク）
  - **髪などに隠れる縁だけ**動かさない（ゼロ固定は「隠れる縁」に限る。顎先スパイクは最下行でも打つ——「外周全固定」と読むと矛盾する。どの縁が隠れるかはレンダで実測）
- **目・眉など顔表面の造作 = 左右非対称**が立体の鍵:
  - 向かう側（縁に近づく要素）: 移動量小 + **横に縮む**（格子の列方向に単調勾配をかける: 顔中心側の列は大きく、縁側の列は小さく動かす。端点比率は中心側:縁側 ≈ 0.65T:0.25T が実証値——勾配自体が横縮みを兼ねる）
  - 遠ざかる側: ほぼ一様に大きく顔面を渡る（微膨張も可）
  - +max と −min のオフセットは**鏡像にならない**（左右の要素で役割が入れ替わる）

## 場の空間再標本化（cp18。相似則の一般化）

同じパラメータ・同じ体の場所・違う素材に場を運ぶとき、committed 現物の変位場を「空間の関数」として読み、新素材の格子位置で標本し直す:

```
p が ソース domain 内: F(p) = ソース格子の双一次補間
p が domain 外:        F(p) = F(clamp(p, domain))   （最近縁の変位を運ぶ = 傾き1継続）
```

- 一様格子 assert + セル snap + 双一次 + クランプの約30行。**恒等検算**（ソース自身の格子点で statePatch 厳密再現）をスクリプト内 assert にすること
- 人間補正キーも空間場として運ばれる（ソースは読むだけ・再生成禁忌のまま）。実証: シャツ襟の人間補正が立ちジップ襟・タートルネックに自然に適合
- 相似則（同一格子の点対点×α）との使い分け: 格子が同じなら相似則、違えば再標本化

## 服の固定の2型（cp18 観察。縫い付けアンカーの拡張）

体の回転に対する服の固定は、**端の物理的所有者**の親戚「服が体に縫い付いとるか、羽織っとるか」で2型に分かれる:

1. **縫い付け固定線**（シャツのイン・ネクタイの結び目）: くっきり境界でゼロ収束（ハード）。固定線実測3型で行を特定
2. **羽織りのフェード帯**（ジャケット・コート等の境界なし服）: 変位はベルト等で急停止させず、**ベルト行の値から腰線へ向けて Φ ランプで滑らかに 0 へ**。縫い付け型の場をクランプ運搬すると「ベルトで固定」に見える（cp18 でユーザーが知覚、好みの領分として受容・未適用）

★ 別素材へ場を運ぶ前に、ソースとターゲットの固定型が同じかを確認。違えば下端をフェード帯で延長する小手術が要る。

### 衣装差分への転置（3周目追試、2026-07-17）

**衣装差分の topwear を通常衣装の BodyX control に同居させない。** 同じ胴体位置・同じ BodyX パラメータでも、衣装が違えば「どこで体から自由になるか」という境界条件が違う。通常衣装が別体スカートとの境でハードに 0 へ収束する一方、ロングジャケット等が同じ高さを連続して跨ぐなら、共有場は衣装の途中で変位を不連続に消し、腰に蝶番があるように見せる。

処方は**親を共有し、BodyX control は衣装ごとに専用化**すること:

1. 通常衣装の committed BodyX 場を上側の正として空間再標本化する
2. ターゲット衣装と同じ `BodyZ` 親の下に、衣装の実 drawable 範囲を覆う専用 warp を作る
3. 固定型が違う下端だけを衣装側の境界条件へ置換する。フェード帯型なら、開始行 `y_s` の場を保持し、終了行 `y_e` まで C1 で 0 へ落とす:

   ```text
   y <= y_s: F_outfit(x,y) = F_source(x,y)
   y_s < y < y_e: F_outfit(x,y) = F_source(x,y_s) * (1 - smoothstep((y-y_s)/(y_e-y_s)))
   y >= y_e: F_outfit(x,y) = 0
   ```

4. topwear と一体の襟・背面・大型ショルダー等も、名前や見た目でなく**実 drawable 所属**を棚卸しして同じ専用場へ移す

共有してよいのは、袖のように topwear から物理的に独立し、素材 bbox・既存 domain・接続関係が通常衣装と同型だと実測できた部品だけ。左右対称や名称一致だけでは共有の根拠にならない。

検証は、① rest sha 完全一致、②ソースの共通格子点で変位厳密一致、③フェード終端行が全点 0、④BodyX ±端の腰帯に折れ・局所停止がない、⑤各 drawable の rig 所有者が1つ、の5点。3周目追試では別衣装2種を専用化し、export / Runtime 実機でユーザーが「圧倒的に動作が自然」と判定した。

- **髪の挟み込みは第3の型 = ソフト型**（3周目 FaceY 人間 gate で確定）: 体と衣服に挟まれた髪の裾をハード型（ゼロ収束）で組むと「裾だけ死んだ髪」に見える。髪は縫われていない——裾は僅かに動き続けるのが正（フェード先 = 0 でなく小さな残存値）。「端の物理的所有者」の判定に「挟まれているが固定されていない」の中間クラスを追加
- **bump アンカー（顎・鼻の突出量）はモデル依存ダイヤル**: 機構転置（鼻の 0.5 等）は初期値にすぎず、見えの過不足は人間 gate で出る（3周目実証: FaceY 顎が「明らかに突出」と知覚され人間補正）。gate 提出の残ダイヤル欄に必ず載せること

## 回転射影の統一原理（2周目ブラッシュアップ。X/Y/Z・眼球の統一導出）

全回転 rigging は一つの原理のインスタンスである: **素材の各点は球面上の点であり、回転 R(Δ) の像を画面平面へ正射影したものが場になる**。点の属性は (u, v, z) = 軸からの横距離・縦距離・想定奥行き。z だけが不可視 = 唯一の設計対象。

| 軸 | 回転 | 射影の像 | 実体 |
|---|---|---|---|
| X（縦軸回り・ヨー） | R_y(Δ) | dx = u(cosΔ−1) + z·sinΔ、dy≈0 | warp 変位場（z プロファイル設計） |
| Y（横軸回り・ピッチ） | R_x(Δ) | dy = v(cosΔ−1) + z·sinΔ、dx≈0 | warp 変位場（z は X と共有 = 軸横断の資産） |
| Z（視線軸回り・ロール） | R_z(Δ) | **射影が面内回転のまま残る**（縮まない） | rotation2d（warp は回転を補間できない） |

- X/Y で z が主役なのは「奥行きが画面に倒れ込む」から。Z で z が消えるのは「回転面が画面と平行」だから——3行は同じ球面回転の3断面
- **眼球（レシピ02）も同族**: 眼球球面の回転射影。ただし可動域が狭く z 変化が知覚下 → **二次元閉面近似 = 純平行移動**で足りる（±11px 実装は満点通過。再実装しない = ユーザー裁定 2026-07-06）
- BodyX / BodyZ は体幹軸の同じ3断面（pivot とゲインが違うだけ → パラメータ族の相似・再標本化）
- 「変位と縮尺の一致則」は本原理の帰結: cos 項（縮尺）と sin 項（変位）は同じ Δ を語らねばならない
- 2周目の使い方: 本章で原理を掴む → 各軸の節（回転射影則 / 軸の転置 / rotation2d）を実装レシピとして引く

## 卵形ドームによる大域場の設計（2周目 Fable 統制走 2026-07-06 確立。X 核 field の正典手順）

> ⚠ **本節の U(y)・縁係留の入力は [レシピ06-0「見えの目録」](06-0-appearance-inventory.md) から引くこと**（3周目確立）。素材 alpha の直接参照は3つのカテゴリ錯誤（素材縁=シルエット / 見えている=シルエット / 素材幅=殻幅）を生む——処方は後述「見えの目録による係留と殻の設計」。本節の「U(y) は行別・側別に alpha 実測」「縁係留は両側 ≈0」は、**素材縁が担い手曲面の limb と一致するモデルでだけ**そのまま成り立つ記述として読むこと。

統一原理「全ての点は自分の (u,z) を持つ」の実装は、**単一の連続な頭部曲面の点標本化**で行う。思想 = **実測較正した卵形の剛体回転の正射影 + 局所レリーフ + シルエット不変性**（ユーザー gate 3ラウンドで確定）。

> `z(u,y) = Z0 · dome_u(u; U(y)) · dome_y(y) + Σ b_i(u,y)`
> `dx = u(cosΔ−1) + g·z·sinΔ` を**全要素（鼻・目・眉・口・輪郭）の全格子点**に適用する。弦項を目・口にも必ず含める——遠側目は鼻より大きく動くのが正（r=√(u²+z²) が鼻より大。実測 −24.9 vs 鼻 −24.6）

- **dome_y = 縦回転軸からの水平距離のドーム**（赤道 = 目の高さ、上極 = 頭頂、下極 = 顎下の放物線）。⚠罠: 正中線を「側面視の突出プロファイル」（額・眉間・鼻根がほぼ平坦）と取り違えると変位が y 方向に一様化し、**正中線が直線のまま顔全体がスライド**して見える。検証 assert: 回転時の正中線変位が「目の帯で最大に膨れる単峰の弧」（額 < 眉間 < 目帯 < 鼻先 > 唇 > 顎先。顎/鼻 ≈ 0.5 前後）
- **U(y) は行別・側別に alpha 実測**。ただし **dome 用 U はシルエット幅ピーク行で凍結**する（頭蓋は目・顎の行では細らない——alpha の細りは髪の食い込みや意匠）。**縁帯用の U は別**（役割が違う。単一 U に兼ねさせると「遠側目の渡り不足」か「縁係留の不完成」のどちらかを必ず踏む）
- **局所レリーフ b_i**（鼻・唇・顎）: コンパクト台の2D bump（例: 鼻 |u|≤15 × y±25 の quartic）。⚠罠: 可分近似 `z_rel(y)·plate(u)` は bump を「行全体の横一列の稜線」にし、**顎が剛体並進して傾きが変わらない**。bump 振幅は**格子透過率を実測して逆算較正**する（5×5 格子で透過率 0.49 の実例——峰 8 が材料で 4 に減る。アンカーは材料レベルの値で合わせる）
- **シルエット不変性は両側**: 球のシルエットは回転不変。縁係留は遠ざかる側 ≈0（+外向き数px ダイヤル＝面の交代の知覚）だけでなく**向かう側も ≈0**。⚠罠: 向かう側に limb の弦式を係留すると内側の順流と縁の逆引きで**符号反転帯**ができ頬骨がえぐれる（実測 18px 級）。さらに放物ドーム自体が 0.65〜0.7U に構造的逆符号域を持つ——**toward 側の主方向床クランプ**（縁帯適用後の dx を回転方向へクランプ）が閉形の対策
- **|u| ≥ U は z=0 クランプ**（負延長は素材外の格子点に非物理変位を吐く。回り込みの知覚は「縁静止 × 中身の流れ」の相対運動が担う——レシピ07 技法1）
- **解像度と遷移幅は別機構**: 場の遷移が急峻なことによる段差は格子細分で**悪化**する（粗格子は偶然のローパス）——遷移帯の拡張で直す。格子値の精度由来の段差は細分で直る。切り分けてから処方（21×21 + 帯拡張 k13..k18 の併用実例）。ランプ帯の節点スナップは**帯幅を縮めない側の行**を選ぶ
- **発行前検算 → 停止**: 格子バイリニア+メッシュ三角形の予測器は評価器と数値一致する（実証済み）。合否 assert を gen 内で先に通し、**破断が予見された op は dry-run にも載せない**
- 機械 assert は**測定点の定義まで基準文に書く**: 材料点かシルエット縁か / 「bbox 中心」= 中心点変位（縁平均は弦項で系統的過小）/ 状態セットの rest は meshes.json 頂点（inspect は default キー適用で汚染）

## 層の座標系と外周殻の設計則（2周目 Fable 統制走 2026-07-06 確立。外周が「張りぼて」になる病理と処方）

> 一般形は [invariants/layered-rotation-shells.md](invariants/layered-rotation-shells.md)（問題設定を跨ぐ不変量）。本節はその FaceX 実装形。

顔核の卵形（前節）を髪・帽子・カーテンへ**流用してはならない**。2周目 gate 実証: 顔スケールの殻を外周に使うと、画面の大半を占める髪の質量が z=0 の死帯に落ち、「両キー同方向の内向きピンチ」だけが残る——左右非対称（回転の証言）が消え、顔だけがスライドする平面の切り抜きに見える。

1. **層の座標系の問い（設計の最初の問い）**: すべての可視素材について「この素材はどの曲面に属するか」を問う。顔・髪・帽子・背面カーテンは**各自の素材の広がりが定義する自前の殻**を持つ入れ子構造である。判定則 = **その層の素材の全点が殻の上に載る**（死帯なし則: 殻半幅はその層の素材半幅+余白から取る。素材内に z=0 の帯を作った時点で、その領域は回転に参加しない紙になる）。顔輪郭文脈の「limb 外は z=0 凍結が物理」は素材が殻に収まる層の話であり、**素材が殻より広いなら殻を広げるのが正**（「単一球 ansatz に素材を収めない」の同族）
2. **層の実効角**: 一致則（変位と縮尺は同じ角を語る）は**層ごとに**適用する。層の実効角は「その層の中心振幅 ÷ その層の殻半径」から読み取られ、外殻ほど半径が大きく実効角は小さい——**弦項（内向き縮み・縮尺）もその実効角のスケールで入れる**。内側の層（顔核）の弦係数を外殻にそのまま使うと素材端が過剰につままれる。実装は「場全体 × 層ゲイン g = 中心振幅/(殻半径·sinΔ)」が簡潔（弦も自動で実効角スケールになる）
3. **振幅の層間整合**: 中心振幅は基準要素（鼻）級を全層が共有する。**「頭が回る」とは画面の可視質量の大半（髪）が回ることであり、顔は髪の球に開いた窓にすぎない**。外周の振幅を顔より落とすと、顔が独りで滑る
4. **背面の鏡像の鏡**: カーテン（z<0）の中心深度は**その層が張り付いている殻**（髪殻）の鏡像から出発する。顔殻の鏡像を使うと逆流が弱くなり奥行きの証言が消える
5. **耳など limb 付属物の弦**は所属層（頭部外周）の実効角で入れる（顔核のフル弦だと過大な内向きが両キーに出る）

## 見えの目録による係留と殻の設計（3周目 claude-chan 周回 2026-07-12 確立。FaceX fix 3ラウンドの蒸留）

入力 = [レシピ06-0](06-0-appearance-inventory.md) の4表（曲面カタログ・張り付き表・縁3分類地図・所有権表）。場の設計はこの目録の**純関数**であり、素材 alpha を場設計で直接参照しない。

### 殻の幅（錯誤3の処方）

- **窓クラスの素材（顔など）の z プロファイルは、担い手曲面の limb まで生きる**。U(y) は曲面カタログの limb（頭蓋 = 耳外端）から取る。窓の縁で z=0 にすると素材端帯が「両キー同向ピンチ」の死帯になる（invariants §2 の病理の実例: 素材右端帯 asym が半減していた）
- **A = g·Z0 のアンカー固定再パラメータ化**: 基準要素（鼻）の材料変位 A を固定し g = A/Z0 で持つと、殻半径の張り替えが1行になり、器官キー（0次）は構成的に不変。変更の無影響証明は「u=0 列のバイト一致」assert が安価で強い
- 委任文の「0次不変」は **keyset の不変**か**場の点値の不変**かを必ず区別して書く（殻半径変更は場の u≠0 点値に必ず波及する）

### 係留（錯誤1・2の処方）

- 係留するのは**縁地図の「可視シルエット区間」だけ**（このクラスの判定は 06-0 で済んでいる。隠れ縁は場のまま流し、隠蔽維持 assert で保護——縁の変位は弦項支配で内向きのため構造的に安全なことが多い）
- **係留値は絶対0でなく接線滑り射影** `(1−nx²)·場(最近縁点)`（n = 輪郭法線）: シルエット不変（法線方向静止）と輪郭に沿う意匠の振り（接線方向滑走）が単一式で両立する。垂直な輪郭では ≈0 に退化するので、そこを係留してよいかは縁分類が先に決める
- **ランプは可視輪郭への符号付き距離場で C1**（法線帯 + 端部接線帯の2パラメータ）。行別 |u| ランプは斜め輪郭で係留境界が階段化しバイリニア混合セルの折れを生む——禁忌。**輪郭の外の格子点は凍結でなく最近縁値のクランプ外挿**（混合セル折れの残り半分が消える）
- 遷移屈曲角 ≈ atan(Δdx/fade長)。fade はメッシュ頂点間隔の3倍以上・格子2セル跨ぎ以上
- keep/release の**縫い目の折れは構造的**で fade 長では消えない——縫い目は遮蔽物の横断点に置き、滑らかさ assert は kept core と縫い目を分離して報告する

### 造作の規定次数 N（準剛体則の拡張。invariants §5 クラス2内部化の精密化）

- 開口造作（目・口）の運搬 = 0次 + 規定1次（前縮）+ **必要なら規定2次**（担い手ドームの Taylor 2次: 弧 x² + 遠近台形 xy。中心で値・勾配ゼロの純曲率増分、g·sinΔ 側スケール、y² は含めない）。「立体感を出したい」の実体はしばしば N=1→2 の引き上げであり、格子細分だけでは1pxも変わらない
- 従属要素（眉）の追従次数は知覚床で分岐: 主要素の高次項が従属要素との間隔に与える開閉量を ±max で数値化し、閾（1.5px 級）超なら追従・以下なら据え置き（決定論分岐・停止不要）
- 剛体（眼鏡）は N に関わらず線形 fit のまま——曲がる目の横で直線を保つ対比こそ物理

### 格子分割の逆算則（旧ヒューリスティクスの置換）

分割数は「domain の広さ」でなく**「表現したい場の次数 × 遷移幅」から逆算**する（ユーザー原理: 三次元的な回転を志すなら分割は必然的に増える）。実証相場: 核 21×21 / 造作 9×9・9×7 / 遷移帯 ≥2 セル。「解像度と遷移幅は別機構」則（前掲）と併用——細分は精度の段差を直すが急峻な場の段差は悪化させる

### gate 提出物の増補

- **格子参加マップを標準装備**（±キーの格子点変位の可視化。**死帯はレンダに写らない**——ユーザーはレンダでなくデフォーマ格子で死帯を発見した、が実証）
- ダイヤル（dome_y 裾・λ・ゲイン・dome_u の断面形）は「ワンノブ + 再走1コマンド」形式で渡す。dome_y の裾比率（額・唇の変位比）はモデル依存ダイヤルであり正典比率（顎/鼻≈0.5 等）は初期値にすぎない
- 既知の残ダイヤル: 放物 dome_u は limb 付近の z を過小評価し toward 側端帯が床クランプで静止しやすい——指摘が出たら円弧系断面への張り替えを検討（√形の limb 無限傾斜棄却の経緯と要衝突検討）

## 顔 gate の追加知見（Astra・2026-09-08）

通常正面素材の左右向きでは、顔の回転に対して首の正面像を変形させない選択がユーザー目視で成立した。首は全軸共通の追従物ではない。ヨーの静止と、俯仰・首かしげで上端を頭へ繋ぎ襟元に収束させる橋渡しを分ける。軸ごとの境界所有を先に決め、首上端の露出を合成画像で確認する。

頬の丸みの指摘には、形の膨張と輪郭位置の移動がある。今回成立したのは、向く側の頬境界を顔面と同方向へ運び、反対側は弱く同方向へ運ぶ場だった。両頬を左右対称に膨らませる場とは異なる。顎への滑らかな減衰を持たせ、正面像を厳密に保つ。境界静止を普遍条件にせず、意図する面の交代を画像で判断する。

承認後に首振り範囲を広げる場合、ワープ変位だけでなく準剛体読者の並進・前縮増分も同じゲイン体系に含める。元の承認形が新しいパラメータ位置で再現されることを実行系で検算すると、表現の変更と可動域の変更を区別できる。個々の振幅・帯位置はモデル専用であり転用しない。

## 入れ子重力補正とパラメータ範囲（Astra 体 gate・2026-09-08）

BodyXへの相似コピーは正規化位置で行う。現在の preset は Face角が±30、Body角が±10なので、生のキー値を同じにすると前縮だけが変位と別の強度になる。実行時の Body差分=α×Face差分を、同じ正規化位置で画像・頂点ともに確認する。

BodyZ用の髪補正を既存FaceZの内側へ置く場合、外側の世界系補正をそのまま加算すると、FaceZでさらに回される。FaceZをR_f、BodyZをR_b、FaceZ適用済み点をq、付け根をaとすると、自由帯の内側補正は R_f^-1[(R_b^-1-I)(q-a)]。頭皮帯との混合を滑らかに行う。既存FaceZのcommitted補正からqを求め、FaceZ×BodyZのキーで座標系変換を表現すれば、既存の首かしげを保ったまま外側の体の傾きへ繋げられる。

逆回転ワープの線形補間と真のrotation2dを組み合わせると、キー間では微小な弦誤差が残る。固定端の許容誤差は半キー間角δとピボット距離rから r(1-cosδ) で上界を取り、端点の厳密一致と区別する。誤差の大きさを画像の画素へ換算して視認性も確認する。数値だけの完全一致のために承認済みの見えを変えない。


## 頬の運搬と反対側の丸み（astra-chan 顔 gate・2026-09-08）

可視輪郭への局所係留で耳から頬への接続が折れるときは、狭い境界帯を重ねず、顔の行全体を滑らかに運ぶ場へ戻す。反対側の眼下・顎が中央へ寄りすぎる場合、顔全体の振幅を下げる前に、その側だけの丸みを広い滑らかな場で戻す。向く側の場と正面の恒等を保存し、輪郭の連続性と顔がえぐれて見えないことを両方向・中間姿勢で判断する。


## 一枚の上着の固定と自由を分ける（astra-chan 体gate・2026-09-08）

シャツ・腰布・短い上着が同一素材の場合、中央を腰へ収め、左右の上着の裾は自由に残す。固定/自由の境目が白い裾の内端を横切ると、裾だけが腰へ引き込まれ尖る。境目を腰布の内側へ移し、可視の上着の縁全体を同じ自由領域へ入れると、裾の丸みを維持できる。帯幅は素材の見えの目録から決め、モデルごとの値を転用しない。

格子のセルが正方向でも、場を標本した実メッシュの長い三角形は折り返す場合がある。この体gateでは目視の尖りと実メッシュの反転が同じ箇所で起きた。実行系のメッシュを、BodyXとBodyZの同時端点でも検査する。格子だけの検証や反転閾の緩和で済ませない。
