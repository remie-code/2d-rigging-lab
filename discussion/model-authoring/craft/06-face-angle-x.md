# レシピ 06: Face Angle X（顔の横回転 rigging）

> **読み順の推奨（2周目ブラッシュアップ）**: 初読は末尾の「**回転射影の統一原理**」から入ること。本文の各節（回転射影則・軸の転置・rotation2d）はすべて統一原理の3軸インスタンスであり、本文は導出の歴史的記録として保持している。

顔の横回転パラメータ（`param_face_angle_x`、preset、レンジは parameters を確認。min=画面左向き / max=画面右向き）に対し、要素ごとの FaceX 層デフォーマを積んで擬似3D回転を作る。閉問題03の蒸留。

## 前提状態

- 対象要素のメッシュ・下位リグ（目の開閉塔など）が完成済み
- 対象要素の選定: 最小核は「鼻・顔輪郭・目」。鼻は**基底鼻**（face 階層の part に属する nose。表情セット配下の nose 群とは別物なので partId で見分ける）

## 構造

- **要素ごとに FaceX 専用デフォーマを1枚**作る（1要素×1パラメータ = 1層の原則）
- **格子解像度の規則**（2026-07-03 ユーザー経験則）:
  - **ベジエ分割数は transform 分割数と揃える**（transform 7×7 なら bezier 7×7）
  - 分割数は「domain の広さ × 表現したい field の曲率」で決める。**余裕を持って要素を覆う domain なら、相場（5×5/7×7）より2段階細かく**（9×9〜11×11 級）。粗い格子は回転射影則の曲率——特に端の縮み帯——を区分線形で潰す（分解能不足）
  - 判断軸の真意は**「素材の大きさ × field の曲率」**であり、domain の余裕は代理指標にすぎない（閉問題05: 後ろ髪はタイトな domain でも幅広素材 × z<0 の曲率で 11×11 が要った）
  - 逆に domain を要素にタイトに絞るなら相場の分割数でよい
- 既存リグ塔（例: 目の状態デフォーマ群）の上に被せる場合は `createWarpDeformer` の **`wrapChildren`**（`[{kind:"rigControl",id:...}...]`）で挿入する。既存塔の parentId が自動で書き換わる。**`wrapChildren` は `childDrawableIds`/`childRigControlIds` と併用不可**（排他モード）。**挿入後は既存機能の回帰確認が必須**（開閉・眼球移動・マスクを合成レンダ1枚で見る）
- 素の drawable（鼻・顔）は `childDrawableIds` 直接指定でよい
- domain = 子要素の**生成後の実頂点範囲**の union + 移動量ぶんのマージン（宣言 bounds は実頂点範囲より狭いことがある。メッシュ生成後に測り直す）

## ゲインと構造の分離（2026-07-03 盲目再構成実験で確立）

**field = 構造 × ゲイン。**

- **構造** = 奥行き比率・左右非対称・field の位相（帯・スパイク・固定縁）。客観であり、本レシピの原理から導出可能（盲目実験で内部比率が完成参照と誤差2割以内で一致）
- **ゲイン** = 全体の振幅スカラー。**モデルオーナーの演出意図**であり正しさの軸ではない（控えめ=上品 / 大きめ=楽しい、はどちらも満点になりうる）
- 手順: **構造をゲイン1で組み、ユーザー gate でゲインのダイヤルを回す**。ゲイン1の基準 = 鼻の振幅 ≈ 頬幅の10%（上品な回転として満点実証済み。演出強めなら〜20%）。調整は全 FaceX キーへの一様乗算（updateCurrent 一括）で機械的に反映できる
- 完成参照から抽出する場合も同じ分離を適用する: **比率は essence（持ち越せる）、絶対値はゲイン込みの較正データ（そのモデル専用）**

## 回転射影則（最上位原理。2026-07-03 ユーザーとの対話3往復で最終形に到達）

**全ての点は自分の (u, z) を持つ**: u = 回転軸からの横距離（画面上で見える。u = x − cx）、z = 想定奥行き（見えない。**これが唯一の設計対象**）。「球の内側/外側」という概念は無い——素材そのものが幾何であり、半径 r = √(u²+z²) は点ごとに定義される。

縦軸回りの**有限回転** Δ に対する画面X変位:

> **dx(点) = u·(cosΔ − 1) + z(点)·sinΔ**

この一本が全現象を吐く:

- 中心（u=0, z最大）: z·sinΔ で最大移動
- **端（z≈0）: u·(cosΔ−1) で左右両端が対称に内側へ縮む**（Δ=30° で −0.134u。「縁は固定」は微分近似の誤り——死帯を作ってはならない。完全静止するのは回転軸上のみ）
- 幅を持つ全要素の伸縮（foreshortening）: 点ごとの dx 差として自動発生
- 背面（z<0）: 逆方向移動（後ろ髪）
- 突出部（z 局所大）: 鼻・顎先の大移動

**よくある誤り2つ**（閉問題04で実際に踏んだ）:
1. **微分近似 dx = Δ·z（cosθ 減衰）で止まる** → limb に死帯ができ、「描画範囲内なのに全く動かない境界」が生まれる。弦の式（有限回転）を使うこと
2. z(x) = √(R²−u²) の**単一球 ansatz に素材を無理に収める** → 球より広い素材（髪など）が定義域外に落ちて凍る。z は点ごとに描くもの（球・円筒は初期 ansatz に過ぎない）

**設計手順**: 要素ごとに奥行きプロファイル z(x)（必要なら z(x,y)）を描く → 式で field を決定論的に生成 → 目視イテレーション。層の目安: 鼻・顎（突出）> 前髪・帽子表面 > 顔面造作（目・眉・口）> 顔輪郭 > 頭蓋（軸近傍）> 後ろ髪（z<0）。

**z プロファイルの実装知見**（閉問題04 fix2 で実証）:
- 横断面の ansatz は**放物線 1−(u/U)² が扱いやすい**。球の √(1−u²) は limb で傾きが無限大になり、粗い格子で折り返し（せん断）を起こす危険がある（検算の上で棄却された実例）
- 縦方向: 頭部は球冠（頂点=素材最上端、赤道=目の高さ相場）、**そこから下の垂れ房は円筒延長**（付け根の並進を運ぶ。髪先まで球で減衰させると付け根と先で裂ける）
- **ゲインの適用順**: 式は物理スケール（実寸 U、実角 Δ）で評価してから、正典への整合は一様乗算で最後にかける（中心ピークを基準要素——鼻——に同期させる）

**決定論で決まらないダイヤル（演出領域）**: ①cx（軸の位置）② z プロファイルの形と層間差（髪が「外側に載って見える」深さ差はいくらか）③全体ゲイン（別掲）。法則が形を保証し、ダイヤルは目視とユーザー gate で決める。

## 同一モデル内拡張の作法（2要素目以降。閉問題05で確立）

既存 FaceX 要素が居るモデルへ要素を足すときは、**既存 field から物理枠（cx・U・Δ・ゲイン g）を復元し、z プロファイルだけを設計する**。基準要素（鼻）のキー振幅がゲインの、既存デフォーマの生成式が軸と殻幅の一次ソース。同じ dx± 式に新しい z を差すだけで、ゲイン・弦/z 比・軸・層間連続性が全部自動整合する。外部数値の持ち込みは不要——**モデル自身が唯一の較正基準**。

## 頭部外周の z 域テンプレ（閉問題05で実証。全て回転射影則への代入）

- **耳（limb、z≡0）**: コロナル面上の付属物 → 弦の項のみが残り、**±両キーが同一 patch になる**（cos の偶性）。微小移動 + 内向き縮み
- **垂れ房**: 直上の既存 field（前髪）と**完全同一式**でよい（層差ダイヤル = 0 の選択）。付け根の連続性が構成的に成立する。層差を付けたくなったらそれは演出ダイヤル②の話
- **後ろ髪カーテン（z<0）**: `z = −Z·(1−(u/U_spread)²)·s(y)`。中心深度 Z は前殻の鏡像が相場、**U_spread は素材の広がり全幅で頭殻 U とは別物**（単一球 ansatz の罠の z<0 版）。弦の項の u は根本写像 `u·(U_head/U_spread)` で圧縮して評価する（毛は根本で頭に付いている）。**左右分割素材は単一の大域式で跨ぐ**——seam 連続が構成的に出る
- **後頭部層（帽子と後ろ髪の間の表層）**: 頭蓋裏面の素材。上端（帽子縁。帽子が未 rig なら静止物に合わせる暫定）で振幅→0、下端でカーテン付け根と**式レベルで一致**させて同期する。**逆方向の微小ドリフトが前髪との差動パララックスになり、横向き時のチラ見えを生む**（受動的な露出でなく能動的な差動が立体感の源泉）

## 隠蔽維持拘束（閉問題05 fix で獲得。振幅の上限則）

**rest で隠れている描き縁（髪の付け根など）は、全キーでも隠れ続けなければならない。** 破れると素材が「浮遊物」に見える（頭から生えている前提が崩れる）。

- **罠は二重苦**: 隠される側が流れるのと同時に、**遮蔽層自身も弦の項で縮んで退く**。露出は両者の和で開く（実測例: 付け根 −25px + 前髪縁の後退 +10px = 35px の露出）
- 上限は ±max レンダで遮蔽の余白を**実測**して決める（宣言 bounds でなくレンダ）
- **実装作法**: 隠蔽拘束は縦プロファイル s(y) に混ぜず、**独立の乗数 q(y)** として被せる。縦は3帯——付け根 = 遮蔽余白まで絞る / 毛先の自由帯 = 1 / 間は smoothstep。絞りの強さがワンノブになり、gate 補正が updateCurrent 一括で済む

## 軸の転置（Face Angle Y で実証。2026-07-04、閉問題07〜09）

法則は軸を替えて転置できる: **dy = v·(cosΔ−1) + z·sinΔ**、v = y − cy（縦の回転軸。耳の高さ相場——実証値は目の高さの X 赤道と 4px 以内で一致）、dx ≈ 0。実測では**本レシピの8割が軸の読み替えだけで走った**（弦・偶性・放物線 ansatz・格子規則・鼻からのゲイン手順・wrap 作法）。特に**殻 z は軸横断の資産**——X の z プロファイルをそのまま sinΔ 項に差すと、層順・ゲイン整合・seam 連続が全部引き継がれる。

**転置で折れるもの（判定基準 = 規則の出自）**:

- **実測由来の規則は軸ごとに測り直す**: 「顔輪郭の外周ゼロ」は X での隠蔽実測の結果であって法則ではない（Y の顔は「殻の皮膚流し + 顎の弦」クラスへ移籍）。q(y) 隠蔽絞りも軸ごとに要否を再実測（独立乗数だから外せる）
- **例外則は幾何的根拠の存在を問う**: 縁ループの dz→dy 結合は「ループが回転面に直交する」という X の幾何の産物で、Y では構造的に消滅する
- **縦殻は軸非対称**: 上極（頭頂）と下極（顎の巻き込み点）は独立のダイヤル
- **ゲインは方向別2値**（実証: 俯き = フル正典 / 見上げ = 0.8倍——未描画面（顎裏）を晒す方向を絞る）
- 先行率はクラス依存（普遍定数ではない）
- **係留先の所有者は軸ごとに再同定**（X の occiput 係留が Y では前髪殻係留になった実例）
- ポリシー（2026-07-04 ユーザー決定）: **1デフォーマ = 1パラメータ責務**。新パラメータは専用デフォーマを新設し既存塔を wrapChildren で包む（新パラメータが親）。**対角成分は Runtime の階層評価の責務 = 設計対象外**（監視レンダのみ。問題が出たら人間が直す）

## 変位と縮尺の一致則（閉問題07 fix で獲得。ゲインの復号規則）

見る側は回転角を2経路で読む: ①**要素間の変位**（sinΔ 系）②**要素内の縮尺** = foreshortening（(cosΔ−1) 系）。**ゲイン g は sin 系にだけ掛けてよい**——cos 系は二次なので g 倍すると知覚の下に沈み、変位が語る角度と縮尺が語る角度が矛盾して破綻に見える（顎は大きく傾いたと語るのに目が潰れない、等）。縮尺は「**変位から読み取られる実効角**」の強度で入れる。X の目の 0.65T:0.25T 勾配の正体はこれ（弦の項の半身であって任意の演出ではない）。

- 「field = 構造 × ゲイン」の精密化: **変位 = 構造 × ゲイン / 縮尺 = 読み取り角の強度のまま**
- **標本化則は1次（勾配）にも及ぶ**: 目だけ潰すと眉-目間隔が逆に開いて悪化する。眉は目の field の 0次+1次を標本化する
- 実装: **平均変位保存アンカー**（開口中心基準の加算勾配）——gate 済みのゲシュタルト振幅を壊さず縮尺だけ足せる
- 対偶: 軸上のピボット要素（v≈0 の耳など）には縮尺を適用しない（変位が語らないものに縮尺だけ語らせない）
- ゲイン非対称なら縮尺も非対称（実証: 俯き10% / 見上げ6% = 実効角 30°/23.6° に一致）

## 垂れ物の重力テンプレ（閉問題08 で獲得。Y 系の垂れ物）

**重力減衰は「動きの消滅」ではなく「回転性の消滅」**。重力は毛束の振り回し（Θ 依存成分）を殺すが、毛束は付け根に付いている以上**並進は毛先まで運ばれる**。毛先の極限 = 自分の付け根の変位のコピー（純平行移動）:

> `field(u,y) = W(y)·球面場(u,y) + (1−W(y))·球面場(u, y_root(u))`

- **「付け根の並進を運ぶ」は軸横断の不変量**（X の円筒延長則と同一物）。収束先を空間ゼロにすると X では「裂け」、Y では「毛先が見えない杭に捕らわれる」として同じ誤りが別の絵で出る
- **W(y) は回転性成分の混合比**であって変位の減衰率ではない。機械検証の型: 恒等式 `field − root = W·(球面場 − root)`
- **W 境界 = 頭蓋接触を失う行**（房は顎・カーテンは襟足）、**遷移距離 ∝ 自由長**。y_root は W 境界の再利用で足りる（減衰の始点と並進コピーの標本行は同じ物理的意味）
- 前髪は適用外: 額に張り付く = 顔に律則されほぼフル追従（重力に勝つ）
- **運搬の2型**（閉問題10で獲得）: 縦素材は**列コピー**、斜行素材（腕など）は**点アンカー**（付け根1点の場を全体に運ぶ。列コピーだと先端が弦クランプに捕まる）

## 縫い付けアンカー（閉問題10で獲得。BodyX 系の境界条件）

> 適用前に確認（cp18 で拡張）: 本節はゼロ収束の**ハード型**（服が体に縫い付け/挟み込みされている場合）。羽織り物（ジャケット・コート等の境界なし服）は**フェード帯型**——末尾「服の固定の2型」を参照して型を先に判定すること。

スカートにインしたシャツ等、**衣服が物理的に縫い付け/挟み込みされている端は「ほぼ動かない」**。実装は重力テンプレの鏡像: `field = P(y)·回転場 + (1−P)·アンカー衣服の場`（アンカーが下・自由端が上。static スカートなら収束先 0）。

- **ゼロ収束の可否は「端の物理的所有者」で分岐する**: 自由端（毛先・タイ先端）をゼロに繋ぐと杭/裂けになるが、縫い付け端は正しくゼロへ収束する。タイは縫われていないので先端まで運ばれ、static スカート上を滑走してよい
- 静止帯は薄く（「ほんとにアンカーのライン付近だけ」——ユーザー較正）。フル可動域を際まで伸ばし、直前で急収束
- 体幹の物理枠: 軸 = 脊柱（胴素材の alpha 重心実測）、**「浅い」は変位比で設計・言語化する**（ゲイン比ではない。頭部同調 α との整合は変位で取る）
- 演出ゲイン（中央の盛り等）も**一致則に従い sin 項のみに掛ける**（縮尺 = 弦は不変）
- 格子: 遷移の折れ点は**格子の節点（行・列）にスナップ**し、式自体を節点上の区分線形で宣言する——再標本化誤差がゼロになる（分割数を増やすより2桁安い）

## 重力テンプレの最終形（閉問題13、y 依存の場 = 回転場で確定）

> 後続獲得のクロスリンク（2周目ブラッシュアップ）:
> - **様式の宣言**: このテンプレで重力の定常を静的リグに焼き込んだモデルは、揺れ dynamics の入力を **positionX 系のみ**にすること（angle 入力は重力の二重計上。レシピ08 §2.1）——様式の選択は2レシピを跨ぐ拘束や
> - 固定線（y_scalp・W 境界の折れ点）は**格子行にスナップ**する（cp16 完結: 直上バイリニア漏れ 22.9→0.00px）
> - **等長性の引き出し（場合により検討、支配的にはしない）**: 特に長い髪の重力追従で「毛が伸びて見える」違和感が出たら、遷移帯に弦成分が混ざっている可能性がある——「列折れ線長 vs rest」の等長検査（レシピ08 §1）を当てる。cp13 実装は満点通過につき予防的再監査はしない

> `field = W(y)·場(u,y) + (1−W(y))·場(u, y_scalp) + plum`

- **3帯モデル**: ①頭皮帯（描かれた生え際まで = 髪が生えている領域。**フル場**——親の回転世界から逸脱しない）②懸垂帯（**生え際の変位ベクトル（X・Y 両成分）を一様に運ぶ**）③最下部（プラム緩流）
- **y_scalp ワンノブ**: W 境界 = 標本行 = 描かれた生え際、に縮退する。測り方 = 毛束メッシュと顔/頭シルエットの**食い込み深度の符号反転行**（解剖学クロスチェック: もみあげ下 ≈ 虹彩下端〜耳下端 / 襟足 = 首上端直上）。センス較正はダイヤルを生成器先頭に置き再調整を1コマンド化
- **遷移は鋭く（数十px）、場の符号反転線（回転場なら pivot の高さ）を絶対に跨がない**——跨ぐと逆向きの場が混ざり運搬が相殺され、物理が逆転して見える。反転線は設計前に引けるので assert を機械化する
- **式の形は場非依存、ダイヤルの値は場依存**: Y の球面場では場が y 一様なため3自由度（境界行・遷移の置き場・標本行）が縮退して見えない。y 依存の場に差し替えると独立変数として復活する——**場の差し替え時は各ダイヤルの意味を実測で再証明する**
- **プラム項（作画の嘘の翻訳）**: アニメ髪は腰丈までは重力に従うが、それ超の長さでは「ふわっと見せる」ため付け根→毛先が非鉛直の嘘をつく——正しい物理（形の凍結運搬）がその嘘を暴く長さになったら、`δ = κ·|d_att|·(プラム方向 − rest方向)` で rest の形を緩やかに垂れ直す。κ 控えめ・完全プラム化禁止・最長毛先帯限定・θ 偶
- **前髪も適用対象**（2026-07-04 ユーザー指摘）: 前髪 drawable は「額に張り付く」上部だけでなく横に長く垂れる毛束を含む——**生え際から先は3帯モデルがそのまま適用される**。「前髪は適用外（顔律則）」という Y 時代の記述は、Y では場が y 一様で近似が露見しなかっただけ。Z 以降は前髪にも y_scalp を引くのが正（試走の現行実装は毛先軽減衰の近似のまま = 再走で正規適用する既知の乖離）

## パラメータ族の相似（閉問題11で実証——18塔の設計コスト実質ゼロ）

> 一般形は末尾「場の空間再標本化」（cp18）: 本節の点対点コピー×α は**格子が一致する場合の特殊形**。格子が違えば再標本化（双一次+クランプ+恒等検算）。根拠はどちらも同じ——**場は素材ではなく空間に属する**。

> **新パラメータの場 = α ×（既存パラメータの committed 場）の点対点コピー**

適用条件5点: ①同じ軸方向の回転（BodyX↔FaceX。BodyY↔FaceY が次候補）②「ゲイン違い」という物理的読みが成立（ユーザー証言で裏取り）③ α は接合の連続条件から導出（例: 襟の運搬量 ÷ 顎場実測 = 0.6）④**ソースは committed 現物**（人間補正も形ごと運ばれ、junction は調整でなく構成で繋がる）⑤格子の双子化（domain・次元を複製元と同一に → restControlPoints 一致で点対点移植）。**順序: 転置が済んだものを相似コピーする。**

## 回転デフォーマ rotation2d（閉問題12で確立——画面内回転の正しい器）

- **warp は回転を表現できない**: keyform 補間は格子点の線形補間——端点に厳密な回転場を打っても、中間パラメータでは弦を渡って縮む。**角度を補間する rotation2d だけが真の回転**（検証: 評価後頂点 = R(pivot,θ)·rest の照合、非等分点込み）
- `createRotation2dRigControl`: **pivot 指定可・wrapChildren 対応**。設計対象は pivot 1点と角度スカラーのみ——warp の格子・domain・z プロファイル議論が消滅し、ゲイン調整は数値の updateCurrent
- **ピボット従属性**: pivot を正しく置けば（首かしげ = 首素材 bbox 中心の実測で一発）並進キーは不要。translation は演出の残余ダイヤル。y-down では正角 = 画面時計回り
- **剛体グループは1基で一括**（1剛体グループ×1パラメータ=1基。wrapChildren に全塔）
- 回転の**中**の補正ワープの正味は `rot + R·c`（O(θ²) 項）。小角度は無視可、大角度は `c' = R⁻¹·(正味−rot)` で厳密化可
- Z 系の構成 = **回転メンバー**（生えている/貼り付いているもの全部: 顔・造作・帽子・耳・前髪・後頭部）+ **重力ワープ**（垂れ物: 回転の中 = 差分補正 / 外 = 全量——2合成は等価）
- **入れ子は無傷で通る**（閉問題14）: rotation2d の子に rotation2d（BodyZ > FaceZ）。合成 = R_outer∘R_inner を Runtime 階層評価が処理、**両 pivot とも rest 座標のまま**——設計者負担ゼロ。「対角は Runtime 責務」の数学的裏付け
- **空メッシュの罠**: 空メッシュ drawable はデフォーマ配下で bounds ゼロ化し評価から消える——**メッシュ→wrap の順序**を守る
- **回転内差分の厳密形をデフォルトに**（閉問題15）: 補正 c を素朴形 net−rot でなく `c = R⁻¹(p+net)−p` で書く。符号反転を跨ぐ carry では O(θ²) 残差が必ず発動する（実測15px級）。op コストゼロ・Φ=0 帯がアフィン化する副産物つき
- **固定線テンプレの統一**（閉問題15で実証）: 髪・ネクタイ・シャツの補正は全て `net = Φ·固定側の場 + (1−Φ)·A`、A = carry（重力系: 固定線の変位を運ぶ）| 0/アンカー場（縫い付け系）。**固定線の実測レシピ3型**: 生え際 = 食い込み符号反転行 / 結び目下端 = 幅プロファイルの極小プラトー / イン線 = 上縁フラット行
- リメッシュ込み変更の回帰は sha256 一致が原理的に不成立——**差分画素の数値局在化**（意図変更領域に閉じることを示す）が正しい手続き。warp レコードの格子フィールド名は `latticeColumns/latticeRows`（payload の transformColumns と別名）

## 奥行きモデル（初期の経験則。球面射影則の断面として保持）

> **dx は「回転軸からの奥行き距離」に比例する。** 回転軸は頭部のほぼ不動な要素（頭蓋・帽子級）を通る。最前面の鼻が最大移動、軸より後ろの要素（後ろ髪）は**負 = 逆方向**に動く。dy はほぼゼロ（X回転は水平の営み）。
> 閉問題04で判明した追加則（いずれも球面射影則から導出可能）: **造作先行率 ~1.3**（目・鼻は直下の顔面 field より 25-30% 先行 = 殻の層差の現れ）/ **同行要素の標本化**（眉は直下の目の field を x の一次関数として自 domain 端点で標本化 = 大域 field の局所サンプル）。

- **鼻 = 純平行移動**（warp 0、全格子点一様）。位置だけが仕事
- **顔輪郭 = 移動小・変形大**。仕事は「動く」でなく「シルエットの作り替え」:
  - 上顔面（額〜目の帯）の肉を向く方向へ大きく流す（この帯が field の最大値を持つ)
  - 顎先は独自に向く方向へ振る（最下行に局所スパイク）
  - **髪などに隠れる縁だけ**動かさない（ゼロ固定は「隠れる縁」に限る。顎先スパイクは最下行でも打つ——「外周全固定」と読むと矛盾する。どの縁が隠れるかはレンダで実測）
- **目・眉など顔表面の造作 = 左右非対称**が立体の鍵:
  - 向かう側（縁に近づく要素）: 移動量小 + **横に縮む**（格子の列方向に単調勾配をかける: 顔中心側の列は大きく、縁側の列は小さく動かす。端点比率は中心側:縁側 ≈ 0.65T:0.25T が実証値——勾配自体が横縮みを兼ねる）
  - 遠ざかる側: ほぼ一様に大きく顔面を渡る（微膨張も可）
  - +max と −min のオフセットは**鏡像にならない**（左右の要素で役割が入れ替わる）

## 量の設計手順（完成参照が無い場合）

1. 巻尺で頬幅（顔メッシュ bbox 幅）と各要素の rest bbox を取る
2. **鼻から決める**: ゲイン1の基準（鼻振幅 ≈ 頬幅の10%）で三点キーを打ち、±max の sweep で「向いた」と読めるか確認（鼻は判定が一番簡単な要素や——位置だけ見ればええ)。ゲイン調整は gate 後のダイヤルに委ねる
3. 鼻の移動量を基準に、奥行き順で各要素の比率を内挿する（目・口・眉は鼻の8〜9割見当から開始、輪郭の流しは鼻より大きくてよいが**輪郭全体の平均移動は小さく**、後ろ髪は負)
4. ★各要素を足すたびに**複数要素同時の sweep** でゲシュタルト判定（単独要素の正誤は人間にも判定困難——位置関係の整合で見る）

## 完成参照（ref 等）がある場合の移植作法

参照の keyformSets から field を抽出できる。domain と格子次元を参照と同一にすれば restControlPoints が一致し patch を点対点移植できる（**移植前に格子一致アサーション必須**）。不一致なら field を関数化して自前格子に区分線形で再標本化する。数値はモデル専用の較正データであり、他 PSD へは持ち越さない——持ち越すのは本レシピの言語だけ。

## 場の空間再標本化（cp18。相似則の一般化）

同じパラメータ・同じ体の場所・違う素材に場を運ぶとき、committed 現物の変位場を「空間の関数」として読み、新素材の格子位置で標本し直す:

```
p が ソース domain 内: F(p) = ソース格子の双一次補間
p が domain 外:        F(p) = F(clamp(p, domain))   （最近縁の変位を運ぶ = 傾き1継続）
```

- 一様格子 assert + セル snap + 双一次 + クランプの約30行。**恒等検算**（ソース自身の格子点で statePatch 厳密再現）をスクリプト内 assert にすること
- 人間補正キーも空間場として運ばれる（ソースは読むだけ・再生成禁忌のまま）。実証: シャツ襟の人間補正が立ちジップ襟・タートルネックに自然に適合
- 相似則（同一格子の点対点×α）との使い分け: 格子が同じなら相似則、違えば再標本化

## 服の固定の2型（cp18 観察。縫い付けアンカーの拡張）

体の回転に対する服の固定は、**端の物理的所有者**の親戚「服が体に縫い付いとるか、羽織っとるか」で2型に分かれる:

1. **縫い付け固定線**（シャツのイン・ネクタイの結び目）: くっきり境界でゼロ収束（ハード）。固定線実測3型で行を特定
2. **羽織りのフェード帯**（ジャケット・コート等の境界なし服）: 変位はベルト等で急停止させず、**ベルト行の値から腰線へ向けて Φ ランプで滑らかに 0 へ**。縫い付け型の場をクランプ運搬すると「ベルトで固定」に見える（cp18 でユーザーが知覚、好みの領分として受容・未適用）

★ 別素材へ場を運ぶ前に、ソースとターゲットの固定型が同じかを確認。違えば下端をフェード帯で延長する小手術が要る。

## 回転射影の統一原理（2周目ブラッシュアップ。X/Y/Z・眼球の統一導出）

全回転 rigging は一つの原理のインスタンスである: **素材の各点は球面上の点であり、回転 R(Δ) の像を画面平面へ正射影したものが場になる**。点の属性は (u, v, z) = 軸からの横距離・縦距離・想定奥行き。z だけが不可視 = 唯一の設計対象。

| 軸 | 回転 | 射影の像 | 実体 |
|---|---|---|---|
| X（縦軸回り・ヨー） | R_y(Δ) | dx = u(cosΔ−1) + z·sinΔ、dy≈0 | warp 変位場（z プロファイル設計） |
| Y（横軸回り・ピッチ） | R_x(Δ) | dy = v(cosΔ−1) + z·sinΔ、dx≈0 | warp 変位場（z は X と共有 = 軸横断の資産） |
| Z（視線軸回り・ロール） | R_z(Δ) | **射影が面内回転のまま残る**（縮まない） | rotation2d（warp は回転を補間できない） |

- X/Y で z が主役なのは「奥行きが画面に倒れ込む」から。Z で z が消えるのは「回転面が画面と平行」だから——3行は同じ球面回転の3断面
- **眼球（レシピ02）も同族**: 眼球球面の回転射影。ただし可動域が狭く z 変化が知覚下 → **二次元閉面近似 = 純平行移動**で足りる（±11px 実装は満点通過。再実装しない = ユーザー裁定 2026-07-06）
- BodyX / BodyZ は体幹軸の同じ3断面（pivot とゲインが違うだけ → パラメータ族の相似・再標本化）
- 「変位と縮尺の一致則」は本原理の帰結: cos 項（縮尺）と sin 項（変位）は同じ Δ を語らねばならない
- 2周目の使い方: 本章で原理を掴む → 各軸の節（回転射影則 / 軸の転置 / rotation2d）を実装レシピとして引く
