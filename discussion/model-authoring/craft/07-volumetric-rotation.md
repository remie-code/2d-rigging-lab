# レシピ 07: 立体物の回転表現（optional 拡張）

レシピ06（回転射影則）の拡張。**対象領域が「立体物極」に寄っているとき**にロードする。閉問題06（帽子・眼鏡 = FaceX アクセサリ）の蒸留だが、適用条件はアクセサリという物のクラスではなく**領域の性質**である。

## 適用判定: ステッカー↔立体物のスペクトラム

すべての描かれた要素は二つの極の間に座る:

- **ステッカー極**: 描かれた物質が常に全部見えている。場 = 回転射影則を各点に適用するだけで完結（表情・顔造作・前髪中心部）
- **立体物極**: 描かれた絵は曲面の射影の一部にすぎず、**回転が「見える面の交代」を伴う**（帽子側面・立ち付属物・接続ループ）

判定の要点:

- **座席は物単位でなく領域単位**。帽子は前面中央ならステッカー近似が効き、側面・縁・付属物ほど立体の理屈が支配する。同じ一枚の drawable の中で支配則が遷移する
- 髪は中間。前髪中心はステッカー（06 の球殻で足りる）、**房は立体寄り——本レシピの正規の適用対象**（試走では未適用。再走で取り組む）
- 隠面の出現の実装は2通り: **変形で出す**（本レシピの技法群）/ **パーツで出す**（見えてくる面そのものを素材として追加する。後頭部パーツ = cp05 の実例）

## 技法カタログ（全て回転射影則への代入または拡張。閉問題06で全て実証済み）

### 1. シルエット縁（張りぼての防止）

体積物の描かれた輪郭は物質の端ではなく**視線が曲面に接する軌跡**。回転しても縁は頭部シルエットにほぼ張り付き、**物質（皺・柄・バッジ）が縁を通り抜けて流れる**。縁ごと動かすと「平面のカードが回っている」に見える。

- 実装: 行別の実シルエット半幅 W(y) をテクスチャ alpha から実測し、`w=clamp((|u|−0.55W)/(0.45W))` ランプで縁列を隣接層（頭部シルエット所有者）の場へブレンド。係留先は「絶対静止」でなく**「シルエット所有者と同じ式」**（擬似3Dでは頭ごと僅かに動く）
- 縁（微動）と内部（フル流）の**相対運動**が「側面が見えてきた」の知覚を生む

### 2. 傾いた接続ループ（dz→dy 結合）

被り物の接続線は傾いた3Dループ（深かぶり = 前は額・後ろは下がる）。傾き k が dz を dy に結合し **dy = −k·u·sinΔ** が生まれる——「X回転は dy≈0」の例外則。

- 向く側の境界は上がり（接続面が奥へ回って隠れる）、逆側は下がる（背面弧が現れ、深くかぶった形が露出）。下がる側で背面パーツが覗いてよい
- k は演出ダイヤル（実証値 0.05 = 縁端 5px 級から目視較正）

### 3. 立ち付属物の錐断面（面の交代）

猫耳などの立ち付属物は三角錐の射影。「付け根の並進を運ぶ」（06 の凍結帯）は平板ステッカー扱いで、立体感が出ない。各点に**自前の z 断面**を与える——稜線（付け根中心→頂点）で最大、フランクへ低下。

- **断面は非対称が正**: 実測フットプリントを頭円上で厳密回転して検算する（対称テントは検算で棄却された実例あり）。外フランク急落・内フランク緩落
- 結果: 向く側フランク詰まり・逆側開き（近耳が太り遠耳が痩せる）= 面の交代

### 4. 剛体の低次場（眼鏡）

顔に浮く剛体は、下地の顔造作 field を標本化しつつ **z≡const の0次代入**（= 平行移動 + 弦の一様縮み、わずかな先行 ~1.05）に均す。場の曲率をそのまま通すとフレームが有機的に曲がり「壊れた眼鏡」になる。

- 剛性は全頂点の**直線 fit 残差**で機械検証できる（実証: 残差 0.003px）

### 5. 接触縁の所有権と差動従属

二層が画面上で重なる場所の見た目は**手前の層が所有する**（知覚上の前後で決める——描画順と食い違うことがある。実例: 帽子は draw order 最前面だが知覚上は前髪が手前）。奥の層は接触帯で手前の層の field へ従属させる（係留先の切替。ランプでブレンド）。

- **完全一致は従属の上限であって最適ではない**: 外側の殻は内側よりわずかに大きく動くのが物理。殻差 `λ·ZC·(z_outer−z_inner)` の差動を残す。素の物理差動（λ=1）は知覚不能なことがある——λ で数px 級まで増幅して目視較正（実証: λ=4 でスリップ 0.7〜2.2px。見苦しい滑り ±18px 級に戻さない）
- 差動 × 縁の勾配が**接点の縦走行**（沈み込み/現れ）を生む——立体感の仕上げ

### 6. 接続の連続性次数（C0 → G1）

隣接層との縫い目は C0（位置、隙間なし）では足りないことがある。G1（接線）の不変量は**「変形後の関節角 = rest の関節角」**——完全接線吸着は rest 自体が非G1（作画意匠の角）なら誤り。

- **接線の相手は「回転後の所有者」で選ぶ**: rest の隣接と回転後の隣接は交代することがある（実例: rest では髪、+30 の遠側下隅では後頭部パーツ）。±max の変形後レンダで実測してから割り当てる
- G1 の大半は技法5の場共有から構成的に出る。整形補正は 1〜3px 級の後始末（先端ピボットの格子応答は設計の半分以下に沈む——ピボット行の微回転を併用）

## 被り物の座標系と頂部凍結帯（2周目 Fable 統制走 2026-07-06 追記。技法1〜6 の前提となる土台）

- **被り物の座標系 = 「直下の層の水平殻を共有 + 縦断面だけ自素材の球冠に張り替え」**。密着する被り物（帽子・カチューシャ級）は水平殻を直下の髪殻と完全共有する（層差は技法5 の差動で扱う——殻を別に立てない）。縦断面は**自素材の最上端を極とする球冠**に張り替える（直下の層の縦断面を使うと、被り物が上へはみ出す帯が定義域外で死に、クラウンがせん断する）。判定条件 = 素材が直下の層の極より上に伸びるか。共有の報酬 = 押さえ接触線の連続・シルエットの引き継ぎ・ゲイン整合が式ひとつで構成的に出る
- **頂部凍結帯（垂れ房則の上向き鏡像）**: 極より上に立つ素材（立ち付属物・頂部のたるみ）は縦断面を**付け根の行の値で凍結**する = 付け根の並進を運ぶ。凍結しないと先端が付け根に対して遅れ、付属物が倒れて見える（「頂部が塊として回るか」が gate の軸）。Y 転置節の「X の頂部凍結帯」の定義はこれ
- **剛体は場の読者であって作者ではない**（技法4 の手順精密化）: 剛体アクセサリの場は自分で設計せず、**下地の committed 場を代表点（レンズ中心等）で標本化し、その値の線形 fit（傾き+切片）をそのまま剛体場にする**。先行率（外側の殻の読み）は fit 値への微小乗算。剛性の検証は全頂点 dx の直線 fit 残差
- **差動の振幅は知覚が決める**（技法5 の較正注記): 素の物理差動（λ=1）はサブピクセルに沈んで知覚不能なことがある。**符号と形は物理から、振幅は目視較正から**——λ は増幅ダイヤルであり、知覚可能な数px 級に達するまで上げてよい（見苦しい滑りに戻さない上限は素材の縁勾配が決める）

### 技法の相互作用と測定手順（2周目 3b-v3 で判明した不足の補填）

- **技法1 × 技法3 の相互作用**: W(y) は立ち付属物の高さ帯では「付属物自身の幅」になり、縁係留が錐断面を殺す（稜線変位が潰れる）。立ち付属物の行帯では技法1 の縁係留を無効化し、技法3 が縁まで自前で z を描く（錐の外フランクは縁の外でも z→0 へ落ち続ける = 死帯なし）
- **複数ランプの合成順**: 縁係留（技法1）は最外殻、面従属（技法5）はその内側に掛ける。逆順だとシルエットが膨らむ
- **頂部凍結行 y_freeze の測定定義**: alpha の列プロファイルで「立ち付属物の裾がクラウンへ合流する行」（colsTop のジャンプ検出）を取る。目測の推定帯は当てにならない（2周目実測: 推定帯の外に真値）
- **接続ループの傾き k の読み**: 下縁 alpha の最外半幅でループ円を fit → その傾きに**層ゲイン g を乗じて**初めて縁端数px 級に落ちる（素の幾何傾きをそのまま使うと過大）
- **隠蔽維持 q_root の解**: 露出点には「q をいくら絞っても救えない構造的露出」（隣接素材の横幅不足等）が混ざる——**rescuable な点の min で q_root を解き**、構造的露出は別途パーツ解の候補として報告する
- **toward 側の主方向床クランプは要素普遍**（レシピ06 卵形ドーム節の罠が帽子でも再発・同処方で解決）: 放物殻×弦項の構造的逆符号域は殻を持つ全要素で発生しうる

## 拘束台帳の運用（planning-gate の実体化）

**発火条件: 同一 field に fix が2ラウンド以上、または原理が3つ以上重畳したら、次の fix の前に `Inventory first`。**

- 台帳 = その field に効いている全拘束の表（原理 / 実装形・数値 / 出所 / 依存する隣接層）。**L0 のコンテキストでなく永続ファイルに住まわせる**（コンテキストは圧縮で削れる前提）。起草は調査エージェント（Sylph/opus 級）に委任してよい——現物 keyforms と生成器の照合まで込みで
- fix 委任には**全行を「保存 / 置換 / 意図的変更」の処置付き**で積む。直近の指摘だけから委任文を組むと、古い層の拘束が圧縮で落ちる（recency 圧縮の複合欠落——実際に踏んだ）
- **保存行は生成器 assert で drift 検出**（「キーを編集せずに挙動を壊す」を機械で捕まえる）
- 実例の教訓: 台帳起草の調査が L0 の誤診（dy 死亡説）を現物反証した。台帳なしの fix は生きている拘束を「直し」、真犯人を放置するところだった

## 人間仕上げ境界（役割分担の実測。2026-07-04）

- **Fable の到達点 = 土台**（全原理の合成 field、数値検証込み）。そこから先の「縁が隣接パーツに接するか」級の視覚微調整は、**Fable の反復より人間の手が速い**（実測: 良い土台の上なら1分未満。Fable は複数回の試行で不達）
- 「センスに見える課題」はまず1回、原理を言語化して委任してみる価値がある（G1 は言語化で勝てた。接触判断は勝てなかった）——**委任文に停止条件（目視1回で不達なら人間領域と報告）を積む**のが型
- **人間補正後の field への機械再生成は禁忌**: 人間の手直しが commit されたら、以降は committed 現物が正典。生成器式からの一括打ち直しは補正を上書きする。台帳に人間補正行を追加し、不触域を明示すること

## 軸の転置（Face Angle Y の立体物。2026-07-04、閉問題09で実証）

- **面の交代の Y 版**: 被り物は俯きで**頂面が現れる**（X の「側面チラ見え」より劇的）。実装は X の頂部凍結帯を転置しないこと——**凍結系装置の要否は「回転面と付属物の向き」で反転する**。Y では真の縦断面（極で z→0）がそのまま頂面の出現を生む（実証: 極と額帯の差 12.3px でクラウンが開く）
- **縁ループの dz→dy 結合は Y で消滅**（ループが回転面と同一平面に入る）。楕円の開閉は一般式の点ごと z 差が自動供給する。例外則は転置前に幾何的根拠の存在を問うこと
- **立ち付属物（猫耳）の Y = 前傾 + 明示縮尺**。縮尺は一致則の強度（変位が語る実効角）で入れ、ゲイン非対称なら縮尺も非対称
- **λ 差動（技法5）は接触対ごとに1回較正すれば軸を跨いで流用できる**
- **境界打ち直しの一般形 = 境界値を運ぶ H ランプ**: 描き縁が格子行に載らない場合、`H(y)·マスター場(u, min(y, y_縁)) + (1−H)·自場` で縁の値を格子内へ運ぶ
- 格子の margin 拡張時は**分割数を増やして物理ピッチを保存**する（13×13 → 15×15 の実例）
- **人間補正済みの場（C10 級）の上への新パラメータ層**: wrap は安全（X キーに触れない）。旧生成器は設計知識としては使えるが**X キー現物との一致は仮定しない**。人間補正キーのバイト不変 assert を名指しで入れる
- **ピボット要素**（回転軸の高さに住む耳など）: 「ほぼ動かないことが正しい」——死帯禁止の微小変位のみ入れ、縮尺は不適用（一致則の対偶）。「不動の検証」も数値で残す（実証: 隣接する顔殻の 1/5〜1/10）

## 襟 = 縁ループの同族（閉問題10で実証。巻き付き衣服縁）

**首に巻き付いた襟は帽子縁と同じ縁ループクラス**（カフス・ベルトライン等も同族の見込み）。ステッカー流で解くと物理的に正しくても「回った」でなく「滑った」に読まれる。

- **中央（前立て・結び目）は「正面」と認知される基準線**——並進は維持してよい（演出として盛るのも可。盛りは sin 項のみ = 一致則）
- **回転の証言は左右の肩→首線（接続線）の傾きの非対称が担う**: 遠側 = 奥の面が見えてきて**急峻化**、近側 = 緩やかに寝る。**実物の襟はこんなに変形しない——実物以上に盛るのが演出のウソの本体**（ユーザー言語化 2026-07-04）
- 追従要素（結び目）は**値コピーでなく式共有 + 自格子再標本化**——継ぎ目誤差を機械測定できる
- 非対称の最終の盛り加減は人間仕上げ境界になりやすい（帽子左右端と同型）——土台と**ワンノブのダイヤル**（非対称量・中央盛り）を整備して渡すのが Fable の仕事
- **PRE assert = 人間補正ガード**: 生成器の「前値一致」assert は、人間補正が入ったキーへの機械再生成を止める安全装置を兼ねる。assert が止まったら回避せず差分編集へ切り替える
