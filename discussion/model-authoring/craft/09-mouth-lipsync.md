# レシピ 09: 口パク（最大情報素材の単一変形 + 素材参照 morph 場）

> 由来: 閉問題17（2026-07-05 通過）。対象: Mouth Open × 母音（あいうえお）の口 rigging。同型の「参照素材への morph」全般に流用可能（表情差分の口・目の変形バリエーション等は未検証）。

## 0. 方式原理（2つの不変量）

1. **最大情報素材を正とする**: 変形は情報を潰せるが**発明できない**。歯・舌・口内を持つ最大情報の絵（全開の「あ」）を唯一の生きた drawable にし、他状態は変形で作る。opacity 切替の直積（母音×開き量）は組合せ爆発する——切替は一方向1境界のときだけ（レシピ05）。PSD に旧デフォルト口（閉じ・中間）の drawable が別にある場合は永久非表示化し、mouth_a を唯一の生きた drawable にする
2. **パッケージ内参照素材 = 合法オラクル**: ユーザーが「答えの形」を drawable として供給（永久非表示）し、エージェントがシルエットを実測して場に翻訳する。ref/ 封じ込めと両立する唯一のオラクル経路

## 1. 塔（入れ子の順序が物理）

```
既存追従塔（最内側） ⊃ MouthOpen ワープ ⊃ 母音ワープ i/u/e/o ⊃ mouth_a
```

- 母音が形を作り、Open が外から潰す →「い の半開き」「閉じたら母音が消える」が合成から自動で出る。rest 素材と同形の母音（あ）はワープ不要
- **通し周回の工程2時点では追従塔は未存在**——MouthOpen を最外に独立で建て、追従塔（工程3）が後から外を包む。上図は包まれた後の最終形。また param_mouth_vowel_a にはキーを打たない（あ=rest 同形）——runtime が a=1 を送っても無反応なのは仕様（開きは MouthOpen が担う）
- MouthOpen: キー1 = 恒等（rest = 全開）/ キー0 = 閉じシルエットへの潰し。**閉じは純変形**（配信縮尺では潰しの方が専用閉じ素材より視認性が高い——ユーザー裁定 2026-07-05）
- default open=0 → rest レンダの口は「潰した基準素材」になる（旧素材と画素が変わるのは方式の帰結。差分局在で機械確認）

## 2. シルエットの実測

- **メッシュ境界方式が一次**: 自動メッシュは alpha 輪郭に沿う → `inspectEvaluatedGeometry`（includeVertices）の頂点群から、口角（水平極値）と列プロファイル（水平 N 帯の y_top/y_bot）を取る。**非表示のままで測れる**（幾何は可視性と独立）
- プロファイルは3点移動平均で平滑化（決定論）
- 一時表示 → フォーカスレンダ → 非表示（op 往復）は目視照合用。合成レンダは背後の肌が写るため数値の正にしない

## 3. morph 場（基準 B → 目標 T の2段写像）

```
1. 水平（口角アフィン）: u = (x − x_L^B)/(x_R^B − x_L^B) → x' = x_L^T + u·(x_R^T − x_L^T)
2. 垂直（列ごと上下縁対応）: v = (y − y_top^B)/(y_bot^B − y_top^B)
   v∈[0,1]: y' = y_top^T + v·(y_bot^T − y_top^T)
   帯域外（v<0 / v>1 / 口角の外）: 最寄り縁のデルタで平行運搬（連続性）
statePatch = (x', y') − rest
```

- ★ **潰し場は高曲率**——折れ線がシルエット線に乗る場は格子解像度を要求する。9×7 は +4.9px 不足、25×23 で +2px gate 通過（実測）。数値 gate（±2px）を先に決め、格子は gate が決めさせる
- 検証: プロファイル残差（列平均 ≤3px・最大 ≤6px）/ 潰し高さ ≤ 閉じ参照 +2px / rest 差分の対象領域局在 / 既存キー無傷
- **差分の対象領域局在の手続き**: 変更前後の rest レンダを PNG デコードし、差分画素の bbox が対象領域（口 bbox + マージン）内に閉じることを数える。リメッシュや意図した画素変更を含む変更ではレンダ sha 一致が原理的に不成立——差分画素の数値局在化が回帰確認の正しい形

## 4. 品質の帰属

- 場の精度の上限 = **参照素材の品質**（例: 口周辺の肌の写り込みはシルエットを歪める）。崩れの一次対応は素材更新（ユーザー領分）。gen スクリプトが数値一次ソースなら素材差し替え後の再キーは決定論で再現できる
