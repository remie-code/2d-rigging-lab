## Body-Xの首追従を撤回（revision1330）

ユーザーから「首が体に合わせて動いているのはおかしい。参照画像は動いていない。左右両方」と指摘。rootが首の下側を襟へ寄せる独立Body-X変位を追加したことが原因。参照の首・襟を拡大して再確認すると、首の左右の線はほぼ定位置を保ち、手前の襟が向きを変えている。

rig_oracle_body_x_neck自体とそのBody-Xキーを削除した。子のrig_face_y_neckはrig_body_z_upperへ昇格し、既存Face-X/Yによる首の変形は維持。首の祖先にBody-X対象が存在しないことを確認した。その他のキーは同一、正面の描画も変更前とピクセル一致。neck-fixed-preservation.jsonを参照。

左右の最大姿勢を実描画し、首を固定しても襟への接続に目立つ隙間は出ていないとrootは確認。首の見える範囲は襟・髪の重なりで変わりうるが、Body-Xは首自体の位置・形を変えない。左右を含めた全41フレームと8代表複合姿勢を同revisionで再描画する。比較画面には「首と襟」の拡大を追加。

教訓: 襟と首の接続を整える目的で首側を動かすと、参照にない身体追従を導入してしまう。まず参照の首の線と衣服の重なりを分けて認知し、固定されている線を保つ。既に入っている変位を正しいと仮定して補償を重ねない。

変更前はneck-fixed-baseline-rev1329/へ保存。現行はbody-x/package revision1330。今回の修正の外観確認はユーザー待ち。
