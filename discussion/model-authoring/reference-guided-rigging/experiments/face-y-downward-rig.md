# Face-Y下向き：承認済み参照からの部位別造形

## 合意と対象

ユーザーは下向き参照v1に「OK、いいと思う。これに対してriggingしていこう」と判断。参照の姿勢を目標に、root自身が下向きの造形を担当した。サブエージェントは使用していない。参照承認と完成rigの外観承認は分け、後者は今回候補の提示後に行う。

作業基点は C:/workspace/remie/rigging/second-rigging-6-sol/reference-generation/face-y/ 。承認済み上向きのrevision1112から、下向き候補v2 / revision1160を制作。down-baseline-rev1112/に変更前のmanifest、rig-controls、keyformsを保存した。上向きとFace-Xの既存記録は履歴として保持。

## 参照から読んだ形と操作

身体の襟先端とネクタイ下端を目安に、生成画像を640×960へ均等縮小し、下向き参照をY方向+9px平行移動した。頭部を正面へ合わせる操作はしていない。衣服の生成による差が残るため厳密な一致ではない。down-alignment.jsonに目安と変換を記録。

下向きでは、目・眉・眼鏡・前髪が下がる一方、顎先の移動は小さい。目から顎までの間隔が縮まり、帽子は頂部よりも下縁の移動が大きく、上面が見える。rootは元絵と参照を見て、これを部位別の点対応として指定した。上向き変位の符号反転やRAFT出力の転写は使っていない。

- 顔：正面の頬から顎の輪郭と、下向き参照の輪郭を滑らかな変位へ対応付け。上半分の下降量と顎先付近の下降量を分けた。
- 目・眉・鼻・口：位置と縦幅を部位別に指定。生成参照の微笑みや描線を貼り付けず、元の通常表情・閉じ口素材を変形した。
- 眼鏡：上縁・ブリッジ・左右の下縁を別々に読んで格子へ反映。初回v1では画面右側の下縁が高く、目の縦幅が詰まって見えたため、v2で下縁を下げ、目の縦幅を少し戻した。
- 帽子：外周、下縁、折り返し、耳の内部、マークの対応を指定。外周だけの平行移動にはしていない。
- 前髪・長い毛束・後ろ髪：顔付近は下向きに追随し、長い毛束の下方へ滑らかに変位を減らした。
- 首：Face-Y変位をゼロに保ち、襟への接続を固定。追加済み首素材に対して顎の位置が変わることで見える範囲が変化する。穴を隠すための首のスライドは加えていない。

変形指定はauthor-down-v1.py / author-down-v2.py、最終格子変位はdown-controls-v2.json。既存Y格子の密度と構造を保持し、-30を最大、-15を半分の変位としてキー設定した。中間キーは独立した参照から作ったものではなく、今回の候補では線形の中間値である。

## 軸の独立と保持の確認

既存の20個のrig_face_y_*へ負側のキーのみを作成・更新した。Face-Xのparameterはparam_face_angle_x、Face-Yはparam_face_angle_yで、target集合に重複はない。各部位のY親とX子の階層を維持し、runtimeによる両変位の加算で斜めを表している。X/Yを同一デフォーマの複合キーにしていない。

rig-controls全体、Face-Y以外の全キー、Face-Yの0/15/30キーがrevision1112と同一であることを確認。保存モデルから再描画したX=-30/0/+30・Y=0とX=0・Y=30は、承認済み上向き制作時の描画とピクセル単位で一致。確認結果はdown-axis-preservation.json。数値チェックは既存状態の保持確認であり、自然さの合格判定ではない。

## 描画と人による確認

revision1160からX=-30/0/+30についてY=-30〜0の31段階、合計93頭部描画、および全身3姿勢を生成。比較ビューは画像補間ではなく実際の保存モデル描画を切り替える。

http://127.0.0.1:8770/face-y/downward/ に正面・位置合わせ済み参照・rigの同位置切替、顔/首の拡大、Face-X選択、Face-Yスライダーと再生を用意。承認済み上向きビューは /face-y/ に残す。

rootは下向きの正面・中間・最大、左右の斜め、および下向き全身を目視。実browserで参照/rig切替、左斜め途中、再生によるパラメータ変化を確認した。斜め専用の参照はないため、その自然さと単軸参照への一致を混同しない。生成側の目の描線・口の表情・首の陰影などは元素材と差がある。今回の完成判断はユーザーによるrig外観の確認待ち。

他表情・他軸・全モデルの厳密検査PASSは今回の確認範囲に含めない。


## v3：垂れる髪を身体に固定しない

ユーザーは、下を向く際に手前の房は若干下がり、後ろ髪は頭に引かれてわずかに変位するはずであり、完全に動かないと違和感になると指摘。v2では長い毛束の下方をほぼゼロ変位へ戻したため、毛先を身体へ固定したように見えていた。rootは頭部拡大での顔・帽子の確認に偏り、髪全体の姿勢変化を十分に認知できていなかった。

v3 / revision1176では8個の髪用Yデフォーマの負側だけを更新。前の左右の長い房は、顔近くから下方へ滑らかにつながる下降を毛先まで残した。前髪パーツの下に垂れる部分にも小さな下降を加えてつなげた。後ろ髪は頭側へわずかに引き上げ、長い部分はごく少し内側へ寄せた。根元・中間・先端を通じて連続した変化にし、全髪の一律平行移動にはしていない。

具体的な初回制作値は前の房の追加下降14〜16px、前髪下方8px、後ろ髪の追加上昇5〜11px（640×960頭部座標基準）。滑らかな重みで接続し、長い後ろ髪には小さな内向き変位も加えた。値は作業上の指定であって合格基準ではない。これは姿勢に応じた変形であり、時間遅れや慣性を計算する物理揺れではない。

顔・首・帽子など髪以外のキー、Face-X、上向きのキー、デフォーマ構造は保持。down-v3-preservation.jsonに確認結果を記録。下向きv3の頭部93枚と全身3枚を保存。author-down-v3.py / down-controls-v3.jsonが再現用ファイル。

頭部ビューに加え、/face-y/downward/hair/ に髪全体の正面・途中・最大、修正前/修正後の同位置比較を追加。ユーザーが毛先と身体との位置関係を直接確認できるようにした。rootは正面と最大、修正前後を切り替えて、前の房が下降し、後ろ髪の先がわずかに引き上がることを画像で確認。ユーザーの外観判断はまだ。
