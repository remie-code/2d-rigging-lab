# 弱めたFace-Y下向き：参照v5からの再制作

## 判断と対象

下向きrigは一旦ユーザー承認後、Editorで他の変位と組み合わせると崩れやすいとの指摘を受けた。ユーザーは下向きの参照自体を正面寄りへ変更する方針を選び、弱めたv3から「もうあとちょっと下げたい」と調整後、新候補v5を承認。「これでもう一回riggingして」と実行を指示した。

root自身が参照を見て、revision1176から下向きの負側だけを再制作。最終候補はmild-down-v2 / revision1218。新参照と今回のrigはユーザー承認済み（2026-09-27「OK、いいと思う。次はbody-xに進もう」）。サブエージェントは不使用。変更前のmanifest・rig-controls・keyformsはmild-down-baseline-rev1176/へ保存。

## 位置合わせと形の読み直し

reference-down-v5.pngを640×960へ均等縮小し、襟先端・ネクタイ下端の目安からY=-4px平行移動。身体の描き変わりはわずかに残る。頭を正面の位置へ重ねるための変換は使わない。mild-down-alignment.jsonとreference-down-v5-aligned.pngに記録。

新参照では、顎先は正面からほとんど動かず、目・前髪・眼鏡が小さく下がる。帽子の頂部の変化も小さく、下縁の下降で上面が少し多く見える。以前の強い下向き変形を全体に一定倍率で縮める方法ではなく、部位別に再指定した。

顔は頬から顎の対応と、上半分の小さな下降を滑らかにつなぐ。目の縦幅の縮みは旧版より少なく、元の開いた目の印象を保つ。鼻・口はそれぞれの参照位置へ動かす。眼鏡は上縁・ブリッジ・左右下縁の対応から作り、v2で画面右側の下縁の位置を微調整。帽子は外周・折り返し・耳・マークの対応を指定し直した。

前の長い房は根元から毛先まで小さな下降を残し、後ろ髪は下方へ行くにつれてわずかな引き上げと内向き変位へ連続的につなげた。毛先を身体へ固定する失敗を繰り返さない。首のY変位はゼロで、襟への接続を固定する。生成参照の描線や微笑みを貼り込まず、元の通常表情・閉じ口素材を変形した。

制作スクリプトはauthor-mild-down-v1.py / author-mild-down-v2.py、最終指定はmild-down-controls-v2.json。Face-Y=-30を今回の弱い下向き最大、-15をその中間として設定。半分のキーは独立した中間参照からの造形ではなく、今回も端点変位の半分。パラメータ値は角度そのものを保証しない。

## 独立した軸と保持

20個の既存Face-Y用デフォーマへ負側キーのみを更新。Face-Xとは別targetを維持し、同じデフォーマへ両軸を設定していない。runtimeの既存の加算合成を利用。デフォーマ構造・格子密度、Face-Y以外の全キー、Face-Yの0/15/30はrevision1176と同一。X=-30/0/+30・Y=0とX=0・Y=30の描画も変更前と一致。mild-down-preservation.jsonに証拠を記録。これは保持の確認であり自然さの合否ではない。

## 複合姿勢の確認と限界

左右Xの最大と中間Yを目視。さらに下向き最大へ、X=-30/Z=-15、X=+30/Z=+15、X=-15/Body-X=-10/Body-Z=-10、X=+15/Body-X=+10/Body-Z=+10を加えた4代表姿勢を描画した。rootが確認した代表姿勢では顔・眼鏡・首のつながりに大きな崩れは見られなかった。

ユーザーへ崩れの目立った具体的組み合わせを任意で尋ねながら制作したが、制作時点でそのEditor状態は特定できていない。今回の4姿勢で全ての合成問題が解消したと断定しない。Body-Yは今回保存モデルのkeyform一覧に存在せず、確認対象として加えていない。他表情・物理揺れの全状態や全モデル技術PASSは未検証。
