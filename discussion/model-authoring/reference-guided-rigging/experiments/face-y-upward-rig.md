# Face-Y上向き：独立したデフォーマによる制作

## 合意と対象

ユーザーは上向き参照v5を最大姿勢の目標として承認し、riggingの実行を依頼。X用とY用は独立したデフォーマとし、一つのデフォーマに両軸のキーを設定しない。斜め向きはXとYの変形を重ねて表す。この方針を今回の必須条件とした。root自身が画像を認知・指定・修正。サブエージェントは使用していない。

成果基点：C:/workspace/remie/rigging/second-rigging-6-sol/reference-generation/face-y/ 。negative-face-x/package revision1036を別コピーして制作。既存Face-X側の保存モデルは変更していない。現在は上向きrig候補v3 / revision1112。ユーザーのrig外観承認はまだ。

## 構造と合成の実装事実

既存モデルには部位別のrig_face_y_*が20個あり、その子に対応するrig_face_x_*が存在した。首のみ子の名前はrig_reference_face_x_neck。このY階層を再利用し、上向きのキーを再制作した。顔、鼻、両目、眉、口、眼鏡、耳、帽子、前髪、左右の長い毛束、後ろ髪、首を、同じ変形が必要な単位で扱う。

- Face-Xのキーはparam_face_angle_x、Face-Yのキーはparam_face_angle_y。それぞれのtarget ID集合に重複なし。
- Face-Xの全キーと全対象デフォーマは制作前と同一。
- Y=0の変位はゼロ。X=-30/0/+30・Y=0の描画は元のFace-X v5とピクセル単位で一致。
- runtime-core/src/rig-control-warp-lattice.tsのapplyWarpLattice2dToVertexは、restの参照座標から各格子の変位をサンプリングし、現在頂点へ加算する。今回はこの既存の合成を使っている。X変形後の座標をYのサンプル位置に使う方式へエンジンを変更したわけではない。
- Face-Yの0/15/30を上向き範囲として制作。負側は継承された旧キーが存在するが、下向きの制作・承認済みとはしない。

## 位置合わせと造形

生成画像1024×1536を640×960へ正規化し、襟の両先端とネクタイの下端を目安にY方向+8pxの平行移動。頭・顔を正面と重ねるための位置合わせはしていない。衣服の描き変わりが残るため厳密な一致とはしない。alignment.jsonに基準を記録。

参照では目、鼻口、眼鏡、顎が一様に同じ距離だけ上がっていない。帽子頂部の移動は小さく、下縁と耳内部の見える面が変わる。これを個別の対応点・曲線へ指定し、滑らかな格子変位にした。首は追加済み素材が顎の背後まで存在するため、今回はY変位をゼロとし、上がった顎に対して見える範囲が変わるようにした。襟に接する首下端を上へ引き上げていない。

v1では顔幅の推定とy方向の曲線から頬・顎を作ったが、小さな折れが見えた。v2は滑らかにしたものの顎周辺が平たくなった。v3では正面・参照それぞれの実際の輪郭線へ戻り、画像上に輪郭候補を重ねてrootが確認。髪などへ誤対応した点を除外・訂正し、頬から顎先の対応を滑らかな変位へ再計算した。これはRAFTからの自動転写ではない。

Y側格子はskin 11×41、hat 21×21、front_hair 21×25、glasses 17×13へ細分化。他は既存格子を利用。目と眉の高さ、眼鏡下縁、頬にかかる細い前髪を実描画で調整した。新しい画像素材の生成や、参照画素のモデルへの貼付けは行っていない。

これらの格子数、+8px、補間設定は今回の制作値であり、視覚判断の合格閾値ではない。

## 確認と比較画面

保存モデルrevision1112からX=-30/0/+30それぞれについてY=0〜30の31段階、計93頭部画像と全身3画像を描画。rootはY単独の正面・途中・最大、左右の斜め最大および途中を目視。顎の初回の折れを軽減し、髪・眼鏡・帽子の動きと首下端の位置を確認した。斜め専用の参照はないため、その自然さを参照一致として証明していない。

http://127.0.0.1:8770/face-y/ に、正面・目標参照・rigの同位置切替、頭部/顔・首の表示切替、Xの3姿勢選択、Yの連続段階・再生を用意。参照との交互表示はX=0/Y=30を比較する。画像補間で見せかけた変化ではなく、各パラメータ値で実rendererから出した画像。

参照の口のわずかなへの字や生成画像特有の目の描線・首の陰影は、元の通常表情素材と一致しない。表情を変えて画像を模写するのではなく、今回の軸で目標とする姿勢と全体の印象を確認する。完成承認はユーザーが画像を見て判断する。
