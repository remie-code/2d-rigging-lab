# 手動造形によるFace-X中間姿勢の試作

2026-09-25。ユーザー承認済みの実験範囲。実施中、外観の承認は未取得。

## 目的と判断

前回の点・輪郭＋RAFT後段処理は技術的に動作したが、顔・眼鏡・髪の関係が不自然だった。ユーザーはroot自身が参照を見てモデリングする中間姿勢一つの試作を承認した。対応点の認知と、部品全体を自然な形にする造形能力を切り分けて確かめる。

rootが部品別の形・変形制御を直接決め、描画画像を見て修正する。数値は作業意図を描画へ伝えるためのもので、自然さの合格基準ではない。元絵と参照と手動試作を同位置・同倍率で切り替えて提示し、ユーザーが結果を判断する。前の対応点承認は今回の外観承認ではない。

## 範囲と入力

作業先は C:/workspace/remie/rigging/second-rigging-6-sol/reference-generation/manual-midpoint。旧Astraのrig成果は参照しない。元PSDはread-only、通常衣装・通常表情・閉じ口。既存の元絵・位置合わせ済み中間参照を使う。位置合わせは変更しない。

一つの中間姿勢のみ。最大姿勢、反対方向、Body、最終rigは含めない。RAFT、画像フィッティング、参照画素の貼り込み、新規画像生成は使用しない。元PSDの部品をroot指定の変形で再描画する。

## rootの造形方針（初期仮説）

顔肌、左右の目一式、眉、鼻、口、眼鏡、前髪、後ろ髪、帽子、耳、首を別に制御する。目は白目・虹彩・まつ毛に共通のaffineを適用し、ばらける変形を避ける。手前の目は丸みを保持、奥の目は横幅を縮める。眼鏡は橋とレンズの幅を格子で指定。髪と首は付け根付近から変位をなだらかに減らす。衣服・身体・尻尾は固定。

参照の帽子の耳の高さの変化は、そのままコピーせず元の形を保つ。これを含む初期値はrootの仮説であり、描画後に再判断する。全座標は2048×3072 canvas上の絶対座標。初期の詳細数値はrootからOrchへ送付済みで、成果ディレクトリのversion付きcontrols JSONが再現用の正本になる。

## 分担と工程

1. root: 造形判断、部品ごとの数値指定、初回描画と修正版の画像確認。
2. Orch-Sylph: 素材抽出・描画器・表示器を別Gnomeへ委譲し、独立Review-Sylphへ技術検証を委譲。自身は実装しない。
3. Gnome: PSDの可視leafとマスク・順序を保持して抽出。指定affine/格子のみで逆写像描画。controlsと版別画像を保存。元絵/参照/試作の同位置切替表示を作る。
4. Review: identity、既知変形、alpha・積層順、指定制御点への忠実性、参照画素とflowの不混入を検証。技術PASSと外観判断を分ける。
5. root: 画像を見て必要な修正を指示。実表示を確認し、実験結果と限界を記録してユーザーへ提示。

格子は指定された変位のbilinear補間。定義域外は変位の端値延長。数値を最適化で勝手に変更しない。部品未指定はidentity。途中版を上書きせず残す。
