## 目的とユースケース

自然な形へパーツを変形した結果、元素材の描画範囲が足りない場合に、形を歪めて不足を隠すのではなく、必要な画像を生成して置き換え、対象パーツを改めてriggingできるようにする。首が顎の下で見切れるケースが出発点だが、入口は首専用にしない。

基本操作は既存パーツの置換と再rigging。独立した部品が必要な場合には新規パーツ追加を使う。新素材の描画範囲が以前より広くなることは許容するが、旧メッシュ・キーを自動保全する特別な範囲拡張・rig移行機能は今回の対象外。

## 合意した制作の往復

1. 対象パーツの元素材・周囲の合成画像・配置と関連構造を取得する。
2. rootが外部の画像生成ツールで素材を作り、その画像を候補として登録する。
3. 生成画像をそのまま同スケールとみなさず、位置・スケールを調整する。対応点の指定と画像確認を使えるようにする。描き足しで外接矩形が変わるため、旧矩形へ単純に押し込めない。
4. 候補単体とモデルとの合成を見て配置を確認する。この段階で旧メッシュにより新素材の描画範囲を切らない。
5. 作業候補で素材を置換または追加し、新しいメッシュ・必要な変形を編集する。対象外パーツや共有デフォーマを巻き込まない。
6. 描画を確認し、結果をまとめて反映または破棄できるようにする。

素材の基準姿勢と座標系は明示する。首の初回ユースケースでは正面基準素材を生成し、riggingで中間姿勢へ動かす。中間姿勢画像へさらに同じ変形を掛ける二重変形を避ける。
