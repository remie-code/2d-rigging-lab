# 動きとしての評価と修正

## 合意

静止したキーだけでなく、その間を動く姿を見る。正面・中間・最大が個別に似ていても、間で顔が滑る、髪が分離する、輪郭が潰れるなら未完了。

Astraは画像を見て違和感を言語化し、自然と感じられるまで修正してよい。数値は作業の参考であり美的な合格基準ではない。ユーザーの確認は別の判断として残す。

## 観察の問い

- 頭が横を向いているか。正面の目鼻口が横へ平行移動する「お面」に戻っていないか。
- 顔の輪郭、左右の目の見え幅、鼻・口、眼鏡、帽子が同じ頭の回転を表しているか。
- 前髪と後ろ髪の根元がつながり、後ろ髪だけが背後の板のように静止していないか。
- 中間を経由しても跳びや不自然な加減速、輪郭・遮蔽のちらつきがないか。
- Face-X以外に、口・眼球・身体などを不用意に動かしていないか。
- 将来、他の軸を合成したときにも成立するか（現段階では未実証）。

## 記録とhuman gate

操作した軸/値、表示に使った入力・変換・rig、比較画像や動画、エージェントの観察、ユーザーの発言、残課題を紐付ける。実際にユーザーが見た版だけを評価対象とする。変更後の版に承認を自動継承しない。

今回の区切りは位置合わせした3枚の比較。ユーザーに示す前にエージェントが確認し、未解決の生成差分を明示する。ここでの確認は参照入力の整備に対するもので、rigの合格ではない。

## 仮説

独立した中間キーで大きな一段の変形より自然な軌道を得られる可能性がある。キーを増やすだけで解決するとは限らず、対応・格子・素材のどこに原因があるかを見て判断する。

## 提示方式の修正（2026-09-25、ユーザー指摘）

ユーザーは、横並びの静止画像では位置の一致を認知できず、同じ場所で切り替える方式が必要と指摘した。以降、位置合わせのhuman gateには、共通canvas・共通crop・同倍率を保ち、画像を即時切り替える表示を用意する。横並びは補助にとどめる。フェードや補間を挟んで差を隠さない。切り替え表示自体をrigの連続運動の検証と混同しない。
