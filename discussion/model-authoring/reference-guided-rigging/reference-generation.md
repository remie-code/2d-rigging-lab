# 単一軸の参照画像を作る

## 合意した考え方

「別の横向きイラスト」を作るのではなく、「この元絵に対し、Face-Xだけを最大まで操作したrigの完成表示」を強く意識させて生成する。他の軸・表情・衣装・カメラ・身体姿勢は基準状態とし、元絵との対応関係を保ちたい。これは生成の狙いであり、現行画像で完全に満たされた事実ではない。

正面・中間・最大を用意する。最大だけをゴールにすると大きな変形を単純な補間で表すことが難しそう、というユーザーの指摘が中間生成の動機。中間は最大の格子変位を単純に半分にしたものとして扱わない。

髪は頭の付属物として捉える。前髪だけ動いて後ろ髪が動かない張りぼてに見える問題が指摘された。根元・頭頂・後頭部と、重力の影響を受ける下方の房が連続してつながる目標を与える。後ろ髪問題が解決したとの確定判定はまだない。

## 実験事実への入口

[Face-X生成試行](experiments/face-x-reference-generation.md)に元素材・プロンプト・各結果・ユーザー評価を記録した。中間として使うのはv2。v1は最大に近く、中間候補としてエージェントが退けた。

ユーザーはGPT Image 2.5を鍵と想定した。実際の試行はbuilt-in image_genで行い、呼び出しにモデル選択引数がなく、実モデルIDは独立確認していない。

## 外部事例との関係

ユーザー提示のStandRig投稿スクリーンショットには、RIFEのFLOW指定からデフォーマを作り、正面画像をデフォーマ変形のみで動かす旨が書かれている。「画像は必要ない」は、参照画像が不要という意味ではなく、RIFEが作る補間画像を最終表示に用いず変位情報を使う意味、と会話で解釈した。投稿側の実装は未調査。RIFEと既存方式を組み合わせる比較表示もあるが、その具体的アルゴリズムを再現済みとはしない。
