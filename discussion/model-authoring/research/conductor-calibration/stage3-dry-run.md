### 1.1 FaceX（レシピ06 本文 + 頭部外周テンプレ + 隠蔽維持）

**委任 D1: FaceX 核**（鼻・顔輪郭・目 L/R・眉 L/R・口。1委任 = 塔+キー+検証の1バッチ）

- 設計: 要素ごとに z プロファイル z(x)（放物線 ansatz 1−(u/U)²。球√は limb で棄却済み）。層の目安: 鼻・顎 > 顔面造作 > 顔輪郭 > 頭蓋。cx はダイヤル①（初期値は頭蓋/顔輪郭 bbox の x 中心で**仮置き**——Q10）。ゲイン1 = 鼻振幅 ≈ 頬幅（実頂点範囲列の値）の10%。dx = u(cosΔ−1) + z·sinΔ の有限回転式で field を決定論生成（微分近似・単一球 ansatz の2誤りを踏まない）
- 構造: 1要素×1パラメータ=1層。目の塔（開閉状態デフォーマ3基×2）と口の塔（MouthOpen⊃母音）は `createWarpDeformer` の **wrapChildren** で包む（childDrawableIds と排他）。鼻（**基底鼻**——partId で表情セット nose と区別）・輪郭・眉は childDrawableIds 直。格子: bezier=transform 一致、余裕 domain なら相場より2段細かく（9×9〜11×11 級）、domain = 実頂点範囲 union + 移動マージン
- キー: `editKeyformKey createEndsCenter` / `controlPointOffsets` / min・max 独立設計（鏡像にならない）。目は 0.65T:0.25T 勾配（向く側縮み）、眉は目 field の 0次+1次標本化、輪郭は上顔面の流し+顎先スパイク+隠れ縁のみゼロ

**委任 D2: FaceX 外周**（前髪・垂れ房・後ろ髪カーテン・後頭部層 + 隠蔽維持）

### 1.2 FaceY（レシピ06 軸の転置 + 一致則 + 重力テンプレ最終形、レシピ07 Y 転置節）

**委任 D5: FaceY 殻+造作**

- dy = v(cosΔ−1) + z·sinΔ、dx≈0。cy = 耳の高さ相場（実測クロスチェック: 目の高さの X 赤道と近接。シートに候補が無ければ実測——Q9）。**z プロファイルは X の資産をそのまま sinΔ 項へ**（層順・ゲイン整合・seam が引き継がれる）

- **変位と縮尺の一致則**: ゲインは方向別2値（俯き=フル / 見上げ=絞る——未描画面を晒す方向）、縮尺は「変位から読める実効角」の強度で入れ、実装は平均変位保存アンカー。ピボット要素（v≈0 の耳）は縮尺不適用 + 微小変位のみ（死帯禁止）+「不動の検証」も数値で残す
- assert: 0キー恒等 / 巻尺照合 / 回帰 / 耳の変位が隣接顔殻より一桁小さいことの数値記録

**委任 D6: FaceY 垂れ物**（重力テンプレ最終形 + **前髪3帯の正規適用**＝2周目②）

- `field = W(y)·場(u,y) + (1−W(y))·場(u, y_scalp) + plum`。3帯: 頭皮帯=フル場 / 懸垂帯=生え際変位ベクトル（X・Y 両成分）の一様運搬 / 最下部=プラム緩流。**W(y) は回転性成分の混合比**——恒等式 `field − root = W·(球面場 − root)` を機械検証
- y_scalp ワンノブ: 食い込み深度の符号反転行で実測（解剖学クロスチェック: もみあげ≈虹彩下端〜耳下端 / 襟足=首上端直上）。**固定線・折れ点は格子行にスナップ**。遷移は鋭く、**場の符号反転線を跨がない assert を機械化**（設計前に反転線を引く）
- **前髪も正規適用**: 生え際から先の垂れ毛束に 3帯モデルを引く（試走の毛先軽減衰近似を置換する正規実装。適用軸の範囲は Q4）
- 運搬2型: 縦素材=列コピー / 斜行素材=点アンカー。プラム項は最長毛先帯限定・κ 控えめ・θ 偶
- assert: W 恒等式 / 固定線行 0.000px / 等長検査は「伸びて見える」違和感が出た場合のみ（支配的にしない）/ 0キー恒等 / 回帰

**委任 D7: FaceY 立体物**（レシピ07 Y 転置節）

- 帽子: X の頂部凍結帯を**転置しない**（凍結装置の要否は回転面と付属物の向きで反転）——真の縦断面が頂面出現を生む。描き縁が格子行に載らなければ H ランプで境界値を運ぶ。margin 拡張時は分割数を増やして物理ピッチ保存

- λ 差動は X で較正済みの値を接触対ごとに流用
- 房の Y: D4 の立体化と D6 の3帯の合成（Y では重力テンプレが主・立体断面が従、と**仮置き**——Q3 に含める）

  4. 較正記録の記帳 / craft への書き戻し（曖昧箇所があればレシピ改訂してから工程4 へ）

### 1.8 委任の共通規律（全 D1〜D11）

- 1委任 = 塔+キー+検証の1バッチ（40〜100 tool uses 相場。超えそうなら L0 が分割）

- fix が同一 field に2ラウンド以上 or 原理3つ以上重畳 → **拘束台帳を起草してから次の fix**（永続ファイルに住まわせ、全行を保存/置換/意図的変更の処置付きで委任に積む。保存行は生成器 assert で drift 検出）。台帳起草は Sylph/opus 級へ委任可
