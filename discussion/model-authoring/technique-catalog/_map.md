# Technique Catalog Map

> 外部で公開されている玄人のモデリング技法（どんな表現に、どんな素材を用意し、どう組むか）を集め、加工し、実践するための外部記憶の入口地図。

## 位置付け

ワークスペース内の既存知見（[../craft/](../craft/)）はユーザー自身の素人考えに由来する。本トピックは、それとは独立に、外部の玄人の技法を集めることを目的とする。craft を比較の基準にしない。

## フェーズ 1 の合意事項

- 範囲は広く浅く。特定の例（首かしげ等）に引きずられない。
- 検索の取っかかり（seed）: 素材(PSD)の分け方、顔の角度、目と眉、口、髪、体の角度と呼吸、腕と手、服とアクセサリー、物理の揺れ、パーツ間の連動。分類は seed に押し込まず、集まったものから後で組み立てる。
- メモは軽く: 出典、リンク（投稿・記事・画像）、一、二行の要点。用語は原文のまま。
- 画像は元のリンクを基準にする。他者の画像・本文をリポジトリへ転載しない。
- Web はサブエージェントが seed ごとに並行調査。X はアプリ内ブラウザで L0 が調査（ユーザーがログイン、読むだけ）。
- Live2D / Cubism の固有名詞は、集めるフェーズのメモ（過去調査の文脈, [../../_conventions.md](../../_conventions.md) §7）に限って原文のまま残す。加工フェーズで本プロジェクト語彙へ直す。
