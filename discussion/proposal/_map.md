# Proposal Map

> `discussion/proposal/` 直下のファイルだけを示す地図。Live2D Feature ProposalはPrivate Prototype本体とは分離して管理する。

---

## 位置付け

`proposal/` は、Private Prototypeで得た観察や欲しい編集体験を、Live2Dへの機能要望として整理する文書を置く場所である。

Proposal文書は互換実装の設計書ではない。Cubism形式対応、SDK/Core代替、既存モデル解析を示唆しない。

## 直下のファイル

| Path | Role | Status |
|------|------|--------|
| [_map.md](_map.md) | `proposal/` 直下の入口地図 | Current |
| [live2d-feature-proposal-template.md](live2d-feature-proposal-template.md) | Live2Dへの機能要望を書くためのテンプレート | Current baseline template |

## 次の行動

1. 実際に提案する機能単位ごとに、このtemplateから個別draftを作る。
2. 提出前に、互換実装や権利安全性の断言が混じっていないかreviewする。
