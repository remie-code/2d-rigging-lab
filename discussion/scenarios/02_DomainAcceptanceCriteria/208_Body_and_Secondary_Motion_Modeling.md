# シナリオ: Body and Secondary Motion Modeling

> 参照元AC: [208_Body_and_Secondary_Motion_Modeling.md](../../acceptance-criteria/02_DomainAcceptanceCriteria/208_Body_and_Secondary_Motion_Modeling.md)
> 状態: シナリオ精緻化ドラフト

## 0. このドラフトの目的

このファイルは、`AC-BODY` を「身体、髪、衣装、装飾品の可動を制作・確認する操作粒度」まで降ろした場合、Open Editor がどの制作能力を満たすべきかを確認するためのドラフトである。

ここでは、Cubism Editor の画面構成を模倣することを目的にしない。ただし、Cubism Editor での参照操作や実務上の制作手順を明示し、その操作によって成立している能力を Open Editor の検証可能な期待結果として書く。

データモデル、API、永続化形式、UI コンポーネント設計はこのファイルの範囲外とする。

## 1. 公式事実

- Live2D Cubism のパラメータは、`Angle X` や `Mouth Open/Close` のような特定の動きを表す設定であり、キー間の形状は自動補間される。複数のパラメータを組み合わせてモーションを表現できる。
  参照: [About Parameters](https://docs.live2d.com/en/cubism-editor-manual/parameter/)
- 標準パラメータには、体の回転 `ParamBodyAngleX`, `ParamBodyAngleY`, `ParamBodyAngleZ`、呼吸 `ParamBreath`、腕・手、髪揺れ `ParamHairFront`, `ParamHairSide`, `ParamHairBack`、肩、胸揺れ、全体移動などが含まれる。髪揺れ系は通常、物理演算で設定するものとして記載されている。
  参照: [Standard Parameter List](https://docs.live2d.com/en/cubism-editor-manual/standard-parameter-list/)
- Cubism では、デフォーマにより複数頂点をまとめて編集できる。大きく回転させたい場合は、形状を変えずに回転させるための回転デフォーマを使う。
  参照: [About Deformers](https://docs.live2d.com/en/cubism-editor-manual/deformer/)
- Glue は、2つの ArtMesh の頂点を接着する機能である。Glue weight は頂点単位で調整でき、Glue compatibility はキーフォーム単位で数値を設定できる。胴体に対して首、右肩、左肩など複数箇所の Glue を設定する例が示されている。
  参照: [Glue](https://docs.live2d.com/en/cubism-editor-manual/glue/)
- Cubism の物理演算では、顔の振り向きに合わせて髪揺れのような動きをリアルタイムで付け、書き出すことができる。物理演算はグループ単位で、入力設定、出力設定、物理モデル設定を持つ。
  参照: [About Physics](https://docs.live2d.com/en/cubism-editor-manual/physics-operation/)
- 物理演算で揺れを制御するには、あらかじめ揺れの動きが付いたパラメータを用意する必要がある。入力パラメータには `Angle X`, `Angle Z`, `Body rotation X`, `Body rotation Z` のプリセットがあり、`Body rotation Y` によるジャンプ時の髪の広がりや、腕関連パラメータによるアクセサリ揺れも例示されている。
  参照: [How to Set Up Physics](https://docs.live2d.com/en/cubism-editor-manual/physical-operation-setting/)
- 物理演算の出力では、出力先パラメータ、振り子番号、影響度、反転、倍率、最大出力などを調整できる。出力が大きすぎる場合は、パラメータ範囲外へ振り切れてカクつく原因になる。
  参照: [About Physics](https://docs.live2d.com/en/cubism-editor-manual/physics-operation/)
- Viewer では、物理演算 FPS、振り子グループ、振り子段数、入力パラメータ、出力パラメータを確認できる。物理演算結果は FPS によって変化する。
  参照: [Check Physics Information](https://docs.live2d.com/en/cubism-editor-manual/check-the-physics/)
- 親ワープデフォーマから子デフォーマや ArtMesh の頂点がはみ出すと、負荷やデータ量が増える。Cubism には、親デフォーマ外へはみ出した頂点をハイライトする検証機能がある。
  参照: [Validate Deformer Function](https://docs.live2d.com/en/cubism-editor-manual/convenient-function-deformer/)

## 2. 明示的な仮定

- シナリオ中の `BodyRoot`, `Rot_Torso_Z`, `Warp_Breath_Body`, `Phys_HairFront` などの名前は説明用の例であり、正式な命名規約ではない。
- 衣装・装飾品用の `ParamSkirtFront`, `ParamRibbonSide`, `ParamSleeveL` などは、標準パラメータリストに直接定義されていないため、このドラフトではプロジェクト仮の部位パラメータとして扱う。
- 公式ドキュメントは Cubism 側の操作と概念を説明しているが、Open Editor が部位分類、破綻判定しきい値、警告文言をどう持つかは定義していない。これらは本シナリオでは期待される検証能力として扱い、設計決定とはしない。
- 「隠れ部分が不自然に露出しない」「接続が破綻しない」の具体的な許容値は未決である。このドラフトでは、人が制作確認で見る破綻を検出・再現できることを期待結果として書く。

## 3. シナリオ記述方針

各シナリオは、次の3層を分けて書く。

- Given: 前提となるモデル状態、部位、パラメータ、制作方針
- When / Cubism参照・実用操作: 人が Cubism Editor または同等の制作環境で行う操作を、再現できる粒度で書く
- Then / Open Stack期待結果: このプロジェクトの Open Editor が、UI模倣ではなく同等の制作能力として満たすべき観測・プレビュー・検証結果を書く

このファイルでは、個別の保存形式、内部クラス、API レスポンス、画面レイアウトは定義しない。

## SC-BODY-001: 体の回転・上下・呼吸を身体姿勢として定義できる

### Given: 前提条件

- 既存モデルが読み込まれている。
- 胴体、首、肩、腰に相当する ArtMesh またはデフォーマが存在する。
- 身体用の大域デフォーマを新規作成または選択できる。
- 体の回転と呼吸を、顔表情とは別の身体姿勢として扱う方針が決まっている。

### When / Cubism参照・実用操作

1. パラメータグループ `Body` に相当する場所へ、`ParamBodyAngleX`, `ParamBodyAngleY`, `ParamBodyAngleZ`, `ParamBreath` を用意する。
2. `ParamBodyAngleX`, `ParamBodyAngleY`, `ParamBodyAngleZ` には、最小、デフォルト、最大のキーを設定する。
3. `ParamBreath` には、息を吐いた状態、標準状態、息を吸った状態に相当するキーを設定する。
4. 胴体の左右向き、上下、傾きは、胴体や肩の大域デフォーマを動かして作る。
5. 呼吸は、胸、肩、腹部、服の前面がわずかに広がるようにワープまたは頂点編集で作る。
6. 各パラメータを単独で動かし、次に `ParamBodyAngleZ` と `ParamBreath` を同時に動かして、姿勢変化と呼吸が同時に成立するか確認する。

### Then / Open Stack期待結果

- Open Editor は、身体の左右向き、上下移動、傾き、呼吸を顔表情とは別の身体姿勢変化として扱える。
- `ParamBodyAngleX`, `ParamBodyAngleY`, `ParamBodyAngleZ`, `ParamBreath` に相当する可動範囲をプレビューできる。
- 体の傾きと呼吸を同時に適用した状態でも、胴体、肩、首、服の前面が不連続に跳ねない。
- 呼吸は、顔や口の開閉ではなく、胸、肩、腹部、衣装前面の微小な形状変化として確認できる。
- 可動範囲の端で、胴体の輪郭が潰れる、首元が外れる、服の隙間が急に開くなどの破綻を警告できる。

### 検証するACの項目

- AC-BODY-001: 身体の姿勢変化を定義できること
- AC-BODY-005: 身体可動の整合性を検証できること

## SC-BODY-002: 頭部・首・肩・胴体の連動を定義できる

### Given: 前提条件

- 頭部の向きまたは傾きを制御する既存パラメータとデフォーマが存在する。
- 首、肩、胴体に相当する要素が、頭部要素と区別できる。
- 胴体側には `ParamBodyAngleX` または `ParamBodyAngleZ` に対応する姿勢変化が作成済みである。
- 頭部と胴体を完全に同じ動きにせず、首と肩で連動量を調整する方針が決まっている。

### When / Cubism参照・実用操作

1. 胴体全体を動かす親デフォーマを `BodyRoot` として扱う。
2. 首元の接続を補正するデフォーマを、頭部側と胴体側の間に置く。
3. 肩の左右要素を、胴体の傾きに追従する対象として設定する。
4. 頭部の傾きパラメータを右方向へ動かし、胴体の傾きパラメータを左方向へ動かす。
5. 首、肩、胴体の接続が破綻しないように、首元のワープまたは Glue weight を調整する。
6. 頭部だけ、胴体だけ、頭部と胴体の同時変化、の3状態を切り替えて確認する。

### Then / Open Stack期待結果

- Open Editor は、頭部、首、肩、胴体の連動関係を、同一変形ではなく部位ごとの追従量を持つ関係として扱える。
- 頭部操作時には首元が追従し、胴体全体が意図せず同量回転しない。
- 胴体操作時には肩と首の根元が追従し、頭部の表情や目口の局所変形が壊れない。
- 頭部と胴体を逆方向へ動かした状態でも、首の接続が切れる、肩が胴体から浮く、隠れていた首裏が不自然に露出するなどの問題を検出できる。
- 連動確認の結果として、どの部位が親側に追従し、どの部位が局所変形として残るかを説明できる。

### 検証するACの項目

- AC-BODY-002: 頭部と身体の連動を定義できること
- AC-BODY-005: 身体可動の整合性を検証できること

## SC-BODY-003: 髪の手動可動を物理演算の前提として定義できる

### Given: 前提条件

- 前髪、横髪、後ろ髪に相当する ArtMesh またはデフォーマが分離されている。
- 髪の根元は頭部側に追従し、毛先は揺れとして変形させる方針が決まっている。
- 物理演算を設定する前に、揺れ先となる手動可動パラメータを用意する必要がある。

### When / Cubism参照・実用操作

1. `ParamHairFront`, `ParamHairSide`, `ParamHairBack` に相当する髪揺れパラメータを用意する。
2. 各パラメータに、左揺れ、標準、右揺れのキーを設定する。
3. 前髪は根元を頭部に残し、毛先側だけが遅れて流れるようにワープデフォーマを編集する。
4. 横髪は顔や肩にめり込まない範囲で、左右方向と外側方向の揺れを作る。
5. 後ろ髪は胴体や背中側の傾きと競合しないように、頭部追従と髪揺れの影響範囲を確認する。
6. 髪揺れパラメータを単独で動かし、次に頭部傾きと組み合わせて確認する。

### Then / Open Stack期待結果

- Open Editor は、髪の各部位について、物理演算の出力先になる手動可動状態を定義できる。
- 前髪、横髪、後ろ髪の揺れ方向と可動範囲を、それぞれ独立してプレビューできる。
- 髪の根元は頭部側に追従し、毛先は揺れパラメータにより変形することを確認できる。
- 髪揺れと頭部傾きを同時に適用しても、頭皮付近の隙間、顔への過剰なめり込み、肩上での不自然な露出を検出できる。
- 物理演算へ渡す前提として、どの髪パラメータが出力先として利用可能かを確認できる。

### 検証するACの項目

- AC-BODY-003: 髪の可動を定義できること
- AC-BODY-005: 身体可動の整合性を検証できること

## SC-BODY-004: 頭部・身体入力に応じた髪の物理揺れを定義できる

### Given: 前提条件

- `ParamHairFront`, `ParamHairSide`, `ParamHairBack` に相当する髪揺れパラメータの手動可動が作成済みである。
- 頭部向き、頭部傾き、体の回転に相当する入力パラメータが存在する。
- 髪の物理揺れを、手動キーの代替ではなく、手動可動を入力・出力設定で駆動するものとして扱う方針が決まっている。

### When / Cubism参照・実用操作

1. 物理演算設定を開き、前髪用の物理演算グループ `Phys_HairFront` を作成する。
2. 入力として、頭部の左右向き、頭部の傾き、体の左右向きに相当するパラメータを設定する。
3. 必要に応じて、ジャンプや上下動の入力として `ParamBodyAngleY` に相当するパラメータを追加する。
4. 出力として、前髪用の髪揺れパラメータを設定する。
5. 振り子設定の長さ、揺れやすさ、反応時間、収束速度を調整する。
6. カーソル追従またはシーン再生で、頭部と身体を動かしながら前髪の揺れを確認する。
7. 出力最大値を確認し、揺れが小さすぎる場合と振り切れる場合の両方を調整する。

### Then / Open Stack期待結果

- Open Editor は、髪揺れを手動可動と物理挙動の両方から扱える。
- 髪の物理揺れについて、入力パラメータ、入力影響度、出力パラメータ、出力倍率、反転有無、振り子設定を確認できる。
- 頭部だけを動かした場合、身体だけを動かした場合、頭部と身体を同時に動かした場合で、揺れ方の差を比較できる。
- 出力が不足している場合は可動が小さい状態として、出力が過剰な場合はパラメータ範囲外へ振り切れる可能性として警告できる。
- 物理演算 FPS または同等の計算条件が変わると揺れ結果が変わりうることを、検証観点として扱える。

### 検証するACの項目

- AC-BODY-003: 髪の可動を定義できること
- AC-BODY-005: 身体可動の整合性を検証できること

## SC-BODY-005: 衣装・装飾品・アクセサリの副次可動を定義できる

### Given: 前提条件

- スカート、リボン、袖、腕アクセサリなど、身体本体ではない副次部位が存在する。
- 副次部位は、胴体、肩、腕、脚の動きに追従または遅れて揺れる方針が決まっている。
- `ParamSkirtFront`, `ParamRibbonSide`, `ParamSleeveL` などのプロジェクト仮パラメータを使ってよい。
- 左右に分かれる装飾品では、左右で揺れ方向を反転させる可能性がある。

### When / Cubism参照・実用操作

1. 副次部位ごとに、揺れ先となる手動可動パラメータを用意する。
2. スカートやリボンは、標準、左揺れ、右揺れ、外側へ広がる状態を必要に応じて作る。
3. 袖や腕アクセサリは、腕の動きに追従する入力パラメータを決める。
4. 物理演算グループを作成し、胴体、腕、肩、全体移動のうち、揺れの原因となる入力を設定する。
5. 出力先に副次部位の揺れパラメータを設定する。
6. 左右対称の装飾品では、出力反転を使って左右に広がる動きになるか確認する。
7. 身体の可動範囲内で、衣装や装飾品が身体本体を不自然に貫通しないか確認する。

### Then / Open Stack期待結果

- Open Editor は、衣装、装飾品、アクセサリを身体本体とは別の副次可動部位として扱える。
- 副次部位ごとに、手動可動、物理入力、物理出力、左右反転の有無を確認できる。
- 腕を動かしたときに腕アクセサリが追従し、胴体を傾けたときにスカートやリボンが遅れて揺れることを確認できる。
- 左右対称の装飾品で、片側だけ反転漏れがある、同じ方向へ寄ってしまう、可動範囲外でカクつくなどの問題を検出できる。
- 副次部位が身体本体、髪、顔周りと干渉し、隠れ部分を不自然に露出させる場合に警告できる。

### 検証するACの項目

- AC-BODY-004: 衣装・装飾品の可動を定義できること
- AC-BODY-005: 身体可動の整合性を検証できること

## SC-BODY-006: 身体可動の整合性を可動範囲全体で検証できる

### Given: 前提条件

- 体の姿勢、頭部と身体の連動、髪の可動、衣装・装飾品の可動が作成済みである。
- 身体、頭部、髪、衣装、装飾品の主要パラメータに、想定される最小値、標準値、最大値がある。
- 親子変形、Glue、物理演算のいずれかを含む部位が存在する。

### When / Cubism参照・実用操作

1. 身体姿勢パラメータを、最小、標準、最大、および複数パラメータの組み合わせで確認する。
2. 頭部と胴体を逆方向へ動かし、首、肩、服の襟元の接続を確認する。
3. 髪揺れと衣装揺れを有効にし、頭部、胴体、腕の入力を動かして副次可動を確認する。
4. Glue が使われている箇所では、接着部の重みや互換性により形状が失われていないか確認する。
5. 親ワープデフォーマ外へ頂点がはみ出していないか、またははみ出しが制作上の警告として管理されているか確認する。
6. 物理演算情報として、入力、出力、振り子段数、FPS または同等の計算条件を確認する。

### Then / Open Stack期待結果

- Open Editor は、身体可動の検証を単一パラメータだけでなく、頭部、身体、髪、衣装、装飾品の組み合わせとして実行できる。
- 部位同士の接続が破綻している箇所を、首、肩、腰、袖、髪の根元などの制作上の部位名で示せる。
- 隠れ部分の不自然な露出を、頭部逆方向、胴体傾き、髪揺れ、衣装揺れのどの条件で発生したか再現できる。
- 親子変形が意図通りに伝播していない場合、親側の姿勢変化、子側の局所変形、非伝播対象を区別して説明できる。
- 可動範囲内で形状が潰れる、頂点が親デフォーマ外へ出る、物理出力が振り切れる、Glue 接続部が破綻する、の各問題を別の検証項目として扱える。
- 検証結果は、制作修正に使える再現条件と対象部位を持ち、データ構造や UI 仕様をここでは決めない。
